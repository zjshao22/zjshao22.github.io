# L4｜多模态与生成机制

对应 19—24 单元。目标是区分已给定向量、真实训练模型、构造信号和外部案例。把四类材料都叫“AI 生成结果”会丢掉证据边界。

```sh
python3 -B ai_lab.py l4 --output ./runs/l4 --seed 42
python3 -B practice.py media --output ./runs/media --seed 42
```

## 二维 Flow Matching 真训练

核心程序学习以条件 c 控制的二维分布，目标均值为 `(2*c,0)`、标准差 0.3。网络输入位置、时间与条件，拟合路径速度，再用 Euler 步进从噪声采样。检查样本、目标、损失、参数哈希、留出误差、条件均值与步数对照，不能只看最后散点是否好看。

朴素方案直接给每个样本加固定偏移，不能学到时间和位置相关变化。速度场提供可学习机制；Euler 步数增多改变离散误差和运算量，不会自动纠正训练错误。教师先让学生预测条件正负时的均值方向，再运行并比较。

## 图像、声音与运动材料

![构造图像：计数与遮挡](/ai-labs/data/vision-cards.svg)

教师先让学生独立数可见形状，再看真值文件。遮挡后的图不能唯一恢复被遮内容；示意图不是视觉模型生成。核心 L4 的图文匹配同样使用给定向量，只有二维速度场真实训练。

声音材料为 [纯音](/ai-labs/data/audio-clean.wav) 与 [加噪纯音](/ai-labs/data/audio-noisy.wav)。`practice.py media` 用 wave/struct 读取实际文件，记录采样率、长度、负载、RMS 与已知干净参考下的信噪比。16 kHz、单声道、16 bit、一秒负载是 32000 字节；WAV 文件还含头部。它不是自然语音，更未运行 ASR。

![构造运动帧：身份一致性](/ai-labs/data/motion-frames.svg)

补充程序还按第 24 单元的 `v'=v+a, p'=p+v'` 教学环境训练标量 w，用正动作拟合速度变化，再在负动作和新幅度上滚动预测。输出保存训练系数、损失、真实环境状态与预测轨迹。SVG 是静态材料，数值模型是实际训练，两者不冒称大型视频模型。

## 学生任务与验收

提交条件采样对照、速度场更新证据、音频负载复算、状态预测未见动作轨迹，以及一种生成正确但不能证明现实理解的反例。教师让学生逐项标注“构造输入／真实训练／测量／外部报告”。

<details>
<summary>提示一：看程序实际优化了什么</summary>

Flow 网络拟合速度，状态小模型拟合速度变化系数；音频分析没有训练语音模型。

</details>

<details>
<summary>提示二：留出轨迹逐步比较</summary>

先比较第一步，再看误差是否累积。只报末态会隐藏中间错误相消。

</details>

<details>
<summary>完整解析与最低验收</summary>

必须保留两条命令的实际 JSON，指出训练与非训练环节。信噪比使用已知干净音轨作参考，任意真实录音没有这一真值；小动力学成功也不等于理解现实物理。

</details>

## 独立变式

把教学环境真实速度更新改为 `v'=0.9*v+a`，保持旧模型不变，先预测滚动误差，再另做训练对照。若表现下降，定位环境规则变化，不把它笼统归咎于“随机性”。
