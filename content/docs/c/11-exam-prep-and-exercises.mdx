# 核心概念与典型题型解析

在学习 C 语言的过程中，很多语法细节、运算优先级、边界条件以及底层内存机制看似微小，却直接决定了程序的正确性与鲁棒性。

本节系统提炼 C 语言 **10 大核心知识点族** 的典型题型，深度拆解高频易错陷阱，并通过典型题目测验强化对底层运行机理的准确理解。

---

## 一、十大核心知识点族全景概览

下表归纳了 C 语言 10 大核心知识点族的考查要点与常见易错陷阱：

| 知识点族                 | 包含范畴与核心要素                                                              | 高频易错点                                                |
| :----------------------- | :------------------------------------------------------------------------------ | :-------------------------------------------------------- |
| **1. 概论与编译机制**    | 机器指令、源程序 `.c`、目标文件 `.obj`、可执行文件 `.exe`、`main()` 函数        | 误以为 main 必须在最开头；源文件与目标文件后缀混淆        |
| **2. 格式化 I/O 交互**   | `printf` 格式符、`scanf` 取地址符 `&`、`getchar()` / `putchar()`                | scanf 漏写 `&`；浮点数 `%f` 默认输出 6 位小数             |
| **3. 数据类型与表达式**  | 标识符命名、ASCII 码、整型与字符通用性、`++` / `--`、`sizeof`、优先级           | 整数除法向零截断（`5/2=2`）；取模 `%` 两侧必须为整型      |
| **4. 分支控制结构**      | 关系逻辑表达式、两数互换、`else` 悬空配对、`switch` 常量与 `break`              | 悬空 `else` 忽视缩进；`switch` 遗漏 `break` 产生穿透      |
| **5. 循环迭代控制**      | `while`、`do-while` 最少执行次数、`for` 三要素时序、`break` 与 `continue`       | `do-while` 至少执行 1 次；末尾漏写分号 `;`                |
| **6. 数组与字符串处理**  | 一维数组下标 0 起算、二维数组行优先、字符串 `\0` 哨兵、`strlen` vs `sizeof`     | 数组下标越界无报错；`sizeof("abc")` 为 4 而 `strlen` 为 3 |
| **7. 函数封装与作用域**  | 函数不能嵌套定义、形参实参值传递副本、`static` 局部变量生命周期                 | 误以为函数能直接修改外部实参；`static` 变量只初始化一次   |
| **8. 指针内存寻址**      | 指针本质是地址、`&` 与 `*`、指针作为函数参数、指针移动步长                      | 野指针未初始化解引用；指针加 1 移动一个基类型步长         |
| **9. 结构体与类型定义**  | `struct` 定义不占内存、`.` 与 `->` 运算符、内存对齐、`typedef` 别名             | 结构体大小不是简单累加；`typedef` 不创建新类型            |
| **10. 文件读写与持久化** | 文本 vs 二进制文件、`FILE*`、`fopen` 模式（`"r"` 报错 vs `"w"` 清空）、`fclose` | 读不存在文件 `"r"` 返回 `NULL`；以 `"w"` 打开清空原内容   |

## 三、C 语言语法与表达式深度推演要决

1. **审清变量类型**：看清是整型相除还是浮点相除，`%` 两边是否都是整型。
2. **警惕赋值陷阱**：在 `if` 或 `while` 中，看清写的是 `==`（判断相等）还是 `=`（赋值语句）。
3. **分清前置与后置**：`++i` 先自增后代入；`i++` 先代入当前值后自增。
4. **数清数组越界**：`a[10]` 的合法下标只有 `0` 到 `9`，字符串记得预留 `\0` 的 1 字节。
5. **死守函数栈帧**：普通形参只是副本，想改变外部实参**必须传地址并解引用 `*`**。
