# 计算机网络

为什么不同设备上的程序能互相交换数据？浏览器的请求如何穿过不同链路与路由器？这组课程沿着[斯坦福计算机网络入门讲义的第一单元](https://github.com/khanhnamle1994/computer-networking/tree/master/Unit1-Internet-and-IP)，从应用的需求一路走到包的内部结构。

每节课都有概念解释、具体例子和练习。按顺序阅读后，你应该能画出一份数据从应用到链路、再到目标主机的过程，并解释每层在做什么。

1. [网络应用怎样通信](./01-how-web-works)：网页、文件共享与通话为什么都需要网络。
2. [互联网的四层模型](./02-four-layers)：应用、传输、网络与链路怎样分工。
3. [IP 如何把数据送向终点](./03-ip-and-packets)：数据报、逐跳转发与分组交换。
4. [封装：一个包里装着什么](./04-encapsulation)：把各层的控制信息连成完整旅程。
