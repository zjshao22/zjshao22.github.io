# 循环结构与迭代算法

在处理海量数据、数学级数求和、遍历字符数组以及图形绘制时，计算机最大的威力在于能够不知疲倦地重复执行指定操作——这就是**循环（Loop）控制结构**。

本节深入剖析 C 语言三大循环语句的底层执行时序与判定机制，厘清 break 与 continue 的跳转差异，并通过字符流处理、递推数列累加与嵌套图形打印掌握经典迭代算法。

---

## 一、三大循环语句的执行时序与特征对比

C 语言提供了三种形式的循环语句：`while`、`do-while` 和 `for`。

| 循环结构       | 语法格式                             | 判定时序                                    | 最少执行次数 | 典型适用场景                                 |
| :------------- | :----------------------------------- | :------------------------------------------ | :----------: | :------------------------------------------- |
| **`while`**    | `while (条件) { 循环体; }`           | **先判断，后执行**（当型循环）              |   **0 次**   | 循环次数未知，仅由外部输入或条件哨兵决定     |
| **`do-while`** | `do { 循环体; } while (条件);`       | **先执行，后判断**（直到型循环）            |   **1 次**   | 无论如何都必须至少运行一次（如用户菜单交互） |
| **`for`**      | `for (初值; 条件; 步进) { 循环体; }` | **初始化 $\to$ 判断 $\to$ 执行 $\to$ 步进** |   **0 次**   | 循环次数固定、已知或具备明确计数器的场景     |

### 1. `while` 循环：当型循环

如果一开始条件就不满足（为 0），循环体**一次都不会执行**：

```c
int i = 10;
while (i < 5) {
    printf("这里绝不会被打印！\n");
}
```

### 2. `do-while` 循环：直到型循环

### 3. `for` 循环三要素执行时序剖析

`for` 循环是使用最频繁的循环语句：

```c
for (表达式1; 表达式2; 表达式3) {
    循环体;
}
```

其严谨的时序逻辑为：

1. **表达式 1（初始化）**：仅在整个循环**刚启动时执行 1 次**。
2. **表达式 2（条件判定）**：每次进入循环体前检查，若为真（非0）继续，若为假（0）立即跳出循环。
3. **执行循环体代码**。
4. **表达式 3（步进迭代）**：在循环体执行完毕后执行（通常为 `i++`），随后回到第 2 步重新判定！

## 二、流程跳转：break 与 continue 的核心区别

在循环内部，有两个用于改变控制流的关键关键字：

| 关键字          | 功能与作用域           | 执行后的去向                                                                                      |
| :-------------- | :--------------------- | :------------------------------------------------------------------------------------------------ |
| **`break;`**    | **彻底终结整层循环**   | 立即跳出当前所在的最内层循环，后续所有迭代统统放弃，直接执行循环大括号外的下一条语句              |
| **`continue;`** | **跳过当前这一轮迭代** | 提前结束本次循环体尚未执行的剩余代码，直接跳往下一次循环的步进表达式（`for` 的表达式3）或条件判定 |

## 三、实战算法：字符分类统计（流式循环）

**任务描述**：输入一行字符，分别统计出其中的英文字母、空格、数字和其它字符的个数。

### 算法思路与 ASCII 条件

通过 `getchar()` 逐字符读取，遇到换行符 `\n` 时结束。利用 ASCII 码区间对字符进行分类：

- 英文字母：`(c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')`
- 空格字符：`c == ' '`
- 数字字符：`c >= '0' && c <= '9'`
- 其它字符：上述情况之外的 `else`

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    int c; // 必须使用 int 接收 getchar() 返回值以正确处理 EOF
    int letters = 0, spaces = 0, digits = 0, others = 0;

    printf("请输入一行字符:\n");
    while ((c = getchar()) != '\n' && c != EOF)
    {
        if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z'))
            letters++;
        else if (c == ' ')
            spaces++;
        else if (c >= '0' && c <= '9')
            digits++;
        else
            others++;
    }

    printf("英文字母个数: %d\n", letters);
    printf("空格个数: %d\n", spaces);
    printf("数字个数: %d\n", digits);
    printf("其它字符个数: %d\n", others);

    return 0;
}
```

## 四、实战算法：斐波那契分数序列递推求和

**任务描述**：有一分数序列：
$$\frac{2}{1}, \frac{3}{2}, \frac{5}{3}, \frac{8}{5}, \frac{13}{8}, \frac{21}{13}, \dots$$
求出这个数列的前 20 项之和。

### 数学规律与状态迭代

观察相邻两项的分数规律：

- 第 1 项：分子 $a_1 = 2$，分母 $b_1 = 1$
- 第 2 项：分子 $a_2 = 3 = a_1 + b_1$，分母 $b_2 = 2 = a_1$
- 第 3 项：分子 $a_3 = 5 = a_2 + b_2$，分母 $b_3 = 3 = a_2$
- **递推公式**：下一项的分子 = 原分子 + 原分母；下一项的分母 = 原分子。
- 因为原分子的值会被修改，所以必须借用临时变量 $t$ 暂存原分子！

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    int i, n = 20;
    double a = 2, b = 1, s = 0, t;
    /* a 为分子，b 为分母，s 为累加器，t 为临时变量 */

    for (i = 1; i <= n; i++)
    {
        s = s + a / b;       // 累加当前项
        t = a;               // 暂存旧分子
        a = a + b;           // 新分子 = 旧分子 + 旧分母
        b = t;               // 新分母 = 旧分子
    }

    printf("sum=%.10f\n", s); // 输出: sum=32.6602607986
    return 0;
}
```

## 五、实战算法：区间内指定倍数累加筛选

**任务描述**：输入变量 n，计算 1 至 n 中是 3 的倍数的数值之和。

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    int n, i, sum = 0;

    printf("请输入变量 n: ");
    scanf("%d", &n);

    for (i = 1; i <= n; i++)
    {
        if (i % 3 == 0) // 判断是否能被 3 整除
        {
            sum += i;
        }
    }

    printf("1 至 %d 中是 3 的倍数的数值之和为: %d\n", n, sum);
    return 0;
}
```

_验证_：当输入 $n = 40$ 时，输出求和结果为 $273$。

## 六、实战算法：双重嵌套循环打印菱形图案

**任务描述**：编写程序在屏幕上输出如下 7 行菱形图案：

```text
      *
    * * *
  * * * * *
* * * * * * *
  * * * * *
    * * *
      *
```

### 几何规律推导

将图案拆解为**上三角（4 行，行号 $i = 0, 1, 2, 3$）**与**下三角（3 行，行号 $i = 0, 1, 2$）**：

| 三角部分   | 行号 $i$ | 前导双空格数量 | 打印星号 `* ` 数量 | 规律公式                      |
| :--------- | :------: | :------------: | :----------------: | :---------------------------- |
| **上三角** |    0     |       3        |         1          | 空格：$3 - i$；星号：$2i + 1$ |
|            |    1     |       2        |         3          |                               |
|            |    2     |       1        |         5          |                               |
|            |    3     |       0        |         7          |                               |
| **下三角** |    0     |       1        |         5          | 空格：$i + 1$；星号：$5 - 2i$ |
|            |    1     |       2        |         3          |                               |
|            |    2     |       3        |         1          |                               |

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    int i, j, k;

    /* 上三角 4 行 */
    for (i = 0; i < 4; i++) // 控制上三角 4 行
    {
        for (j = 0; j < 3 - i; j++) // 控制每行前导空格
            printf("  ");
        for (k = 0; k < 2 * i + 1; k++) // 控制星号个数
            printf("* ");
        printf("\n");
    }

    /* 下三角 3 行 */
    for (i = 0; i < 3; i++) // 控制下三角 3 行
    {
        for (j = 0; j <= i; j++) // 控制每行前导空格 (1, 2, 3 个)
            printf("  ");
        for (k = 0; k < 5 - 2 * i; k++) // 控制星号个数 (5, 3, 1 个)
            printf("* ");
        printf("\n");
    }

    return 0;
}
```

## 本节小结与核心要点

1. **执行次数底线**：`while` 和 `for` 可能是 0 次；`do-while` 至少执行 1 次。
2. **break vs continue**：break 拔剑斩断循环；continue 跳过本轮直奔下轮。
3. **斐波那契迭代**：迭代更新前务必先保存旧变量 `t = a; a = a + b; b = t;`。
4. **嵌套循环法则**：外层循环控制行数，内层循环控制列数（先空格后符号）。
