# 03｜运算需要的数学桥梁

资料检索系统有两个候选片段，每个片段用三个数字表示。查询向量为 $q=(1,2,0)$，片段 A 为 $(2,1,0)$，B 为 $(0,1,2)$。程序怎样比较？在理解“语义”之前，先确保每个乘法的形状和数值都说得清。

## 点积是配对相乘再相加

两个同长度向量的点积为 $q\cdot a=\sum_iq_i a_i$。因此 A 得分 $1\times2+2\times1+0\times0=4$，B 得分 2。把所有维度先求和再相乘，会得到完全不同的数，也会丢掉维度配对关系。点积经常用作兼容性得分，但只有当向量表示适合任务时，高分才有意义。

向量长度 $\|q\|=\sqrt{\sum_iq_i^2}=\sqrt5$。余弦相似度把点积除以双方长度；这里 A 和 B 的长度也都是 $\sqrt5$，故余弦分别为 0.8、0.4。若 A 所有坐标乘 10，点积变成 40，余弦仍为 0.8。归一化会改变比较所强调的性质，不能一律认为某种得分更正确。

## 矩阵是组织多次运算的工具

把 A、B 按行放成矩阵 $X$，形状为 $2\times3$。一个 $3\times2$ 的参数矩阵可以把每行映射到二维：

$$
X=\begin{bmatrix}2&1&0\\0&1&2\end{bmatrix},\qquad
W=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\qquad
XW=\begin{bmatrix}2&1\\2&3\end{bmatrix}.
$$

输出第一行第一列来自 $2\times1+1\times0+0\times1=2$。内侧维度 3 必须相同，输出保留外侧维度 $2\times2$。批次、序列位置、表示维度在后续分别出现；写形状能在运行前发现大量错误。矩阵乘法一般不能交换次序，形状允许也不代表结果相同。

加权和是同一思想：两条值向量为 $v_1=(2,0)$、$v_2=(0,4)$，权重 0.25 和 0.75，输出 $0.25v_1+0.75v_2=(0.5,3)$。权重若非负且和为 1，结果是输入的凸组合；注意力将反复使用这一步。

## 从得分变成概率

分类器可能给出原始得分 $s=(0,\ln2,\ln3)$。softmax 定义为 $p_i=e^{s_i}/\sum_je^{s_j}$，得到 $(1/6,2/6,3/6)$。概率必须非负且总和为 1；原始得分可为负数，也不必归一化。实际程序常先减最大得分再取指数，概率不变，却能减少数值溢出。

条件概率 $P(B\mid A)$ 表示已知 A 时 B 的概率；$P(A,B)=P(A)P(B\mid A)$。若下雨概率 0.2，下雨时迟到概率 0.5，不下雨时迟到概率 0.1，总迟到概率为 $0.2\times0.5+0.8\times0.1=0.18$。不能把 0.2 和 0.5 直接相加。

期望是按概率加权的平均。例如奖励分别为 0、2、4，概率为 $1/6,2/6,3/6$，期望奖励为 $0+4/6+12/6=8/3$。它不是“最可能的奖励”：最可能的是 4，两者回答不同问题。后训练中增加期望奖励，需要追踪概率怎样改变。

## 用 Python 检查而不是代替解释

```python
import math
q, a = [1, 2, 0], [2, 1, 0]
dot = sum(x * y for x, y in zip(q, a))
scores = [0.0, math.log(2), math.log(3)]
weights = [math.exp(s - max(scores)) for s in scores]
probabilities = [w / sum(weights) for w in weights]
print(dot, probabilities, sum(probabilities))
```

教师先遮住结果，让学生预判，再运行；浮点结果接近 1 即可，不要求每次恰好打印 1。学生记录手算、实际输出、容差与形状。

## 学生任务：改变权重

对 $v_1=(2,0)$、$v_2=(0,4)$，得分改为 $(\ln3,0)$。求 softmax、加权输出；再把两个得分都加 100，判断结果是否改变。

<details>
<summary>提示一：先变成指数比例</summary>

两个指数比例是 3:1，概率相加应为 1。每个输出坐标分别加权。

</details>

<details>
<summary>提示二：共同平移会约掉</summary>

原权重为 0.75、0.25，第一坐标来自第一条值，第二坐标来自第二条值。共同增加 100 使分子分母同乘一个数。

</details>

<details>
<summary>完整解析与验收</summary>

输出为 $(1.5,1)$。共同平移不改变概率；程序应先减最大值保持稳定。验收既检查数字，也要求解释“得分不是概率”和“矩阵内侧维度必须匹配”。

</details>

## 独立变式

三类得分全相等时概率是多少？若词元编号从 2 换成 200，能否据此说语义距离增加 100 倍？答案是等概率各 $1/3$；编号只是查表索引，语义关系来自表示及其训练。给出一组任意重编号而内容不变的例子，即完成迁移。
