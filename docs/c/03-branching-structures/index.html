分支结构与条件控制

在现实生活与软件开发中，程序的执行不可能总是一条道走到黑。我们需要根据不同的输入和状态，选择不同的分支路径执行——这就是分支（选择）控制结构。

一、逻辑真假与 if 分支结构

在 C 语言中，判断条件是否成立遵循一个基本铁律：

  • 数值为 0 表示“假”（False）。
  • 任何非 0 数值均表示“真”（True）（无论是正数 1、100 还是负数 -5，只要不等于 0，均被视为真）。

四、switch-case 多分支与 break 防穿透机制

当多分支判断是基于某一个整型或字符型表达式的离散等值比较时，使用 switch-case 语句比冗长的 if-else 结构更加优雅清晰。

2. switch 的四大刚性规则

  1. 表达式类型限制：switch(...) 括号中的表达式必须是整型（如 int, char, short），绝不能使用浮点型（float, double）！
  2. case 标号限制：case 后面必须跟着一个常量或常量表达式（如 case 1: 或 case 'A':），不能是包含变量的表达式（如 case x: 严重报错）。
  3. 标号唯一性：同一个 switch 内各个 case 的常量值不能重复。
  4. break 的穿透效应（Fall-through）：
    • 如果某个 case 分支执行完毕后没有写 break;，程序不会退出，而是会毫无阻拦地顺次穿透执行下一个 case 的所有代码，直到遇到 break 或整个 switch 结束为止！

执行下列代码段后，控制台屏幕上输出的结果是（ ）： int x = 2; switch (x) { case 1: printf("A"); case 2: printf("B"); case 3: printf("C"); break; default: printf("D"); }
