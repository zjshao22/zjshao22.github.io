OSPF 与 BGP 怎样组织真实路由

从域内最短路径走向跨自治系统策略，推演区域、通告与收敛

第十七节：OSPF 与 BGP 怎样组织真实路由

校园网希望楼宇之间采用低成本、可快速修复的路径；接到两个运营商时，又可能希望优先使用合同价格更合适的出口。若把整个互联网当作一幅所有人共享、所有边含义一致的图，就忽略了管理范围与商业策略。域内与域间路由面对不同问题，因此通常采用不同机制。

一、自治系统把管理边界说清楚

自治系统 AS是采用共同管理与路由策略的一组网络，对外呈现一定的路由关系。AS 号不是 IP 地址，也不是路由器的设备编号；一个 AS 可以有很多路由器与前缀。

IGP用于自治系统内部，例如 OSPF；BGP用于交换前缀可达性与路径属性，既可在不同 AS 之间建立 eBGP，也可在同一 AS 内通过 iBGP 分发相关信息。iBGP 不是“另一个计算所有内部链路的最短路径算法”。

本节构造 AS 64512、64520 等来自私用 AS 范围，只用于课堂拓扑；真实公网分配与通告需要遵循相应管理。互联网不是要求每台个人电脑运行 BGP，终端通常只需要本地路由与默认网关。

二、OSPF 把链路状态算法变成协议

OSPF 路由器通过 Hello 等消息发现邻居、监测邻接，并交换链路状态信息 LSA。符合条件的邻接建立后，同步数据库；状态变化需要可靠传播，并识别新旧与过期信息。

相关消息包括数据库描述、链路状态请求、更新与确认；它们帮助补齐差异与确认传播，不能用“每台设备一次发全图，以后永不变化”替代这个过程。OSPF 常直接封装在 IP 中，协议号为 89，不是 TCP 89 或 UDP 89 端口。

各设备针对适用范围建立链路状态数据库，以自身为起点计算路径，再结合连接前缀等信息形成路由。OSPF 开销可配置；设备也可能依据带宽与参考值计算默认开销，因此算法看到的是约定的成本，不保证等于实测 RTT。OSPFv2 规范定义了邻接、数据库与路由计算。

邻居与完全邻接不要混为一谈

共享广播网络中若每台路由器都与每台其他路由器进行完整数据库同步，状态交换会很多。OSPF 可选 DR、BDR 组织相关邻接与传播。不是所有听到 Hello 的邻居都必定进入同一种完全邻接状态。

DR 是控制平面的组织角色，不表示所有用户数据必须先绕到 DR 再转发。点到点链路又有不同邻接方式，不能把广播网络的规则套给所有接口。

三、区域为什么能减小计算范围

校园规模扩大后，若每次支路变化都让全部设备保存细节与重新计算，会增加负担。OSPF 把网络分成区域，路由器主要维护自己所参与区域的详细链路状态。

Area 0作为骨干，区域边界路由器 ABR连接区域与骨干等范围，传播符合规则的跨区域可达信息；连接外部路由信息的 ASBR承担外部路由引入角色。两种角色可以由同一设备承担，也可以不同。

构造范围设备或前缀信息作用
Area 1教学楼路由器、192.168.10.0/24本区域详细拓扑
Area 0校园骨干与 ABR连接区域的骨干关系
Area 2宿舍路由器、192.168.20.0/24另一区域详细拓扑
AS 外部运营商提供的可达前缀或默认路由需按外部路由引入与策略处理

区域可以减少细节传播范围，汇总还可以减少前缀数量；汇总同时隐藏某些细节。不能把各区域编号理解为总成本，也不能只按“区域数最少”选择用户分组路径。

OSPFv2 的基础设计用于 IPv4；OSPFv3 最初适配 IPv6，并有后续扩展支持其他地址族。协议版本与地址族需要检查实际配置，而不是只看到邻居名字就宣布 IPv6 路由已正常。OSPFv3 规范说明了其初始 IPv6 设计。

Hello 检测时间、泛洪、计算与表项安装都影响实际中断。不能把 Dijkstra 在程序里耗时 1 ms 当作整套协议的故障恢复时间。瞬时不一致还可能造成临时环路与丢包。

五、BGP 通告的是前缀与路径属性

BGP 建立 TCP 会话，常用服务端口 179。它通过 UPDATE 通告可达前缀与属性，也可以撤销已经通告的前缀；KEEPALIVE 与定时机制等帮助维护会话。底层 TCP 可靠并不保证通告内容或策略必然正确。

常见属性包括：

属性在基础推演中的作用
AS_PATH记录经过的 AS 路径信息，帮助防环与选择
NEXT_HOP表达应到达的下一跳，需要本地路由能解析
LOCAL_PREFAS 内表达出口偏好，较高值常优先
MED向邻接关系表达入口偏好，比较有条件
COMMUNITY给路由附加可供策略解释的标记

这不是要求所有设备按同一份无条件属性清单做最终比较。实际选择还涉及合法性、可达性、配置与协议/实现规则；要先确认哪些候选可使用，再按适用策略排序。BGP-4 规范定义了属性与选择过程。

eBGP 通告向外传播时通常把自身 AS 加入 AS_PATH。收到包含自身 AS 的相关路径，通常会拒绝以避免 AS 级环路；特定受控配置可能有例外。它检查的是 AS 依赖，不等于证明 AS 内没有瞬时转发环路。

六、完整算例：为什么选择较长 AS 路径

构造校园 AS=64512，经出口 P 连 AS64520，经出口 Q 连 AS64521。两个出口都学到文档前缀 203.0.113.0/24，下一跳均可达；没有其他额外策略。

候选AS_PATHAS 个数LOCAL_PREF当前条件
P64520 64530 645503200有效、下一跳可达
Q64521 645502100有效、下一跳可达

假设校园策略先按 LOCAL_PREF 选择，值越大越优先。P 虽然 AS_PATH 更长，仍获选。这个策略可能反映费用、合同、容量或业务要求；BGP 不保证总是最少 AS、最低 RTT 或最短物理距离。

A 路由器可能用 OSPF 找到出口 P 的内部路径，再按 BGP 选出的外部可达信息送往 P。到 P 的内部成本大于到 Q 的内部成本，也不自动推翻已经更高的 LOCAL_PREF。

第一步提示：先划掉不能用的候选

若 NEXT_HOP 不可达，或 AS_PATH 出现被拒绝的自身 AS，不能只因为 LOCAL_PREF 最大就照样选。先检查资格，再比较策略。

核对两次变化后的选择

若 P 被撤销，Q 仍有效且下一跳可达，则可以改选 Q。若把二者 LOCAL_PREF 都设为 100，且约定下一项比较 AS_PATH 长度、其余条件无额外影响，则 Q 的两 AS 路径胜过 P 的三 AS 路径。

这两个结论都来自明确条件，不是把“BGP 看很多字段”当成无法推演的黑箱。

七、iBGP 与 IGP 怎样协作

边界学到的可达信息需要分发给 AS 内需要它的路由器。iBGP 保留相关外部属性，本地 IGP 让设备可以到达边界或 NEXT_HOP。NEXT_HOP 可能需要递归路由查找，不必总是建立 BGP 会话的那台邻居。

基本 iBGP 通告规则不把从一个 iBGP 邻居学到的路由再照常传给另一个 iBGP 邻居，所以朴素设计需要全互联会话。规模大时可用路由反射器等机制组织传播，它们又增加自己的属性与防环规则。反射器是控制传播的角色，不要求全部用户数据穿过它。

BGP 会话正常但目的不可达，仍可能是 NEXT_HOP 无路由、策略过滤、数据出口故障或回程不通。OSPF 的邻接、BGP 的会话和用户流量的成功是不同证据。

八、通告策略、聚合与路由安全

同一前缀可由不同方向通告；汇总较大前缀可以降低路由表规模，更具体前缀又可能构成例外。分组转发依旧按最长前缀匹配，不能因为一条 /16 的 BGP 属性更喜欢，就忽略表里有效的 /24。

外部策略还决定向谁出口某条路由。常见商业关系区分客户、提供者和对等者，用导入与导出规则限制转接范围；实际合同策略不同，不能把“学到了就通告给所有人”当作安全默认。

误配置可能产生路由泄漏，冒用前缀可能改变流量方向。过滤、前缀授权验证与会话保护处理不同威胁；授权源 AS 的验证也不等于验证整条 AS_PATH。安全单元会进一步区分这些保证。

九、观察任务：从控制证据走到转发证据

在课程模拟器或自己获准管理的实验设备中，分别读取 OSPF 邻居/数据库/路由，以及 BGP 会话/候选路径/选中路径。Cisco 风格设备可用 show ip ospf neighbor、show ip route ospf、show ip bgp summary、show ip bgp；其他平台用对应只读命令。

选择一个目的前缀，交出“通告来源→候选属性→选中下一跳→本地出口”的对应表。如果只看到 Established，还没有证明该前缀存在、被选中或可转发；若没有获准设备，就用第六部分的构造数据推演，不编造真实邻居日志。

只在课程隔离拓扑中观察老师安排的一条链路变化。记录故障前后下一跳与实际探测，分别写出控制面变化时间、数据恢复证据与测量的粒度。不要在校园真实骨干关闭端口进行测试。

十、独立变式：先合法，再比较，再转发

新增候选 R：AS_PATH=64522 64512 64550，LOCAL_PREF=300。按普通防环规则是否可选？随后 P 被撤销，Q 的 NEXT_HOP 也在本地不可达，现在能否因为 Q 是剩下的最短 AS 路径就直接转发？

最后假设 Q 恢复可达，路由表还有 203.0.113.128/25 → 另一有效出口 T。目的 203.0.113.130 与 203.0.113.10 各按哪个前缀查找？

完成后核对

R 包含自身 AS64512，按本题普通规则拒绝，不因为 LOCAL_PREF=300 而越过防环。P 撤销且 Q 下一跳不可达时，没有本题给出的有效可用候选；路径长度最短不能创造下一跳可达性。

Q 恢复后，.130 匹配 /25 与 /24，按 /25 去 T；.10 不在 .128/25，按 /24 的有效结果去 Q。BGP 为同一前缀选择候选与分组对不同前缀做最长匹配，分别完成不同工作。
