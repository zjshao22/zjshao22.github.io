## 通用预训练模型单独记录

`hardware.json` 记录 Apple M1 Pro、32 GiB、macOS arm64；`local-model/probe.json` 保存 Ollama 0.40.6、已安装 deepseek-r1:7b Q4_K_M、权重摘要、请求返回及载入状态。请求显式 `num_gpu=0`，观察 `size_vram=0`。只验证这个本机实例，不推断所有学生设备已具备条件。

`local-model/l5/l5.json` 的生成格式/来源检查通过，原始回答保留供人工核查。`local-model/l6/l6.json` 的通用模型策略四次选择 read，未计算或结束，预算后停止，整体核验为 false，CLI 退出 1；这是保留的真实失败案例。核心 L6 的微型学习策略另行完成了 read→calculate→finish。两者不能混记为“通用模型任务全过”。

通用模型只有已量化实例，没有其未量化版本质量比较；L7 的微型网络另做实际浮点/int8 对照。临时启动的 Ollama 服务在实测后停止，没有下载新权重或调用云 API。

## 复核入口

在仓库根目录运行 `python3 -B scripts/package-ai-labs.py --check`，核对发布文件哈希、ZIP 条目与 CRC；需要更新包时先不加 `--check` 重建。学生从 `public/ai-labs/README.md` 的命令运行，环境与权限范围以该文件和 environment.json 为准。

`presenter-summary.json` 合并两份单独复测结果：新主线 50 页、374 屏均无溢出、语义边界内切或正文/代码字号失败；保留历史十课也完成复测。新主线仍有 16 个稀疏屏、9 个碎屏建议项，本次使用默认审计，未声称通过严格稀疏度检查或 4K 审计。原始批量超时报告与 retry 文件均保留，没有删除失败证据。

全仓 `npm run check` 仍报告 20 个既有文件的格式问题，均不是本次修改文件；本次变更另用 Prettier 范围检查，结果保存在 `format.json`。没有为此改写其他课程。类型、Lint 和构建的通过结果不等同全仓格式已经清零。

后续课堂核验：学生本人环境诊断、实际授课、提示前后表现、教师保留的陌生迁移题和个人答辩。它们是教学使用环节，不由本机工程输出替代。
