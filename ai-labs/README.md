# 现代人工智能 CPU 实验包

版本：2026-10-21-v2。面向有 Python 基础、AI 零基础的学生。环境清单见 [environment.json](/ai-labs/environment.json)，本包来自已归档的 40 单元稿，作为选用材料保留；当前[人工智能十课](/docs/ai)不要求完成全部八组实验。运行与验收以本文为准，原实验教学页保存在教师档案中。

本包只依赖 Python 3 标准库。核心路径不下载模型、不调用云 API、不要求 GPU。所有训练数据和校园资料均为明确构造的教学材料；程序输出才是本次实际运行证据，课程文字中的参考值不代替学生运行。

从课程网站下载 [完整 ZIP](/ai-labs/ai-cpu-labs.zip)，解压后保留 data 子目录。单独下载 ai_lab.py 不足以运行文件与回归实验。[SHA256SUMS](/ai-labs/SHA256SUMS.txt) 用于检查包内源文件和材料。

## 运行

建议 Python 3.10 或更新版本；课程制作机实际使用 Python 3.14.6。进入解压后的目录后运行：

```sh
python3 -B ai_lab.py l1 --output ./runs/l1 --seed 42
python3 -B ai_lab.py l2 --output ./runs/l2 --seed 42
python3 -B ai_lab.py l3 --output ./runs/l3 --seed 42
python3 -B ai_lab.py l4 --output ./runs/l4 --seed 42
python3 -B ai_lab.py l5 --output ./runs/l5 --seed 42
python3 -B ai_lab.py l6 --output ./runs/l6 --seed 42
python3 -B ai_lab.py l7 --output ./runs/l7 --seed 42
python3 -B ai_lab.py l8 --output ./runs/l8 --seed 42
python3 -B -m unittest -v test_ai_lab.py
python3 -B practice.py sft --output ./runs/sft --seed 42
python3 -B practice.py media --output ./runs/media --seed 42
python3 -B practice.py memory --output ./runs/memory --seed 42
```

每个命令在指定目录生成对应的 `lN.json`；L6 还在该目录生成隔离的 `sandbox/numbers.txt`。如果该文件已有不同内容，程序拒绝覆盖，需换输出目录。实验不执行 shell、任意 Python 表达式或外部程序；文件工具只读沙盒内不超过 4096 字节的文件。

补充命令分别输出 sft.json、media.json、memory.json。记忆命令还真实创建、更正并读回 memory-store.json；重复实验请使用新输出目录，已有记忆不会被重置。其他命令复用同一结果路径会更新日志，做对照请分目录保存。

命令退出码为 0 表示本次全部程序核验通过，1 表示有核验失败或运行错误。失败输出应保留分析，不能手改核验字段或把参考结果复制进日志。换种子可能暴露训练波动，`--seed 42` 是课程固定复现入口。

`ai_lab.py` 的 L1—L8 JSON 共同字段（practice.py 补充日志以 configuration 记录配置）：

- `environment`：Python、平台、CPU 数及 UTC 时间。
- `run_configuration`：种子、选配模型。
- `sources`：资料性质与实际运行类别。
- `parameters_changed`：训练参数是否实际改变；具体前后值或哈希在各实验内容内。
- `checks`、`all_checks_passed`：核验名称、依据及结果。
- `limits`：本实验尚不能证明的能力边界。
- `seconds`：本次完整实验实际耗时；不同电脑数值不同。

## 八组实验

| 实验 | 真正运行的内容                                   | 学生重点检查                                         |
| ---- | ------------------------------------------------ | ---------------------------------------------------- |
| L1   | 解析梯度线性回归、有限差分、自动求导 XOR 网络    | 梯度误差、整批损失、参数更新、过大学习率失败         |
| L2   | BPE、小型完整因果 Transformer 训练与自回归生成   | 交叉熵、延迟复制、因果遮挡、注意力归一化、检查点重载 |
| L3   | 两动作策略梯度、DPO 参数更新、固定参数候选选择   | 哪个步骤改参数、哪个步骤只花推理预算、验证器漏洞     |
| L4   | 二维条件 Flow Matching 网络真实训练与 Euler 采样 | 时间输入、目标速度、留出损失、条件均值、步数与方差   |
| L5   | BM25 基线、真实训练的微型双编码检索、带来源抽取  | 排名、来源、无答案、冲突；核心答案模式是 extractive  |
| L6   | 真训练的三个动作分类策略、实际文件读取与计算执行 | 模型选动作、规则取参数、执行器权限、预算、结束断言   |
| L7   | 训练小线性网络、真实 int8 序列化/整数累加、LoRA  | 文件字节数、误差、冻结参数、适配前后留出误差         |
| L8   | 组合资料系统、固定回归集、基线与消融             | 固定文件哈希、每题状态与引用、失败分布、消融作用     |

L2 的词表为 `^abcd?;`。训练串形如 `^a?a;`。模型需在 `^a?` 之后输出 a，在 `^b?` 之后输出 b；最后一个词元相同，目标不同，因而不能仅靠 bigram 计数完成。整个任务仍很小：训练后的复制表现不等于会自然语言对话，生成探针也不是未知语义泛化测试。最终 FFN 使用 tanh，其他 Transformer 关键路径在源码中完整保留，便于检查。

L4 学习的是均值为 `(2*c,0)`、标准差 0.3 的二维条件分布。图文特征匹配示例为明确给定的构造向量，未声称训练了 CLIP。音视频和前沿模型能力另在课程中按来源分析。

L5 的复测查询使用与训练不同的字符串，但共享教学主题与词汇；不能把它称作陌生领域泛化。核心生成器是来源抽取，拒答与冲突策略是公开规则。语言模型生成只有下文明确选择的分支才会发生。

回答器只读传入排名中的记录，不从全库补回漏召回来源。移除必要记录后可能无证据；只检到冲突的一方时也不会凭空补另一方。这正是需要独立测检索召回和证据覆盖的原因。

L6 的核心是狭窄的学习策略：动作类型由学得的 softmax 权重选择，状态文字、文件名和数值参数解析由控制程序给出。它真实训练和推断，但不冒充通用大模型智能体。恶意请求测试直接挑战执行器，不能据此证明模型免疫所有注入。

L7 比较的是实际序列化存储和本次 Python 耗时；int8 占用更少不代表 Python 循环更快。LoRA 的构造目标本来就是 rank 1，结果不能推广到所有任务。KV 数字是公式计算，未称为已分配的进程内存。

L8 的 `data/frozen_cases.json` 是公开的固定回归规格。源码保存其 SHA256，运行前后检查不变；发布时内容已经可见，不能称为开发者从未看过的隐藏能力评测。教师需另设未公开的陌生迁移题和个人答辩。

## 图像、声音与运动材料

以下输入均由 make_media.py 用标准库生成，真值在 data/media-truth.json。运行 `python3 -B make_media.py` 可重建；它们不是模型输出。

| 文件                                                                                                 | 使用方式与边界                                                                                             |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| [vision-cards.svg](/ai-labs/data/vision-cards.svg)                                                   | 对比形状计数、文字和遮挡。图 B 中隐藏的内容不能仅凭可见像素完整恢复。                                      |
| [audio-clean.wav](/ai-labs/data/audio-clean.wav) 与 [audio-noisy.wav](/ai-labs/data/audio-noisy.wav) | 单声道、16 kHz、16 bit、1 秒、440 Hz 合成音调与加噪版本。用于采样和噪声分析；不是自然语音或 ASR 识别结果。 |
| [motion-frames.svg](/ai-labs/data/motion-frames.svg)                                                 | 两行人为帧序列，B 的第四帧改变颜色，供检查身份一致性。不是视频或世界模型生成结果，也不能证明物理模拟正确。 |

可以直接用浏览器看 SVG、播放 WAV，再用 Python 的 wave、struct、json 读取和核对。大型语音、视觉和世界模型的能力分析须另看课程提供的一手案例。

`practice.py media` 实际分析两份 WAV 的采样率、时长、负载、RMS 和有干净参考的信噪比；另训练第 24 单元位置—速度环境的系数，在未参与训练的动作上滚动预测。图像与 SVG 仍是构造输入，不能将这些分析称为运行了通用语音或视频模型。

## 监督、记忆与修复补充任务

`practice.py sft` 从随机初始化的微型 Transformer 训练，只在复制回答和结束位置计损失，保存移位目标、位置掩码、真实损失与参数；它不是通用预训练模型的微调。请求位置没有直接目标损失，但共享参数仍可能通过上下文接收梯度。

`practice.py memory` 演示单写入者的读最新、版本校验、合并、读回和下一任务键检索。T1/T2/T3 均为构造通知；没有更新模型参数，也未实现多进程事务。

`data/coding` 是平均值修复任务，含故意错误的 average.py、四项契约测试和教师参考实现。先将目录复制到独立工作目录，在副本运行 `python3 -B -m unittest -v test_average.py`，保存预期失败；修改 average.py 后再运行。不要把任务基线的故意失败当作实验包回归失败。

## 可选：实际本地预训练模型

核心八实验不依赖此项。如果教师已准备合法、匹配硬件且安装好的 Ollama 模型，可在 L5、L6 添加：

```sh
python3 -B ai_lab.py l5 --output ./runs/l5-local --seed 42 --local-model deepseek-r1:7b
python3 -B ai_lab.py l6 --output ./runs/l6-local --seed 42 --local-model deepseek-r1:7b
python3 -B practice.py probe --output ./runs/probe --model deepseek-r1:7b
```

程序只请求 `http://127.0.0.1:11434/api/generate`，禁止环境代理转发，显式 `num_gpu:0`、上下文 1024、最多生成 96 个词元、JSON 格式和 180 秒超时。不自动启动服务、下载模型或切换到云服务。模型名称只是已安装实例的选择参数，不能说明每台学生电脑都已具有它。

本地调用的原始请求和返回原样保留。L5 需要字符串来源 ID；数字引用、未知来源、错误 JSON 都会留下校验失败，不能静默纠正后宣称成功。校验格式与来源存在并不证明回答事实正确。L6 让真实语言模型选择工具，执行器继续独立校验路径、类型和预算。模型调用失败时记录失败，没有脚本回答兜底冒充模型输出。

制作机核验实例为 Ollama 0.40.6、deepseek-r1:7b Q4_K_M，权重摘要在 environment.json；探针保存运行时、已安装实例、原始调用与载入状态。此包不分发通用权重或运行时，学生电脑仍需单独诊断。没有未量化版本的对照时，不声称完成通用模型量化前后比较。

## 修改与交付

源码允许导入，`main()` 有独立入口保护。可以修改学习率、网络规模、训练数据、候选预算及语料，但应保留原种子基线，比较改变前后结果与成本。不要为得到通过输出而修改检查条件。

需交出自己运行的 JSON、参数/状态解释、一处失败或反例、一个未照搬原题的变式。测试通过证明这些明确条件下的程序行为；课堂使用效果、学生理解与陌生迁移需另行检验。

仓库维护者更新材料后运行 `python3 -B scripts/package-ai-labs.py`（仓库根目录），再用同命令加 `--check` 核对源码哈希、ZIP 条目与 CRC。ZIP 固定条目时间，不含本机运行记录、模型权重或依赖缓存。
