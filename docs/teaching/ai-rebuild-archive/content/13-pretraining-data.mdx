# 13｜预训练的数据与目标

把公开网页都下载后训练，是否一定比用少量整理材料更好？如果测试题和答案已经在训练文本里，模型得高分可能只是重现。如果正文乱码、广告重复、时间标签混乱，更多词元也可能增加错误信号。预训练的数据工程决定模型反复学习的分布。

## 自监督不等于没有监督目标

下一词元目标由文本自动生成，所以称自监督；它仍明确奖励对训练文本后续词元的预测。模型会学到语言结构、关联、代码模式和部分知识，也可能学到材料中的错误与偏见。目标不是“每个事实都经过查证”，更不是“像网页那样写就一定正确”。

本课给定六条教学记录：A“水在特定条件下会结冰”；B 与 A 完全相同；C“水 在 特定条件下 会结冰”；D“会员广告会员广告”；E“测试题：2+3=5”；F“测试题：2 + 3 = 5”。先把 E、F 定为评测材料，再检查其他数据；如果先随机切分再去重，近似重复可能一份进训练、一份进测试。

## 一个可解释的数据流水线

| 步骤       | 本例处理                    | 需要记录的副作用           |
| ---------- | --------------------------- | -------------------------- |
| 来源登记   | 保存来源、版本、可用范围    | 公开可见不等于可任意使用   |
| 规范化     | 统一换行、明显空白          | 代码缩进和诗歌格式可能重要 |
| 精确去重   | A、B 只留一份               | 是否删除引用与来源关系     |
| 近似检查   | C 与 A、E 与 F 标为候选重复 | 语义相似不保证完全等价     |
| 质量规则   | 标记重复广告 D              | 方言、短文本可能被误伤     |
| 分组切分   | 同来源或同题家族放一起      | 与部署分布是否一致         |
| 混合与采样 | 按任务设定抽样比例          | 小语种或专业文本是否被稀释 |

一个可运行的简单去重键是去掉空格后的字符串；它可发现 C，却也可能把本来不同的代码压成一样。教学中先用简单规则看见收益，再构造误伤反例，才有理由引入更精细处理。对每一步保存保留数、删除数和样例，而不是只宣布“数据已清洗”。

## 混合比例改变训练关注

假设语料包含通用文本 80 条、代码 20 条。均匀按条抽样时，代码占 20%；若每轮人为抽通用 50 条、代码 50 条，代码梯度影响会增加，但样本重复率也增加。重复训练不等于获得新信息，过度采样可能使小集合被记住。不同长度记录还会导致按条比例与按词元比例不同，必须说明分母。

合成数据由模型或程序生成，可以覆盖特定任务和补充格式。但如果教师模型重复同一错误，学生会系统继承；若用同一模型生成题和判答案，错误可能互相掩盖。对于算术或代码，应尽可能用独立程序核验；对开放解释，仍需人工或可靠来源审查。

## 记忆、泛化与污染怎样区分

逐字复现训练段落说明模型能保留模式，不证明它能解决新问题。将数字、变量名、问法或组合条件改变，观察表现，才能检查更广的能力。污染是评测信息进入训练或调参过程，使评测不再独立；不仅是直接看到标准答案，也可能是用最终测试反馈反复挑提示。

教师让学生先不看标签，设计去重与质量规则，再揭示哪些是代码、哪些是自然语言。学生产物包括原始记录、规则、处理结果、被误删样例和冻结测试。不得把课程自造文本称为真实互联网分布。

## 学生任务：清洗也会犯错

给定 `print("a b")` 和 `print("ab")`，若去除所有空格再去重，会发生什么？再给 `答案：5`、`答案： 5`，同一规则是否有用？请提出兼顾两种材料的处理策略。

<summary>提示一：空格是不是内容的一部分</summary>

代码字符串里的空格会改变输出；普通排版空格可能只是格式。按文件或字段类型处理，比全库一刀切更合理。

</details>

<summary>提示二：将“候选相同”与“确定删除”分开</summary>

可以先生成规范化键找候选，再比较原文、类型与来源；保留删除理由，允许回查。

</details>

<details>
<summary>完整解析与验收</summary>

第一对程序会被错误合并，却分别打印 `a b` 与 `ab`；第二对可视为排版差异。可对自然语言字段规范空白，对代码用保守规则并保护字符串。验收要求提交至少一条保留、一条删除、一条转人工检查的例子。

## 独立变式

测试集一共 100 题，发现其中 30 题与训练近似重复，应直接扣掉 30 分吗？先独立提出复评方案。

<details>
<summary>独立完成后核对</summary>

应报告污染范围，隔离相关题，建立新的未见题或按题族重新切分，再对固定方案复测；不能机械扣分，因为每题难度与污染影响不同。旧成绩应标明条件受损，不能冒充独立能力估计。

</details>
