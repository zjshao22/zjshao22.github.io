# 现代人工智能：原理、系统与前沿

一个会回答、查资料、看图和使用工具的系统，内部到底发生了什么？这门课从具体任务出发，沿输入表示、参数学习、内容生成、知识接入、行动执行和结果核验逐步拆开。面向有计算机与 Python 基础、尚未接触 AI 的学习者；数学随问题补齐，不要求先掌握深度学习框架。

40 个知识单元不等于 40 个课时。先预测、再复算或运行，随后解释反例并完成陌生变式。没有 GPU 和模型 API 也能完成八组 CPU 核心实验；微型训练与大型前沿案例分别标明范围。

## 动手路径

先完成 [环境、下载与运行](/docs/ai/lab-00-environment)，再随相关单元进入实验：

1. [L1 模型真的学到了什么](/docs/ai/lab-01-learning)：参数、梯度与泛化。
2. [L2 从词元到生成](/docs/ai/lab-02-token-to-generation)：完整微型 Transformer。
3. [L3 反馈、验证与推理预算](/docs/ai/lab-03-feedback-and-budget)：监督、偏好和推理对照。
4. [L4 多模态与生成机制](/docs/ai/lab-04-multimodal-generation)：速度场、信号和状态预测。
5. [L5 带来源的资料问答](/docs/ai/lab-05-retrieval-and-sources)：检索、冲突和拒答。
6. [L6 受限工具、记忆与修复](/docs/ai/lab-06-tools-and-memory)：执行、读回和测试。
7. [L7 资源与适配对照](/docs/ai/lab-07-resources-and-adaptation)：int8、KV 和 LoRA。
8. [L8 综合项目与独立复测](/docs/ai/lab-08-project-and-defense)：基线、消融和答辩。

[下载完整实验包](/ai-labs/ai-cpu-labs.zip)。包内数据为明确构造的教学材料，自己的运行日志才是本次实验证据。

## 怎样判断学会了

每个单元都给出具体问题、朴素方案及其缺陷、机制与状态推演、学生任务、三级提示和独立变式。第一次先不展开提示，保留预测；需要时逐级查看，最后核对验收。完成作品、运行通过、个人能解释和能独立迁移分别检查。
