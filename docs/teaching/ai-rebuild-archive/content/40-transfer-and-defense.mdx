# 40｜独立解释、迁移与答辩

项目能运行，不代表每位成员都理解每一步；讲过一个公式，也不代表换数字后能复算。本单元用个人解释、现场变式与延迟回顾检验这些不同层次。AI 可以辅助制作，答辩时须分清自己完成、借助工具完成和仍不能解释的部分。

## 第一轮：沿一次真实输出解释

教师从学生提交的日志挑一条，要求不靠现成提示说明：输入怎样编号或表示，哪些参数在本次改变，材料来自何处，工具实际执行了什么，核验为何通过。学生可以查看自己的原始日志和代码，但不能只复述“这里调用模型”。

以资料问答为例，学生应能从问题追到排名，再到实际上下文与引用；若模型输出含来源编号，要检查支持句而非只检查编号存在。若说进行了训练，应指出更新前后参数或哈希与损失；若只改上下文，应明确参数未更新。

## 第二轮：现场改变一个条件

教师从下表选题，先要求预测，再允许运行。具体新数值和题面课堂临时决定，表内只是题型。

| 变式类型             | 学生先预测                   | 再交出的核验                   |
| -------------------- | ---------------------------- | ------------------------------ |
| 新资料与冲突         | 哪段应被检到、何时应拒答     | 排名、实际材料、回答和来源     |
| 遮挡或生成策略变化   | 哪些位置可见、分布如何改变   | 中间概率、固定种子与输出       |
| LoRA rank 或数据变化 | 参数量、表达限制与过拟合线索 | 更新记录与留出误差             |
| 工具越权与预算       | 校验应在哪里拒绝             | 原始动作、拒绝原因、实际状态   |
| 记忆更正与过期       | 当前有效记录是哪条           | 写前版本、合并、读回与后续使用 |

不要求每次预测都正确。预测错后能定位原因，和事后复制正确输出不同；保留最初预测和修订解释。若运行失败，先区分环境、程序、模型与任务定义，不能立即删除失败文件重来。

## 第三轮：阅读未讲过的报告

教师给一份新的模型卡或论文摘要，附足够来源信息；学生按第 37 单元六列表提取机制和证据。至少写一项未披露内容、一项不能由现有证据推出的结论，以及一个可反驳过强主张的测试。阅读题不依赖购买 API 或下载大型权重。

一个合格回答例如：“文档只声明接收图像并输出文本；没有证据表明能生成图像。我会查输出模态与样例，而不是从多模态三个字推断。”这里看的是证据使用能力，不要求猜出厂商未公开的细节。

## 用可观察标准记录学习状态

| 维度       | 尚需支持       | 达到本课验收             | 可进一步迁移           |
| ---------- | -------------- | ------------------------ | ---------------------- |
| 机制解释   | 只报术语       | 指出输入、状态变化与输出 | 能解释陌生反例         |
| 实验复现   | 只能复制参考值 | 自己运行并核对配置       | 能诊断更换环境后的问题 |
| 证据与边界 | 把演示当保证   | 对应来源和限定条件       | 设计有区分力的新测试   |
| 系统实现   | 只看最终文字   | 追到检索、工具、日志     | 独立定位跨组件失败     |

这是一份课程验收建议，不是已经观察到的学生表现。教师分别记录独立完成、提示后完成和未完成；不要把集体项目成功率写成每个人掌握率。若需成绩权重，由任课教师根据课程要求确定。

## 延迟回顾与接续

在一次后续课堂中，短暂闭卷回顾四个问题：训练和上下文改变什么；下一词元概率如何得到；检索与回答失败怎样区分；工具权限由谁执行。先独立作答，再开放分层提示。正文与原日志保留，回顾记录单独用于比较延迟保持。

教师收取个人答辩表，学生写下一个已解决问题、一个仍需验证问题和下一步可运行实验。完成设计不等于已授课，运行通过不等于学生已经掌握；证据链应让后来的人知道当前究竟到哪一步。

## 学生任务：判断三种“完成”

A 小组程序按公开七题全部通过；B 同学在提示下复算出注意力；C 同学在未见资料变式中独立定位漏召回。各支持什么结论，还不能支持什么？

<details>
<summary>提示一：把对象和条件写全</summary>

分别是程序、小组或个人；分别是公开题、提示后计算或独立迁移。

</details>

<details>
<summary>提示二：不要跨越证据层次</summary>

A 是当前规格下的工程结果，B 是有支持条件的学习表现，C 是这一次陌生任务中的独立表现。

</details>

<details>
<summary>完整解析与验收</summary>

三项都应如实记录。A 不证明全组每人掌握，B 不证明闭卷独立复算，C 也不证明所有未来任务均能处理。合格答案既不夸大，也不抹去已有证据。

</details>

## 独立变式

第二周同学忘记公式，却能从数组和程序重新推导。如何判断学习状态？

<details>
<summary>独立完成后核对</summary>

记录其能否独立恢复定义、检查维度、给出正确中间状态并解释边界；背诵和重建是不同证据。仍需在适合课程目标的新问题中检验，而非只按是否记住原句判断。

</details>
