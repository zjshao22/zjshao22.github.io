#### 2. 设计与建立四张基准表（20分）

在 Workbench 表设计器（Table Editor）中配置字段属性与主外键引用：

<WorkbenchTableEditorFigure />

四表完整标准 DDL 语句：

```sql
-- 1. 学生表 t_student
CREATE TABLE IF NOT EXISTS t_student (
  sid CHAR(10) NOT NULL COMMENT '学号，主键',
  sname VARCHAR(10) NOT NULL COMMENT '姓名',
  sex CHAR(1) NULL COMMENT '性别',
  age INT NULL COMMENT '年龄',
  major VARCHAR(20) NULL COMMENT '专业',
  PRIMARY KEY (sid),
  CHECK (age >= 0 AND age <= 120)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. 教师表 t_teacher
CREATE TABLE IF NOT EXISTS t_teacher (
  tid CHAR(10) NOT NULL COMMENT '工号，主键',
  tname VARCHAR(10) NOT NULL COMMENT '姓名',
  age INT NULL COMMENT '年龄',
  title VARCHAR(20) NULL COMMENT '职称',
  PRIMARY KEY (tid),
  CHECK (age >= 18 AND age <= 100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 3. 课程表 t_course（外键 tid 引用 t_teacher）
CREATE TABLE IF NOT EXISTS t_course (
  cid CHAR(10) NOT NULL COMMENT '课程号，主键',
  cname VARCHAR(20) NOT NULL UNIQUE COMMENT '课程名，唯一值',
  tid CHAR(10) NULL COMMENT '工号，外键',
  PRIMARY KEY (cid),
  CONSTRAINT fk_course_teacher
    FOREIGN KEY (tid) REFERENCES t_teacher(tid)
    ON UPDATE CASCADE ON DELETE RESTRICT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 4. 选课表 t_student_course（联合主键 sid + cid）
CREATE TABLE IF NOT EXISTS t_student_course (
  sid CHAR(10) NOT NULL COMMENT '学号，外键',
  cid CHAR(10) NOT NULL COMMENT '课程号，外键',
  score INT NULL COMMENT '成绩，允许为空',
  PRIMARY KEY (sid, cid),
  CONSTRAINT fk_sc_student
    FOREIGN KEY (sid) REFERENCES t_student(sid)
    ON UPDATE CASCADE ON DELETE CASCADE,
  CONSTRAINT fk_sc_course
    FOREIGN KEY (cid) REFERENCES t_course(cid)
    ON UPDATE CASCADE ON DELETE RESTRICT,
  CHECK (score >= 0 AND score <= 100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

- **第 1 题：根据个人学号查询个人信息（查询前置任务 1 插入的本人记录）**

  ```sql
  SELECT tname, age FROM t_teacher WHERE title = '副教授' AND age BETWEEN 30 AND 35 ORDER BY age DESC;
  ```

- **第 6 题：查询所有学生的学号，姓名和性别，将查询结果插入到新表 `t_sinfo` 中**

  ```sql
  CREATE TABLE t_sinfo AS
  SELECT sid, sname, sex FROM t_student;
  -- 核验新表：
  SELECT * FROM t_sinfo;
  ```

- **第 7 题：查询有同学选修的课程的课程号及课程名（预期 4 门：c001, c002, c003, c008）**
  ```sql
  SELECT DISTINCT c.cid, c.cname
  FROM t_course c
  JOIN t_student_course sc ON c.cid = sc.cid;
  ```
- **第 8 题：查询李平同学所选修课程的课程号，课程名和成绩（预期 2 行）**
  ```sql
  SELECT c.cid, c.cname, sc.score
  FROM t_student s
  JOIN t_student_course sc ON s.sid = sc.sid
  JOIN t_course c ON sc.cid = c.cid
  WHERE s.sname = '李平';
  ```
- **第 9 题：查询选修了数据库课程但成绩为空的学生的姓名（预期 2 人：李勇、李华）**
  ```sql
  SELECT s.sname
  FROM t_student s
  JOIN t_student_course sc ON s.sid = sc.sid
  JOIN t_course c ON sc.cid = c.cid
  WHERE c.cname = '数据库' AND sc.score IS NULL;
  ```
- **第 10 题：查询既选修了 C001 号课程，又选修了 C002 号课程的学生的学号（预期 1 人：2012001）**
  ```sql
  SELECT sid FROM t_student_course
  WHERE cid = 'c001' AND sid IN (
    SELECT sid FROM t_student_course WHERE cid = 'c002'
  );
  ```
- **第 11 题：查询李平同学选修的课程门数以及平均成绩（预期 2 门，79.0 分）**
  ```sql
  SELECT COUNT(*) AS course_count, AVG(sc.score) AS avg_score
  FROM t_student s
  JOIN t_student_course sc ON s.sid = sc.sid
  WHERE s.sname = '李平';
  ```
- **第 12 题：查询年龄比李平同学大的所有学生的学号，姓名和年龄（李平27岁，预期 8 人）**
  ```sql
  SELECT sid, sname, age FROM t_student
  WHERE age > (SELECT age FROM t_student WHERE sname = '李平');
  ```
- **第 13 题：查询每个专业的学生人数，显示“专业”和“人数”两列**
  > **数据状态差异**：状态 A 原始基线包含 4 个专业与 1 组 NULL；状态 B 插入陈雷后新增“计算机科学与技术：1人”，共 6 组。
  ```sql
  SELECT major AS 专业, COUNT(*) AS 人数
  FROM t_student
  GROUP BY major;
  ```
- **第 14 题：查询选课人数超过 5 人的课程信息，要求显示课程号，课程名和选修人数**
  > **预期结果**：预期 2 门课程满足条件（`c008 计算机基础` 选修 10 人，`c003 软件测试` 选修 9 人）。
  ```sql
  SELECT c.cid, c.cname, COUNT(sc.sid) AS 选修人数
  FROM t_course c
  JOIN t_student_course sc ON c.cid = sc.cid
  GROUP BY c.cid, c.cname
  HAVING COUNT(sc.sid) > 5;
  ```
- **第 15 题：查询没有选修数据库课程的学生的学号**
  > **数据状态差异**：状态 A 原始基线为 8 人；状态 B 插入陈雷后（陈雷未选课），未选数据库人数变为 9 人。
  ```sql
  SELECT sid FROM t_student
  WHERE sid NOT IN (
    SELECT sc.sid
    FROM t_student_course sc
    JOIN t_course c ON sc.cid = c.cid
    WHERE c.cname = '数据库'
  );
  ```

### 三、实验二标杆全案示范（以图书管理系统为例）

#### 1. 概念设计文字表达规范

- **出版社实体**：出版社名（主键/标识）、地址、电话、Email。
- **借书人实体**：借书证号（主键/标识）、姓名、单位。
- **图书实体**：书号（主键/标识）、书名、数量、位置。
- **联系与基数**：出版社与图书存在 1:N 出版联系；图书与借书人存在 M:N 借阅联系，借阅联系包含联系属性“借阅时间”。

#### 2. 逻辑结构设计与 3NF 规范化推导

1. `出版社(出版社名, 地址, 电话, Email)`，主键：`出版社名`。
2. `借书人(借书证号, 姓名, 单位)`，主键：`借书证号`。
3. `图书(书号, 书名, 数量, 位置, 出版社名)`，主键：`书号`，外键：`出版社名` 引用出版社表。
4. `借阅(借书证号, 书号, 借阅时间, 归还时间)`，联合主键：`(借书证号, 书号, 借阅时间)`。
   - **联合主键解析**：同一读者可在不同日期重复借阅同一本书，故必须将借阅时间纳入主键。

- **3NF 证明**：每个属性均为单值不可拆分的原子项（满足 1NF）；所有非主属性均完全函数依赖于候选键，无部分依赖（满足 2NF）；不存在非主属性对码的传递函数依赖（满足 3NF）。

#### 4. 实验二问答题（10分）

1. **试描述将 ER 图转换为关系模式的一般规则（5分）**：
   - **实体转换**：一个实体型转换为一个关系模式。实体的属性即为模式的属性，实体的码即为模式的主键。
   - **1:1 联系**：可转换为一个独立模式，也可以与任意一端合并。若合并，应将另一端的主键及联系属性加入到被合并端作为外键；**特别注意：外键列必须声明 `UNIQUE` 唯一约束**，防止基数退化为 1:N；若该端为强制参与则外键加 `NOT NULL`，可选参与则允许为 `NULL`。
   - **1:N 联系**：可转换为一个独立模式，但通常合并到**N 端实体对应的关系模式**中。方法是将 1 端实体的主键及联系属性加入到 N 端模式中，作为 N 端的外键。
   - **M:N 联系**：必须转换为一个**独立的关系模式**。该模式的属性为两端实体的主键与联系本身的属性，其主键为两端实体主键组合而成的**联合主键**。
2. **针对撰写设计文档中遇到的问题阐述心得体会（5分）**：

```javascript
// server.mjs - 最小可运行教师成绩管理全栈服务（带 Token 会话鉴权与权限隔离）
import express from "express";
import mysql from "mysql2/promise";
import crypto from "node:crypto";

const app = express();
app.use(express.json());
app.use(express.static("public"));

const pool = mysql.createPool({
  host: "localhost",
  user: "root",
  password: "your_password", // 请替换为本地实际密码
  database: "teachingdb_chen",
  waitForConnections: true,
  connectionLimit: 10,
});

// 服务端内存会话存储：Map<sessionToken, { tid, tname, title }>()
const activeSessions = new Map();

// 统一身份认证中间件：提取 Bearer Token，拒绝客户端伪造身份
function requireAuth(req, res, next) {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith("Bearer ")) {
    return res.status(401).json({ error: "未提供有效身份凭证，请先登录系统" });
  }
  const token = authHeader.slice(7).trim();
  const session = activeSessions.get(token);
  if (!session) {
    return res.status(401).json({ error: "会话已过期或无效，请重新登录" });
  }
  req.currentTeacher = session; // 注入服务端验证后的安全教师上下文
  next();
}

// 1. 教师登录（密码凭据校验 + 颁发会话 Token）
app.post("/api/login", async (req, res) => {
  const { tid, password } = req.body;

  // 教学系统默认密码验证（可扩展比对哈希）
  if (!password || password !== "123456") {
    return res.status(401).json({ error: "登录密码错误（教学系统默认密码: 123456）" });
  }

  const [rows] = await pool.execute(
    "SELECT tid, tname, age, title FROM t_teacher WHERE tid = ?",
    [tid],
  );
  if (rows.length === 0) {
    return res.status(401).json({ error: "教师工号不存在" });
  }

  const teacher = rows[0];
  const token = crypto.randomUUID();
  activeSessions.set(token, teacher);

  res.json({ token, teacher });
});

// 2. 教师安全注销
app.post("/api/logout", requireAuth, (req, res) => {
  const token = req.headers.authorization.slice(7).trim();
  activeSessions.delete(token);
  res.json({ success: true, message: "已安全退出系统" });
});

// 3. 获取该教师承担的课程列表（强制取自 req.currentTeacher.tid）
app.get("/api/courses", requireAuth, async (req, res) => {
  const tid = req.currentTeacher.tid;
  const [rows] = await pool.execute(
    "SELECT cid, cname FROM t_course WHERE tid = ? ORDER BY cid",
    [tid],
  );
  res.json(rows);
});

// 4. 查看主讲课程的选课花名册与成绩（双重校验 tid 与 cid）
app.get("/api/scores", requireAuth, async (req, res) => {
  const tid = req.currentTeacher.tid;
  const { cid } = req.query;
  const sql = `
    SELECT c.cid, c.cname, s.sid, s.sname, s.sex, s.age, s.major, sc.score 
    FROM t_course c
    JOIN t_student_course sc ON c.cid = sc.cid
    JOIN t_student s ON sc.sid = s.sid
    WHERE c.tid = ? AND c.cid = ?
    ORDER BY s.sid`;
  const [rows] = await pool.execute(sql, [tid, cid]);
  res.json(rows);
});

// 5. 添加选课记录（确保课程归属当前教师）
app.post("/api/add-enrollment", requireAuth, async (req, res) => {
  const tid = req.currentTeacher.tid;
  const { sid, cid } = req.body;
  const [auth] = await pool.execute(
    "SELECT 1 FROM t_course WHERE cid = ? AND tid = ?",
    [cid, tid],
  );
  if (auth.length === 0) {
    return res.status(403).json({ error: "无权为此课程添加选课" });
  }
  try {
    await pool.execute(
      "INSERT INTO t_student_course (sid, cid, score) VALUES (?, ?, NULL)",
      [sid, cid],
    );
    res.json({ success: true });
  } catch (err) {
    res.status(400).json({ error: "添加失败：学号不存在或该学生已选修此课程" });
  }
});

// 6. 删除选课记录（退选，强制校验课程归属）
app.post("/api/delete-enrollment", requireAuth, async (req, res) => {
  const tid = req.currentTeacher.tid;
  const { sid, cid } = req.body;
  const sql = `
    DELETE sc FROM t_student_course sc
    JOIN t_course c ON sc.cid = c.cid
    WHERE sc.sid = ? AND sc.cid = ? AND c.tid = ?`;
  const [result] = await pool.execute(sql, [sid, cid, tid]);
  if (result.affectedRows === 0) {
    return res.status(403).json({ error: "无权退选此记录或记录不存在" });
  }
  res.json({ success: true });
});

// 7. 成绩录入与修改（边界校验 + 归属校验）
app.post("/api/update-score", requireAuth, async (req, res) => {
  const tid = req.currentTeacher.tid;
  const { sid, cid, score } = req.body;
  if (score < 0 || score > 100) {
    return res.status(400).json({ error: "成绩必须在 0 到 100 分之间" });
  }
  const sql = `
    UPDATE t_student_course sc
    JOIN t_course c ON sc.cid = c.cid
    SET sc.score = ?
    WHERE sc.sid = ? AND sc.cid = ? AND c.tid = ?`;
  const [result] = await pool.execute(sql, [score, sid, cid, tid]);
  if (result.affectedRows === 0) {
    return res.status(403).json({ error: "无权操作此课程或记录不存在" });
  }
  res.json({ success: true });
});

app.listen(3000, () => console.log("系统运行于 http://localhost:3000"));
```

```python
# grade_system_gui.py - Python Tkinter 原生桌面 GUI 客户端（带口令认证与数据范围隔离）
import tkinter as tk
from tkinter import ttk, messagebox, simpledialog
import pymysql

DB_CONFIG = {
    "host": "localhost",
    "user": "root",
    "password": "your_password", # 请替换为您本地真实的 MySQL root 密码
    "database": "teachingdb_chen",
    "charset": "utf8mb4"
}

class GradeSystemApp:
    def __init__(self, root):
        self.root = root
        self.root.title("学生成绩管理系统 · 教师端 (Python 原生 GUI)")
        self.root.geometry("860x540")
        self.teacher = None
        self.show_login_frame()

    def get_conn(self):
        return pymysql.connect(**DB_CONFIG, cursorclass=pymysql.cursors.DictCursor)

    def show_login_frame(self):
        self.teacher = None  # 注销退出时清空当前教师身份上下文
        if hasattr(self, "main_frame"):
            self.main_frame.destroy()

        self.login_frame = ttk.Frame(self.root, padding=30)

        ttk.Label(self.login_frame, text="任课教师身份登录", font=("Helvetica", 16, "bold")).grid(row=0, column=0, columnspan=2, pady=15)
        ttk.Label(self.login_frame, text="教师工号 (tid):").grid(row=1, column=0, sticky="e", pady=5)
        self.tid_entry = ttk.Entry(self.login_frame, width=20)

        ttk.Label(self.login_frame, text="登录密码:").grid(row=2, column=0, sticky="e", pady=5)
        self.pwd_entry = ttk.Entry(self.login_frame, width=20, show="*")
        self.pwd_entry.insert(0, "123456")
        self.pwd_entry.grid(row=2, column=1, pady=5)

        ttk.Button(self.login_frame, text="登录进入系统", command=self.do_login).grid(row=3, column=0, columnspan=2, pady=15)

    def do_login(self):
        tid = self.tid_entry.get().strip()
        pwd = self.pwd_entry.get().strip()

        # 凭据校验：教学默认密码 123456
        if pwd != "123456":
            messagebox.showwarning("登录失败", "密码错误！教学模拟系统默认口令为: 123456")
            return

        try:
            with self.get_conn() as conn:
                with conn.cursor() as cur:
                    cur.execute("SELECT tid, tname, age, title FROM t_teacher WHERE tid = %s", (tid,))
                    self.teacher = cur.fetchone()
        except Exception as e:
            messagebox.showerror("连接错误", f"数据库连接失败: {e}")
            return

        if not self.teacher:
            messagebox.showwarning("登录失败", f"工号 {tid} 不存在或无教师权限！")
            return

        self.login_frame.destroy()
        self.show_main_frame()

    def show_main_frame(self):
        self.main_frame = ttk.Frame(self.root, padding=15)
        self.main_frame.pack(fill="both", expand=True)

        # 顶部信息栏
        top_bar = ttk.Frame(self.main_frame)

        cols = ("sid", "sname", "sex", "age", "major", "score", "status")
        self.tree = ttk.Treeview(self.main_frame, columns=cols, show="headings", height=15)

            self.tree.column(c, width=100, anchor="center")

            with conn.cursor() as cur:

                self.courses = cur.fetchall()

        if self.courses:
            self.course_combo["values"] = [f"{c['cname']} ({c['cid']})" for c in self.courses]

            self.tree.delete(item)

            SELECT s.sid, s.sname, s.sex, s.age, s.major, sc.score
            FROM t_course c
            JOIN t_student_course sc ON c.cid = sc.cid
            JOIN t_student s ON sc.sid = s.sid
            WHERE c.tid = %s AND c.cid = %s
            ORDER BY s.sid

        with self.get_conn() as conn:
            with conn.cursor() as cur:
                cur.execute(sql, (self.teacher["tid"], cid))
                for row in cur.fetchall():
                    score_val = row["score"] if row["score"] is not None else "NULL"
                    st = "已登分" if row["score"] is not None else "待录入"
                    self.tree.insert("", "end", values=(row["sid"], row["sname"], row["sex"], row["age"], row["major"], score_val, st))

    def edit_score(self):

        if not sel: return messagebox.showwarning("提示", "请先在表格中点击选中一名学生！")

                conn.commit()
        messagebox.showinfo("成功", f"学生 {sname} 的成绩已成功更新为 {new_score} 分！")

    def delete_enrollment(self):

        if not sel: return messagebox.showwarning("提示", "请先选中一名要退选的学生！")
        item = self.tree.item(sel[0])["values"]
        sid, sname = item[0], item[1]
        if not messagebox.askyesno("退选确认", f"确定要将学生【{sname}】({sid})从本课程退选吗？该操作将删除该条选课记录！"): return

        cid = self.current_cid()
        with self.get_conn() as conn:
            with conn.cursor() as cur:
                cur.execute("DELETE sc FROM t_student_course sc JOIN t_course c ON sc.cid = c.cid WHERE sc.sid = %s AND sc.cid = %s AND c.tid = %s", (sid, cid, self.teacher["tid"]))
                conn.commit()
        messagebox.showinfo("成功", "已成功退选该学生！")
        self.load_enrollments()

    def add_enrollment(self):
        sid = simpledialog.askstring("添加选课", "请输入待选课学生的学号 (如 2013002):")
        if not sid: return

            with self.get_conn() as conn:

                    cur.execute("INSERT INTO t_student_course (sid, cid, score) VALUES (%s, %s, NULL)", (sid.strip(), cid))
                    conn.commit()
            messagebox.showinfo("成功", "选课记录添加成功！")
            self.load_enrollments()
        except Exception as e:
            messagebox.showerror("添加失败", f"无法添加选课：{e}")

if __name__ == "__main__":
    root = tk.Tk()
```
