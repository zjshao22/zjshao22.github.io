# 函数模块化与变量作用域

一个大型工业软件如果把成千上万行代码全部塞进一个 `main()` 函数中，不仅可读性极差，而且几乎无法排查 Bug 和复用功能。

**函数（Function）** 是 C 语言中实现**模块化程序设计（Modular Programming）**的核心载体。一个函数就是一个完成特定子任务的独立功能模块。

本节深入剖析函数的声明、定义与模块化调用，厘清形参实参“单向值传递”内存模型，掌握数组作为函数参数的指针退化规律，以及局部、全局与 static 变量的作用域与生命周期机制。

---

## 一、函数的定义与声明机制

### 1. 函数的定义规范

函数的完整语法结构如下：

```c
返回值类型 函数名(形式参数列表)
{
    函数体语句;
    return 返回值表达式;
}
```

- **返回值类型**：若函数无需向调用者返回任何结果，必须将返回值类型指定为 **`void`**。
- **return 语句**：不仅用于向调用方回传计算结果，还兼具**立即提前终止当前函数执行**的功能。

### 2. 函数声明（原型声明）的必要性

在 C 语言中，编译器的处理是从上到下顺序扫描的：

- 如果一个被调函数的完整代码写在 `main()` 函数**之后**，那么在 `main()` 之前必须先写一行**函数原型声明（Function Prototype）**，告诉编译器：“后面有一个名字叫这个、接受这些参数、返回该类型的函数，请放心通过语法检查”。

```c
int Max(int x, int y); // 函数声明（必须以分号 ; 结尾）

int main() {
    int m = Max(10, 20); // 正常调用
    return 0;
}

int Max(int x, int y) { // 函数定义
    return (x > y) ? x : y;
}
```

## 二、形参、实参与单向值传递副本机制

这是 C 语言学习中最关键、也是最容易产生误区的心智模型之一：

### 1. 形式参数（形参） vs 实际参数（实参）

- **实参（Actual Argument）**：调用函数时，括号里实际传入的常量、变量或表达式（如 `Max(a, b)` 中的 `a` 和 `b`）。
- **形参（Formal Parameter）**：在函数定义头部声明的变量（如 `int Max(int x, int y)` 中的 `x` 和 `y`）。只有当函数被调用时，系统才会在栈帧中为形参临时分配物理内存。

### 2. 单向值传递机制（Pass-by-value）

> [!IMPORTANT] 核心原则：传参只是复制数值副本！
> 在 C 语言中，普通变量作为实参传递时，系统只是将**实参的值复制了一份副本塞给形参**！
> 形参和实参在物理内存中占据的是**两块完全互不相干的独立内存单元**！
> 函数内部无论怎么修改形参的值，实参本身**绝不会发生任何改变**！

看下面的经典反例：

```c
void try_change(int x) {
    x = 999; // 仅仅修改了形参 x 自己的副本
}

int main() {
    int a = 10;
    try_change(a);
    printf("%d\n", a); // 依然稳稳输出 10！a 毫无变化！
    return 0;
}
```

## 三、实战案例：封装自定义 Max 函数并在主函数中调用

**任务描述**：编写两个数字求最大的函数 `Max`，在主函数中输入 10 个整数，通过循环调用 `Max` 函数求出这 10 个数中的最大值。

### 核心实现代码

```c
#include <stdio.h>

// 两个数求最大的自定义函数
int Max(int x, int y)
{
    int m;
    if (x > y)
        m = x;
    else
        m = y;
    return m;
}

int main()
{
    int a[10];      // 定义含 10 个元素的数组变量
    int i, j, max;

    printf("input 10 numbers:\n");
    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]); // 输入 10 个数组元素的值

    printf("\n");
    max = a[0];             // 初始化 max 为第 1 个元素

    for (j = 1; j <= 9; j++) // 循环调用 Max 依次打擂台比较
        max = Max(max, a[j]); // 调用自定义 Max 函数更新 max

    printf("the max number is %d.\n", max);
    return 0;
}
```

## 四、实战案例：数组作为函数参数计算平均值

在工程开发中，经常需要将连续数据块传递给计算函数：

### 1. 数组传参的特殊本质：指针退化

当把一维数组名作为参数传递给函数时，例如：

```c
float Average(int a[], int n);
```

系统**绝对不会傻傻地把数组里的所有元素都复制一遍**（那将耗费巨大内存与时间）。在 C 语言中，**形参声明为 `int a[]` 本质上就是指针 `int *a`**！传入的仅仅是数组的首元素内存地址！
因为函数内部无法通过 `sizeof(a)` 获知数组的元素个数，所以**必须额外传递一个参数 `n` 表示数组的长度**。

### 核心实现代码

```c
#include <stdio.h>

// 求数组平均值的函数
float Average(int a[], int n)
{
    int i, sum = 0;
    float aver;

    for (i = 0; i < n; i++)
        sum += a[i];

    aver = (float)sum / n;      // 强制类型转换，避免整数除法截断
    return aver;
}

int main()
{
    int i, a[10]; // 定义含 10 个元素的数组变量
    float aver;

    printf("input 10 numbers:\n");
    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]); // 输入 10 个数组元素的值

    aver = Average(a, 10);  // 调用 Average 函数传入数组名与长度 10

    printf("the Average is %f.\n", aver);
    return 0;
}
```

## 五、变量的作用域、存储类别与生命周期

在 C 语言中，变量在什么地方能被访问（作用域），以及在内存中存在多久（生命周期），由其定义位置和存储说明符决定：

| 变量类别                  | 定义位置                   | 存储区域                  | 作用域 (可见范围)                            | 生命周期 (存活时间)                             |
| :------------------------ | :------------------------- | :------------------------ | :------------------------------------------- | :---------------------------------------------- |
| **局部变量 (auto)**       | 函数体或复合语句 `{}` 内部 | **栈区 (Stack)**          | 仅在定义该变量的 `{}` 大括号内部可见         | 进入大括号时创建，离开大括号时立即销毁          |
| **全局变量 (extern)**     | 所有函数体外部             | **静态数据区 (Data/BSS)** | 从定义点开始，整个源文件中的所有函数均可访问 | 伴随整个程序的运行始终存在，程序退出才销毁      |
| **静态局部变量 (static)** | 函数体内部加 `static` 修饰 | **静态数据区 (Data/BSS)** | **仅在定义它的函数内部可见**                 | **贯穿程序运行始终！** 函数退出后其值被完整保留 |

### 核心机制剖析：static 静态局部变量

看这个经典的自增调用示例：

```c
void count_call() {
    static int count = 0; // 只在程序启动时初始化 1 次！
    count++;
    printf("%d ", count);
}

int main() {
    count_call(); // 打印 1
    count_call(); // 打印 2（保留了上次的计数值！）
    count_call(); // 打印 3
    return 0;
}
```

## 六、函数的递归调用与基准出口条件

**递归（Recursion）** 指一个函数在自身函数体内部直接或间接地调用自己。
实现递归必须满足两个铁律：

1. **递归推导公式（Recursive Step）**：将大规模问题分解为相似但规模更小的子问题。
2. **递归出口（Base Case）**：必须有一个无条件返回的边界条件，否则会导致死递归，造成**栈溢出崩溃（Stack Overflow）**！

```c
// 经典递归求解 n 的阶乘 n!
long factorial(int n) {
    if (n <= 1) return 1;          // 递归出口
    return n * factorial(n - 1);   // 递归递推
}
```

## 本节小结与核心要点

1. **不可嵌套定义**：函数之间相互独立，函数内不能定义新函数。
2. **值传递只传副本**：普通形参是实参的独立拷贝，函数内修改不影响外部实参。
3. **数组传参退化为指针**：数组名传参传递的是首地址，必须配合传递数组长度 `n`。
4. **static 变量只初始化一次**：离开函数不销毁，再次调用保留旧值。
5. **递归必须有出口**：缺少基准出口会导致栈溢出（Stack Overflow）。
