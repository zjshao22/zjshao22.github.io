# L5｜带来源的资料问答

对应 25—27、32 单元。资料均为包内虚构校园记录，不代表真实校规。目标是从问题追到实际检索片段、回答与来源，分别解释检索和回答器的失败。

```sh
python3 -B ai_lab.py l5 --output ./runs/l5 --seed 42
```

## 先标相关材料，再看排名

教师给“校园网络报修电话”“图书馆开放时间”“校外停车收费”三类问题。学生先标出相关材料、缺少资料或冲突，再运行 BM25 基线与真实训练的微型双编码检索器。不能用模型排名反过来决定金标准。

输出记录初始排名、训练查询、损失、复测排名、来源与无答案处理。复测字符串没有参与训练，但共享构造主题和词汇，不叫陌生领域泛化。训练只改变检索嵌入；核心回答仍为透明抽取与显式规则。

## 错误必须在实际输入上定位

回答器只使用传入排名所列的记录，不能从全库偷偷找回漏掉的正确来源。若漏掉图书馆冲突通知，它可能只看到一个答案；这属于证据覆盖失败，不能在回答器后面补原文，再宣称检索没有问题。

学生在自己的代码副本中把问题所需记录从传入排名删除，比较答案与来源；再删掉冲突双方之一。第一项应暴露无证据，第二项可能形成不完整的单方回答。解释为何真正的完整系统还须评价召回、日期与来源覆盖，而不仅评价最终句子。

## 可选的本地模型生成另行记录

按[环境页](/docs/ai/lab-00-environment)准备好已有本地模型后，可附加 `--local-model`。此分支提供明确材料、保存原始请求返回，并验证 JSON 与来源 ID；它与核心抽取结果分开存放。格式合格、来源存在仍不能证明答案得到支持，学生要人工核对支持句。

## 学生任务与验收

交出词法/学习检索逐题比较、一个漏召回反例、无答案与冲突处理，以及一条来源支持说明。教师追问“错误发生在排名、上下文还是回答”；学生用实际内容回答，不能只说“模型幻觉”。

把实际排名记录 ID 和最终引用逐项对照；引用不应来自未传入记录。

看到一个说法与查全所有相关说法不同。需要独立评估证据召回，而非要求回答器猜出未见通知。

</details>

<details>
<summary>完整解析与最低验收</summary>

默认核心应报告有依据回答、无证据和冲突；删证据对照则揭示管线缺陷。合格报告区分构造查询词门控、学习排名和来源抽取的职责，不把它们合称通用语义理解。

</details>

## 独立变式

给同一资料加一份有版本日期的更正通知，设计正确回答所需规则，再运行并记录原行为。若当前程序不能按日期消解，诚实报告冲突或补写可测试规则，不能直接把新答案塞进结果文件。
