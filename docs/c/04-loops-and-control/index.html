循环结构与迭代算法

在处理海量数据、数学级数求和、遍历字符数组以及图形绘制时，计算机最大的威力在于能够不知疲倦地重复执行指定操作——这就是循环（Loop）控制结构。

本节深入剖析 C 语言三大循环语句的底层执行时序与判定机制，厘清 break 与 continue 的跳转差异，并通过字符流处理、递推数列累加与嵌套图形打印掌握经典迭代算法。

一、三大循环语句的执行时序与特征对比

C 语言提供了三种形式的循环语句：while、do-while 和 for。

数学规律与状态迭代

观察相邻两项的分数规律：

  • 第 1 项：分子 a1=2a_1 = 2a1​=2，分母 b1=1b_1 = 1b1​=1
  • 第 2 项：分子 a2=3=a1+b1a_2 = 3 = a_1 + b_1a2​=3=a1​+b1​，分母 b2=2=a1b_2 = 2 = a_1b2​=2=a1​
  • 第 3 项：分子 a3=5=a2+b2a_3 = 5 = a_2 + b_2a3​=5=a2​+b2​，分母 b3=3=a2b_3 = 3 = a_2b3​=3=a2​
  • 递推公式：下一项的分子 = 原分子 + 原分母；下一项的分母 = 原分子。
