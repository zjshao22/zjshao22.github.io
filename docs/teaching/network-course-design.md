# 计算机网络：完整课程设计与 AI 制作规则

修订日期：2026-10-14。供教师与课程维护者使用；学生页面只呈现教学内容。

## 本轮范围与课程定位

用户已授权从八节入门单元扩展为完整计算机网络课程，并确认 01、02、03 已向学生讲授，要求保持这三节结构。本轮将三份源文件逐字保留，新增独立回顾页，从 04 起连接完整机制体系。原有 04–08 的封装、字节序、CIDR、最长前缀和 ARP 有合理的推演基础，继续使用；新增内容补齐其前后依赖。

课程形成 **32 个知识章节 + 前三节回顾 + 3 个独立实验**。知识章不等于固定一课时，正式学时、考核权重和学生实验环境仍未给定，不据其他课程推定。当前范围为计算机专业本科网络核心体系，包含新协议及规模化网络的进阶概览；不宣称穷尽所有厂商配置、无线标准版本、研究课题或每一个 RFC。

此前设计只沿第一单元从 1 页扩到 8 页，局部加深了 IPv4 数据平面，未检查完整学科覆盖。原用户要求“易懂”与后来的“丰富翔实、计算机专业大学生”均不能解释为减少深度。此次按学科机制与能力设计，页面数量由内容决定，不再把“八节完整”当成课程完成标准。

## 主教材与取材范围

主教材为 **Computer Networks: A Systems Approach**，**Larry Peterson、Bruce Davie**，使用第六版章节体系的官方开放内容：[在线版](https://book.systemsapproach.org/)、[官方源码](https://github.com/SystemsApproach/book)、[目录](https://github.com/SystemsApproach/book/blob/master/index.rst)。[LICENSE](https://github.com/SystemsApproach/book/blob/master/LICENSE) 为 CC BY 4.0；2026-10-14 核验 [VERSION](https://github.com/SystemsApproach/book/blob/master/VERSION) 为 `6.2-dev`。开放内容持续变化，与商业印刷版不保证同步。

采用该书的系统设计视角：应用需求、直接链路、互联、端到端协议、拥塞、表示、安全与应用共同形成课程骨架。本轮按全书领域检查覆盖，而非仅把原八页反向对应到书中。下面按章节主题映射，不将持续更新的节号当作固定版本保证；后续若规定统一阅读版本，应固定官方提交或标签。

中文正文、校园案例、表格、图示和实验独立制作；无整章翻译或直接搬运教材插图。协议边界由官方 RFC、官方工具文档补充，原始资料链接可在知识处帮助核对，不将教材清单展示在学生页。

## 回顾、提示与评价

前三节回顾在 03 之后单独进入，不移动原文件内容。先收首次解释，再给提示；教师据此补请求/层次/排队的前置误解。每个后续模块开始，用一条前模块的新条件题延迟检查，例如在 ARP 后追问换掩码，在 TCP 后追问丢 ACK，在 TLS 后追问错误主机名。

提示先指条件/字段，再给一处中间状态，最后展开完整解析。记录学生使用过哪级提示；解析后重做算订正。综合评价看机制解释、计算过程、实现与观测、故障证据、陌生迁移，不将多选正确率或页面浏览量替代整体理解。正式考试题型与权重待实际培养要求确定。

## AI 设计、制作、核验与接续

1. 读取最新用户约束、课程原文件、项目记录与适用教学规则；区分当前授权、历史材料与候选建议。
2. 先写覆盖矩阵与能力目标，检查每层、性能、安全和管理是否缺失；再分配页面与实验。
3. 为每项机制找到朴素方案的失败，不从缩写列表开始；给学生完成推演所需的字段、假设和状态。
4. 依据开放主教材与官方规范核对事实。教材提供组织，RFC 提供具体协议边界；内容用原创案例呈现。
5. 实际运行能运行的程序，独立重算算例，检查引用/注册组件、页面链接、折叠解析、移动阅读与投影展示。
6. 按真实课堂反馈返修；未经提供的学生回答或运行结果不补写。仅工具验证不升格为学生掌握或生产部署验证。
7. 保存准确停点，知识库写项目决定与成果入口，详细技术状态留仓库。多人写共享文件时先读最新并合并，写后读回。

课堂最小记录：日期、已讲机制、独立产物与依据、提示后完成情况、误解与订正、当场/延迟/迁移状态、下次准确起点。教师动作是让学生预测、操作、解释、对照；AI 整理这些实际材料，不推定未观察的表现。
