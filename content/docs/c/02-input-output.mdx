# 格式化输入与输出

与某些自带 `print` 语言内置关键字的高级语言不同，**C 语言本身不提供任何输入输出语句**。所有的输入和输出功能全部由 C 标准库函数（通过包含 `#include <stdio.h>`）提供。

其中，最基础也最核心的两个函数是格式化输出函数 **`printf()`**和格式化输入函数**`scanf()`**。

---

## 一、格式化输出函数：printf()

`printf`（Print Formatted）用于将数据按照指定的格式转换为文本字符，并输出到控制台终端。

### 1. printf 的基本语法

```c
printf("格式控制字符串", 输出项1, 输出项2, ...);
```

格式控制字符串包含两类内容：

1. **普通文本字符**：按原样原汁原味地输出（如提示词、标点符号、空格）。
2. **格式转换说明符**：以 `%` 开头，用于指定后续对应输出项的数据类型和显示格式。

### 2. 常用格式转换说明符

|   说明符    | 对应数据类型            | 输出形式与示例                                     |
| :---------: | :---------------------- | :------------------------------------------------- |
| `%d` / `%i` | `int`、`short`          | 有符号十进制整型（如 `100`, `-25`）                |
|    `%c`     | `char`                  | 单个字符（如 `'A'`, `'9'`）                        |
|    `%s`     | 字符串（字符数组/指针） | 连续字符，直到遇到 `'\0'` 终止符                   |
|    `%f`     | `float`、`double`       | 小数形式的浮点数，**默认保留 6 位小数**            |
|    `%lf`    | `double`                | 双精度浮点数（现代 printf 中 `%f` 与 `%lf` 通用）  |
|    `%o`     | 整型                    | **无符号八进制** 形式输出（不带前导 0）            |
| `%x` / `%X` | 整型                    | **无符号十六进制** 形式输出（小写 a-f 或大写 A-F） |
|    `%p`     | 指针变量                | 输出变量在进程虚拟地址空间中的十六进制地址（如 `0x7ffd58`） |
|    `%%`     | —                       | 输出一个纯百分号 `%` 本身                          |

### 3. 宽度与精度修饰符

我们可以通过修饰符对输出的排版布局进行精确控制：

- **`%md`**：设定输出宽度为 `m` 列。若数据位数小于 `m`，则**在左侧补空格（右对齐）**；若超过 `m`，按实际位数完整输出。
- **`%-md`**：设定输出宽度为 `m` 列，**左对齐**，不足部分在右侧补空格。
- **`%.nf`**：控制浮点数输出保留 `n` 位小数（按照四舍五入规则）。
- **`%m.nf`**：同时指定总宽度 `m` 列与保留小数位数 `n`。

```c
float score = 88.5f;
printf("score=%.1f\n", score);  // 输出: score=88.5
printf("%6.2f\n", score);       // 输出: " 88.50" (总宽6列，含小数点共6个字符)
```

## 二、格式化输入函数：scanf()

`scanf`（Scan Formatted）用于从标准输入流（`stdin`，通常为键盘输入，亦可被重定向为文件或管道）读取数据，并按照指定的格式存入变量对应的**内存地址单元**中。

### 1. scanf 的核心语法与地址取地址符 `&`

```c
scanf("格式控制字符串", &变量1, &变量2, ...);
```

<Callout type="error" title="极高频严重错误：绝不能漏写取地址符 &">
`scanf` 的底层工作原理是：它必须知道数据要写到内存中的**哪个具体地址单元**去！
因此，参数列表中必须传入变量的地址（**`&变量名`**），而不是变量的名字！

- 正确：`scanf("%f", &score);` ✔
- 错误：`scanf("%f", score);` ❌（会导致野指针内存非法访问，程序崩溃崩溃 Segmentation fault！）
- **唯一例外**：当读取字符串到字符数组时（如 `char name[20]; scanf("%s", name);`），数组名本身就代表该数组在内存中的首地址，此时**无需加 `&`**！

</Callout>

### 2. 格式控制字符串中的分隔符匹配

`scanf` 的格式字符串中写了什么，用户在键盘上就必须严格敲入对应的字符：

- 若写 `scanf("%d%d", &a, &b);`：两个数字之间可以使用**空格、Tab 键或回车键**作为分隔符。
- 若写 `scanf("%d,%d", &a, &b);`：两个数字之间必须严格输入**英文逗号**（如键盘输入 `10,20`），否则后续变量无法正确识别赋值！

## 三、标准输入缓冲区机制与换行符残留陷阱

几乎每个 C 语言初学者都会遇到一个让人极其抓狂的现象：**为什么第二个输入语句好像被直接“跳过”了？**

我们来看这个经典 Bug 场景：

```c
int age;
char grade;

printf("请输入年龄: ");
scanf("%d", &age);

printf("请输入等级: ");
scanf("%c", &grade); // 致命现象：这一句直接被跳过了，根本没等用户输入！
```

为什么会这样？请看底层标准输入流 `stdin` 的工作原理：

### 1. 产生原因剖析

1. 当程序提示输入年龄时，用户在键盘上敲入 `20` 并按下 **回车键 Enter**。
2. 操作系统将击键输入整行压入标准输入缓冲区 `stdin`，此时缓冲区内有 3 个字符：`'2'`、`'0'`、**`'\n'`（换行符）**。
3. `scanf("%d", &age)` 读走了数字部分 `20`，但**换行符 `'\n'` 被孤零零地留在了缓冲区队列中**！
4. 当程序接着执行 `scanf("%c", &grade)` 时，因为 `%c` 是读取任何字符（包括空白字符和回车），它发现缓冲区里正好有一个现成的 `'\n'`，于是瞬间读走并赋予 `grade`，程序完全不会停下来等待用户键入！

### 2. 两种通用解决方案与适用场景

#### 方案 A：使用 `getchar()` 吸收残留字符

若输入格式严格为“数值后直接紧随回车”，可通过单次 `getchar()` 吸收该换行符：
```c
scanf("%d", &age);
getchar(); // 吸收掉紧随数字后的 '\n'
scanf("%c", &grade); // 正常等待用户输入等级
```
*提示：若数字与换行符之间可能夹带空格或其他多余输入，更严密的做法是循环清空行缓冲：`int c; while ((c = getchar()) != '\n' && c != EOF);`。*

#### 方案 B：在 `%c` 之前添加前导空格跳过空白字符

在 `scanf` 的格式控制符 `%c` 前加上一个空格，表示让 `scanf` 自动跳过输入流前方的所有空白字符（包括空格、Tab 和换行符）：

```c
scanf("%d", &age);
scanf(" %c", &grade); // 注意 %c 前面有一个空格！
```
*注意：若目标业务场景需要将空格字符本身视作有效输入读取，则不能采用方案 B，应使用方案 A 精确控制。*

## 四、字符专用输入输出函数：getchar() 与 putchar()

除了全能的 `printf` 和 `scanf` 之外，C 标准库还提供了轻量高效的单字符输入输出函数：

### 1. `getchar()` —— 从标准输入读取一个字符

- 原型：`int getchar(void);`
- 返回值：成功读取时返回该字符无符号字符形式对应的 `int` 数值；当读取到输入流末尾（EOF）或发生读取失败时返回宏常量 **`EOF`**（C 标准保证其为负整型，常见实现通常为 `-1`）。
- **必须使用 int 接收**：接收 `getchar()` 返回值的变量**必须声明为 `int`** 而不是 `char`！因为若使用 `char`，不仅可能因类型溢出截断导致无法准确比对负数的 `EOF`，还可能在无符号 `char` 平台上引发死循环。
- 经典流式读取范式：
  ```c
  int ch;
  while ((ch = getchar()) != '\n' && ch != EOF) {
      // 循环处理整行字符，遇到换行符或输入流结束时安全退出
  }
  ```

### 2. `putchar(c)` —— 输出单个字符到屏幕

- 原型：`int putchar(int c);`
- 示例：`putchar('A');` 效果完全等价于 `printf("%c", 'A');`，但执行速度更快、开销更小。

## 本节小结与核心要点

1. **库函数性质**：C 语言本身没有 I/O 语句，输入输出依赖 `<stdio.h>`。
2. **printf 默认小数**：`%f` 默认输出 6 位小数；`%.2f` 强制指定保留 2 位小数。
3. **scanf 必须带 &**：普通变量前必须加 `&` 取地址；数组名本身即首地址不需加 `&`。
4. **缓冲区残存回车**：`%d` 读取后遗留的 `\n` 会被后续 `%c` 误读；利用单次/循环 `getchar()` 吸收或 `scanf(" %c")` 前导空格规避。
5. **字符 I/O 利器**：`getchar()` 逐字符读取且用 `int` 接收并处理 `EOF`，`putchar()` 快速单字符输出。
