# 单表查询与题意分析方法

写 SQL 不是背记语法模板，而是**把自然语言描述的业务题意，精确翻译为对集合的数据操作**。许多初学者感到困难，并非不懂 `SELECT` 关键字，而是拿到题目时不知道“第一步该写什么”。

本节我们将确立贯穿全课程的**统一读题六步法**，并在单表查询场景下熟练掌握字段投影、别名指定、区间筛选、模糊匹配、NULL 值逻辑、结果去重、排序及将查询结果物化写入新表。

---

## 一、统一读题六步法

任何一道 SQL 题，动笔前请先在草稿纸或心智中回答以下六个问题：

<SqlOrderFigure />

1. **结果中的一行代表谁？**（确定核心观察对象：是一名学生、一位教师，还是一门课程？）
2. **要输出什么字段，分别来自哪张表？**（确定 `SELECT` 后的投影列与 `FROM` 基表）
3. **表之间按哪些键连接？**（单表查询暂不需要连接；多表时寻找主外键对应）
4. **哪些条件过滤行（WHERE），哪些条件过滤组（HAVING）？**（单表记录直接用 `WHERE` 筛选）
5. **是否涉及 NULL、重复或特殊端点？**（检查 `IS NULL`、`DISTINCT`、闭区间 `BETWEEN`）
6. **结果如何排序，怎样用小数据验证？**（确定 `ORDER BY`，并心算验证预期行数）

## 二、基础语法与核心陷阱剖析

### 1. 投影与列别名（`AS`）

- `SELECT 列1, 列2 FROM 表;` 仅返回关心的列，避免在生产环境中盲目使用 `SELECT *`。
- 可以使用 `AS 新列名` 指定可读中文别名，但在 SQL 执行顺序中，`SELECT` 晚于 `WHERE`，因此**不能在 `WHERE` 条件中直接引用别名**！

```sql
-- 正确：给输出列起友好别名
SELECT sname AS 姓名, age AS 年龄 FROM t_student WHERE sex = '女';

-- 错误写法：在 WHERE 中使用别名（报错 Unknown column '年龄'）
-- SELECT sname, age AS 年龄 FROM t_student WHERE 年龄 > 25;
```

### 2. 区间筛选 `BETWEEN ... AND ...` 的闭区间特性

- `age BETWEEN 30 AND 35` 等价于 `age >= 30 AND age <= 35`。
- 它包含**两个端点值**（30 和 35）。如果题目要求“大于 30 且小于 35”，则不能用 `BETWEEN`，必须使用显式比较符：`age > 30 AND age < 35`。

### 3. 模糊匹配 `LIKE`：`%` 与 `_` 的区别

- `%` 代表**任意长度（包括 0 个字符）** 的任意字符。
- `_`（半角下划线）精确代表**单个字符**。
- 例：`sname LIKE '李%'` 匹配所有姓李的学生（如“李平”、“李勇”、“李娜”、“李华”）；而 `sname LIKE '李_'` 仅匹配姓李且**名字只有两个字**的学生。

### 4. NULL 的三值逻辑与排错

- 在关系数据库中，`NULL` 代表“未知”或“未录入”，它**不等于 0，也不等于空字符串 `''`**。
- 比较运算符（`= NULL` 或 `!= NULL`）的逻辑结果永远是 `UNKNOWN`（假），无法筛出任何数据！
- **语法铁律**：必须使用 `IS NULL` 或 `IS NOT NULL`。

```sql
-- 查出专业尚未确定的学生（例如华宇）
SELECT sid, sname FROM t_student WHERE major IS NULL;

-- 错误写法（永远返回空集）：
-- SELECT sid, sname FROM t_student WHERE major = NULL;
```

### 5. DISTINCT（结果去重）与 UNIQUE（存储约束）辨析

- `DISTINCT` 放在 `SELECT` 之后，是对**查询出来的最终结果集**进行行去重。
- `UNIQUE` 是 DDL 中对表的某列施加的**物理完整性约束**，确保在写入表时不允许插入重复数据。两者所处阶段完全不同。

## 三、【实验一 第二阶段】单表查询上机实战（题 1~6）

完成基础表建立与基线数据导入后，实验一正式进入**单表与基础查询实战阶段**。

请在 **MySQL Workbench**中打开 SQL 编辑器窗口（快捷键 `Ctrl + T` 或 `Cmd + T`），确保左侧 SCHEMAS 中已双击激活个人数据库（呈现加粗高亮），随后逐题输入 SQL 语句，点击工具栏中的**闪电图标（⚡ Execute）**执行，并核对下方**Result Grid**与**Action Output** 输出。

### 题 1：根据个人学号查询个人信息

- **业务对象**：学生个人记录。
- **数据来源**：`t_student` 表。
- **筛选条件**：`sid = '个人实际学号'`（例如第一阶段中插入的个人学号 `2023001` 或已有学号 `2012001`）。
- **预期结果**：精确返回**1 行**，输出学号、姓名、性别、年龄、所在系全部 5 个字段。

```sql
-- 题 1：根据学号查询个人信息
SELECT sid, sname, sex, age, major
FROM t_student
WHERE sid = '2012001';
```

### 题 2：查询所有姓“李”的学生的学号、姓名和年龄

- **业务对象**：所有李姓学生。
- **数据来源**：`t_student` 表。
- **模糊匹配**：`sname LIKE '李%'`（百分号 `%` 匹配任意字数，包含单字名与双字名）。
- **小数据推演**：
  - `2012002` (李平, 27)
  - `2012005` (李勇, 32)
  - `2012007` (李娜, 29)
  - `2013005` (李华, 25)
- **基准预期**：返回**4 行**，字段投影为 `sid, sname, age`。

```sql
-- 题 2：查询姓李的学生信息
SELECT sid, sname, age
FROM t_student
WHERE sname LIKE '李%';
```

### 题 3：查询女同学的姓名和年龄，列名分别指定为“姓名”和“年龄”

- **业务对象**：全体女性学生。
- **数据来源**：`t_student` 表。
- **列别名指定**：使用 `AS 姓名` 与 `AS 年龄` 覆盖默认列头。
- **小数据推演**：
  - 王珊 (25 岁)
  - 周云 (30 岁)
  - 李娜 (29 岁)
  - 杨玲 (28 岁)
  - 李华 (25 岁)
- **基准预期**：返回**5 行**，Result Grid 的列标题显示为自定义中文“姓名”与“年龄”。

```sql
-- 题 3：查询女同学信息并指定列别名
SELECT sname AS 姓名, age AS 年龄
FROM t_student
WHERE sex = '女';
```

### 题 4：查询软件工程专业所有男学生的平均年龄

- **业务对象**：软件工程专业的男学生群体。
- **数据来源**：`t_student` 表。
- **过滤与聚合**：`WHERE major = '软件工程' AND sex = '男'`，对年龄执行聚合 `AVG(age)`。
- **小数据推演**：
  - 李平 (27 岁)
  - 吴军 (33 岁)
  - 王新 (30 岁)
  - 手工计算：$(27 + 33 + 30) / 3 = 30.00$。
- **基准预期**：返回**1 行 1 列**，标量值为 `30.0000`。

```sql
-- 题 4：统计软件工程男学生平均年龄
SELECT AVG(age) AS avg_age
FROM t_student
WHERE major = '软件工程' AND sex = '男';
```

### 题 5：查询年龄在 30 到 35 岁之间的副教授的姓名和年龄，按年龄降序排列

- **业务对象**：符合年龄与职称条件的教师。
- **数据来源**：`t_teacher` 表。
- **条件与排序**：`title = '副教授' AND age BETWEEN 30 AND 35`，降序 `ORDER BY age DESC`。
- **小数据推演**：
  - 刘红 (35 岁)
  - 王海 (34 岁)
  - 张雷 (33 岁)
  - 韩伟 (32 岁)
- **基准预期**：返回**4 行**，年龄由高到低严格排序（35 $\to$ 34 $\to$ 33 $\to$ 32）。

<WorkbenchSingleQueryFigure />

```sql
-- 题 5：副教授年龄区间筛选与降序排列
SELECT tname, age
FROM t_teacher
WHERE title = '副教授' AND age BETWEEN 30 AND 35
ORDER BY age DESC;
```

### 题 6：查询所有学生的学号，姓名和性别，将查询结果插入到新表 `t_sinfo`

- **业务需求**：将查询结果物化保存到新物理表 `t_sinfo` 中。
- **数据来源**：`t_student` 表。
- **物化方式**：`CREATE TABLE ... AS SELECT`。

```sql
-- 题 6：查询结果物化写入新表 t_sinfo
CREATE TABLE t_sinfo AS
SELECT sid, sname, sex
FROM t_student;

-- 执行物化后的数据核验：共 12 行
SELECT * FROM t_sinfo;
```
