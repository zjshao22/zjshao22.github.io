# 计算机网络讲授提示

学生页面按参考讲义第一单元的前半部分组织：网络应用、四层模型、IP 服务与数据报、分组交换、封装。网页、BitTorrent 与 Skype 是原讲义中的对比例子；Skype 的实现描述只作为历史案例使用。

## 讲授重点

- 先让学生说清两个程序怎样交换数据，再引入分层。不要直接让学生背层名。
- IP 的尽力而为是“没有交付保证”，不等于“网络通常不能工作”。
- 路由器逐跳处理网络层信息；链路帧在不同跳可能变化。
- 字节流没有应用消息边界；BitTorrent 文件片段与 IP 数据报不是同一层的单位。

## 检查理解

每节的练习要求学生解释理由。最后的综合任务可检查他们是否能把应用数据、TCP 段、IP 数据报和链路帧正确嵌套，并区分路由器与端点各自的责任。

课程来源：[Stanford Introduction to Computer Networking 讲义镜像](https://github.com/khanhnamle1994/computer-networking)。
