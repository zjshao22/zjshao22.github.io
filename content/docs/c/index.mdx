# C 语言程序设计

C 语言诞生于贝尔实验室，是现代操作系统的基石，也是连接**上层软件逻辑**与**底层硬件物理内存**的最佳桥梁。无论是 Linux 内核、Git 版本控制系统，还是嵌入式单片机、游戏底层引擎与现代语言（如 Python、Node.js 运行时底层），C 语言都扮演着不可替代的角色。

本课程紧扣底层机理与工程实践，帮助你彻底建立严谨的物理内存模型与控制流逻辑思维，掌握从源代码到可执行文件的编译全流程，并攻克指针、结构体与文件持久化等核心难点。

## 二、C 语言核心心智模型：内存是线性的字节阵列

学习 C 语言与高级脚本语言（如 Python、JavaScript）最大的不同在于：**你必须清楚每一行代码在物理内存中发生着什么**。

<CMemoryLayoutFigure />

1. **虚拟内存分区**：
   - **代码段 (Text)**：存放编译后的 CPU 机器指令，只读且受到操作系统保护。
   - **数据段 (Data / BSS)**：全局变量与 `static` 静态变量的常驻区域，整个程序生命周期都有效。
   - **栈区 (Stack)**：函数每调用一次就压入一个栈帧（Stack Frame），局部变量在栈上分配；函数执行结束，栈帧立即弹出销毁。
   - **堆区 (Heap)**：通过 `malloc()` 动态申请的内存，由程序员负责在恰当的时机用 `free()` 释放。
2. **指针是内存地址的门牌号**：
   - 任何变量都有一个物理内存首地址（通过 `&var` 取得）。
   - 指针变量专门存储这个门牌号；通过解引用操作 `*ptr`，我们就能直接顺着门牌号读写那块内存！
3. **安全规范**：
   - 严禁数组越界读取或写入。
   - 字符串必须以 `\0` 结尾，否则标准库函数会一直读取直到触发段错误。
   - 局部变量离开作用域即失效，切不可返回指向栈上局部变量的指针。
