# 22｜流匹配：学习一个速度场

扩散通过加噪与反向过程建立生成路线。另一种思路是让噪声点沿一个可学习速度场移动到数据分布。关键不是给每个噪声点手工画路线，而是从许多噪声—数据样本构造监督信号，训练共享的时间条件函数。

## 先把时间方向说清楚

本页约定 $t=0$ 为噪声端，$t=1$ 为数据端，与上一单元“时间越大噪声越多”的记号不同，使用时必须先核对。取噪声 $z$ 和数据点 $x$，定义直线路径 $x_t=(1-t)z+tx$，其对时间的导数为目标速度 $u=x-z$。这是一种易懂的条件路径选择，不是所有流模型唯一使用的路径。

教学样本取 $z=(0,0)$、$x=(2,1)$，则 $t=0.5$ 时 $x_t=(1,0.5)$、目标速度为 $(2,1)$。训练输入是当前点和时间，输出是速度。采样时没有目标数据点可偷看，只能调用已学速度场。

## 一次真实的学习更新

设极小模型 $v_a(x_t,t)=a x_t$，暂忽略时间输入，只为算一轮梯度。损失定义为 $L=\frac12\|v_a-u\|^2$。初始 $a=0$，预测 $(0,0)$，损失 2.5；梯度为

$$
\frac{\partial L}{\partial a}=\sum_j(a x_{t,j}-u_j)x_{t,j}=-2\times1-1\times0.5=-2.5.
$$

学习率 0.1 后 $a=0.25$，新预测 $(0.25,0.125)$，损失为 $\frac12(1.75^2+0.875^2)=1.9140625$。这给出了数据、目标、损失和参数更新的闭环。它还很不充分：只学一个点，忽略时间，无法代表完整分布。真正微型实验会采样多组 $(z,x,t)$，训练带时间输入的网络。

## 生成是沿学习到的场积分

给初始噪声 $x_0$，求解 $dx/dt=v_\theta(x,t)$。最简单的欧拉步为 $x_{t+\Delta t}=x_t+\Delta t\,v_\theta(x_t,t)$。若教学中直接给定常数场 $(2,1)$，初始 $(0,0)$、步长 0.25，轨迹如下：

| 时间 | 点的位置     |
| ---- | ------------ |
| 0    | $(0,0)$      |
| 0.25 | $(0.5,0.25)$ |
| 0.5  | $(1,0.5)$    |
| 0.75 | $(1.5,0.75)$ |
| 1    | $(2,1)$      |

这张表是给定场的积分，不能当作训练成功证据。实际采样应使用训练后的网络，并比较不同噪声、步数和条件，保存每步预测速度。速度预测误差与离散积分误差都能影响最终分布。

## 为什么不能只记住终点配对

许多不同的噪声—数据配对可能在同一时间附近经过相似位置，网络学习的是这些监督下的整体向量场，而非拥有每个样本的秘密标签。训练配对、时间采样与模型容量会影响结果。二维点云可以可视化覆盖和模式丢失；高维图像还涉及表示、条件和更大训练规模。

[L4](/ai-labs/README.md) 在 CPU 上训练低维速度场，保存损失下降、采样点与条件对照。学生须比较未训练与训练后的模型，不能只展示手工常数场。机制可对照 [Flow Matching 原论文](https://arxiv.org/abs/2210.02747)。教师先展示本页直线积分，再刻意用弯曲场，让学生预测大步长会积累什么误差。
