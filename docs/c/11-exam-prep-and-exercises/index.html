核心概念与典型题型解析

在学习 C 语言的过程中，很多语法细节、运算优先级、边界条件以及底层内存机制看似微小，却直接决定了程序的正确性与鲁棒性。

本节系统提炼 C 语言 10 大核心知识点族 的典型题型，深度拆解高频易错陷阱，并通过典型题目测验强化对底层运行机理的准确理解。

三、C 语言语法与表达式深度推演要决

  1. 审清变量类型：看清是整型相除还是浮点相除，% 两边是否都是整型。
  2. 警惕赋值陷阱：在 if 或 while 中，看清写的是 ==（判断相等）还是 =（赋值语句）。
  3. 分清前置与后置：++i 先自增后代入；i++ 先代入当前值后自增。
  4. 数清数组越界：a[10] 的合法下标只有 0 到 9，字符串记得预留 \0 的 1 字节。
  5. 死守函数栈帧：普通形参只是副本，想改变外部实参必须传地址并解引用 *。
