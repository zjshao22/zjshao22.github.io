# 计算机网络

在宿舍打开课件时，浏览器为什么需要 DNS？交换机如何决定出口？路由表从哪里来？丢掉一个包，怎样避免内容缺失或重复交付？链路都通了，为什么仍可能打不开页面？

这门课沿着这些问题学习完整的网络系统：**信号与链路怎样传送，网络怎样互联，端点怎样可靠通信，应用怎样约定含义，系统怎样安全运行与定位故障。** 原理、推演、操作与自检都在页面中。

校园网是贯穿课程的教学情境；注明的地址、拓扑与报文记录是构造数据，不代表某所学校的实际部署。前三节按原有结构阅读，之后先做回顾，再深入协议机制。

## 怎样检查学会了什么

阅读一项机制之前先写预测，完成练习之后再展开提示与解析。记录错误发生在哪个字段、状态、单位或假设，而不只改最后答案。隔一段时间不看答案重做新场景。

| 能力             | 能交出的证据                                                 |
| ---------------- | ------------------------------------------------------------ |
| 解释层间关系     | 一次访问中各层的输入、输出、标识与职责，说明每跳哪些信息改变 |
| 计算性能         | 时延、开销、窗口、吞吐的计算与模型边界                       |
| 设计局域网与互联 | 地址计划、广播域、路由与返回路径，无重叠且满足容量           |
| 推演状态         | 交换学习表、路由迭代、TCP 序号/窗口、DNS 缓存的变化          |
| 实现应用         | 可运行程序、协议边界、异常处理与实际终端结果                 |
| 判断安全与故障   | 明确假设、支持证据、最小检验与修复后的复验                   |

用综合设计把机制连成系统：不仅说明“怎样成功”，还说明“条件改变后会怎样失败，怎样知道修复有效”。
