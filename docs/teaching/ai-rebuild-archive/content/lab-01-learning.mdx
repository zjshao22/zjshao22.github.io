# L1｜模型真的学到了什么

对应 02—05 单元。目标是证明参数真实更新、损失变化有依据，并区分拟合与泛化。材料为包内构造回归数据、自动求导小网络；全部只用 CPU。先完成[环境诊断](/docs/ai/lab-00-environment)。

## 先预测再运行

教师给 $\hat y=wx+b$、初始 $w=0,b=0$、样本 $(x,y)=(1,2)$，损失为 $\frac12(\hat y-y)^2$。学生先求两个梯度，预测学习率 0.1 后的参数和新损失，再运行包内更完整的批量训练。

```sh
python3 -B ai_lab.py l1 --output ./runs/l1 --seed 42
```

程序实际比较解析梯度与有限差分、更新线性模型，并用小型自动求导网络学习 XOR。学生在 `l1.json` 中追踪参数、训练历史、留出误差与失败对照，写清每个数字属于哪个模型。手算的一条样本不是程序整批数据，不混用数值。

## 把现象变成解释

有限差分近似为 $[L(w+\epsilon)-L(w-\epsilon)]/(2\epsilon)$。它不是另一种神秘训练法，而是独立检查导数的办法；$\epsilon$ 太大或太小都可能产生问题。教师让学生先看误差，再回查损失定义与平均系数。

朴素方案只看训练损失，可能忽略未见数据。学生对照训练与留出误差，再观察过大学习率的失败例；参数变了不等于任务改善，损失下降也不等于任何输入都正确。XOR 的非线性表达能力与真实优化是否学到分别核验。

## 独立变式

复制实验到自己的工作目录，只改变学习率再运行，保留原基线。先预测会更快、振荡还是发散，再用整批损失解释。验收不要求新设置更好，要求结论由输出支持。进入 [L2](/docs/ai/lab-02-token-to-generation) 时继续沿“参数—损失—更新”检查语言模型。
