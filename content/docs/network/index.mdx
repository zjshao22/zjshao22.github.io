# 计算机网络

在宿舍连校园网、看班级群通知、打开学校课程平台、查询车次、播放视频：这些熟悉的操作背后，都是不同设备上的程序在交换数据。

这组课程把所需概念、清晰的图示、例题和答案都写在页面中，可以直接阅读和练习。我们使用一个**简化的校园课程平台**贯穿各节；它帮助解释原理，不代表某所学校或某个 App 的真实内部结构。

1. [从校园生活认识网络应用](./01-how-web-works)：客户端与服务器交换什么，为什么应用要定义数据的含义。
2. [校园网里的四层分工](./02-four-layers)：应用、传输、网络和链路各解决哪个问题。
3. [数据怎样穿过校园网](./03-ip-and-packets)：IP 数据报、路由器、逐跳转发与排队。
4. [从课件请求看封装](./04-encapsulation)：把四层连起来，并用网络现象检查理解。
5. [协议字段为什么要约定字节序](./05-byte-order)：设备怎样一致地解释多个字节组成的数字。
6. [IPv4 地址与校园网网段](./06-ipv4-subnets)：读懂四组数字、子网掩码与 CIDR 前缀。
7. [路由器怎样选择下一跳](./07-longest-prefix)：用最长前缀匹配读转发表。
8. [已知网关 IP，怎样发出第一帧](./08-arp)：用 ARP 找到本地下一跳的链路地址。

每节都给出协议边界、推算过程与带解析的练习。读完后应能独立解释一次访问中的各层职责，并计算数据报长度、发送时延、IPv4 子网和最长前缀匹配结果。

## 阅读依据

课程的主题选择参考了 [Computer Networking 资料库](https://github.com/khanhnamle1994/computer-networking)；例子、讲解和题目围绕国内校园网络重新编写。若要核对协议细节，可阅读 [HTTP 语义 RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)、[TCP RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)、[IPv4 RFC 791](https://www.rfc-editor.org/rfc/rfc791.html)、[CIDR RFC 4632](https://www.rfc-editor.org/rfc/rfc4632.html) 与 [ARP RFC 826](https://www.rfc-editor.org/rfc/rfc826.html)。RFC 是协议规范；本课程的简化模型会明确写出假设。
