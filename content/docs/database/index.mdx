# 数据库原理及应用

在数字校园中，学生选课、成绩登记、学分核算、图书借还，背后都是数据库系统在稳定运转。

本课程围绕一个明确的目标组织：**在理解数据库理论的基础上，能独立完成数据库设计、熟练编写标准 SQL 语句、进行安全运维管理，并将数据库接入后端应用实现完整系统**。

教学主线采用 **“学生选课与成绩管理系统”**：从认识数据 $\to$ 建立四张基准表 $\to$ 数据操作与复杂查询 $\to$ 解释与改进数据库设计 $\to$ 运维与安全管理 $\to$ 接入教师成绩管理程序。图书借阅、超市销售、仓库进销存等业务场景则作为迁移能力检验。四个实践实验不作孤立割裂，而是**与理论学习紧密融合，学到对应技能即就地展开实验实操**。

## 二、核心能力与检验检查点

课程设置了五个阶段性能力检查点（Gate 1 至 Gate 5），用于检验独立解题与实操能力：

<GateChainFigure />

1. **G1 基础操作检查（第 1 章）**：独立建立包含主外键约束的表结构，完成指定增删改操作并核验影响范围。
2. **G2 综合查询检查（第 2~3 章）**：涵盖单表、多表连接、分组聚合、子查询及存在性查询，熟练应对不同业务条件。
3. **G3 数据库设计检查（第 4 章）**：独立完成 ER 模型文字表述、ER 转关系模式、候选键判定与 1NF—3NF 范式分解。
4. **G4 管理与应用检查（第 6~7 章）**：完成数据整库与指定表恢复校验、用户创建与细粒度授权、成绩管理系统端到端功能演示。
5. **G5 综合迁移检查（第 8 章）**：在无代码提示环境下，独立完成陌生业务场景（如图书借阅或超市销售）的综合大题演练与设计表达。

## 三、统一读题与解题六步法

解任何 SQL 查询题，请严格执行**统一读题六步法**，避免凭感觉拼凑代码：

<SqlOrderFigure />

1. **结果中的一行代表什么对象？**（是一名学生、一门课程，还是一条选课记录？）
2. **需要输出什么字段，分别来自哪张表？**（确定投影列与所需基表）
3. **表之间按哪些键进行连接？**（寻找主外键连接路径：`sid`、`tid`、`cid`）
4. **哪些条件过滤行（WHERE），哪些条件过滤组（HAVING）？**（区分记录级筛选与聚合统计筛选）
5. **是否涉及 NULL、重复记录、不存在（未选课）或双重条件？**（决定使用外连接、NOT EXISTS、IN 还是多重筛选）
6. **结果如何排序，怎样使用小数据集手工推演验证？**（确定 ORDER BY 规则，并推导正确结果集合）
