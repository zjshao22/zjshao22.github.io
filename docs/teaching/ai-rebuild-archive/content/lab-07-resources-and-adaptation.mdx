# L7｜资源与适配对照

对应 32—35 单元。目标是分别核验“文件更小”“运算更快”“误差可接受”和“适配有效”，不能由其中一项推出其他三项。

```sh
python3 -B ai_lab.py l7 --output ./runs/l7 --seed 42
```

## 一次可核查的存储比较

程序先训练 $4\times8$ 小线性网络，将 32 个权重打包为 float64 字节和 int8 加尺度字节，输出实际 base64 载荷。比较 256 与 40 字节；这是序列化存储，不是 Python 对象或进程峰值内存。量化后使用整数累加再恢复尺度，记录权重与预测误差。

教师让学生先计算字节数，再查看 `quantization`。学生对照 2000 次调用的两类耗时，解释为何 Python int8 路径可能更慢；本实验没有硬件优化内核，也没有声称该倍数适用于大型模型。

## 真实低秩更新和对照

基础网络训练后冻结，新目标由 rank 1 扰动构造。程序使用 A 随机、B 零的初始化，训练 12 个低秩参数，并与 32 参数完整微调比较。输出包含基础权重哈希、低秩检查点、训练历史与留出误差。

学生先按矩阵形状求参数量，再找出证明“基础冻结”和“适配参数改变”的不同字段。目标特意适配 rank 1，不代表所有真实任务都适合相同 rank；留出误差改善也需按构造分布解释。

## KV 是另一本账

`kv_cache` 保存 $2LBH_{kv}Td_hb$ 的公式值。本例为 4096 字节，未实际分配大型缓存。学生把长度加倍，复算 8192 字节，并指出权重、激活、运行时和缓存是不同内存组成。

## 学生任务与验收

提交存储口径、量化误差、两类耗时、LoRA 参数量及训练前后留出误差；同时提供基础权重未变证据。教师检查单位与分母，再问“这个实验在哪些条件下可能失败”。

## 独立变式

把新任务的目标改变为一般高秩扰动，预测 rank 1 的表达限制，再比较训练与留出误差。若为了更好结果增加 rank，应保留原配置和参数量，不能只交最佳一次。
