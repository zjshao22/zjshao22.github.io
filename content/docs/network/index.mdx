# 计算机网络

在宿舍连校园网、看班级群通知、打开学校课程平台、查询车次、播放视频：这些熟悉的操作背后，都是不同设备上的程序在交换数据。

本单元从“浏览器要什么”走到“第一帧交给谁”。我们使用一个**简化的校园课程平台**贯穿各节；它帮助解释原理，不代表某所学校或某个 App 的真实内部结构。所需定义、图示、例题和解析都在页面中。

## 一次访问中的八个问题

1. [从校园生活认识网络应用](./01-how-web-works)：客户端与服务器交换什么，为什么应用要定义数据的含义。
2. [校园网里的四层分工](./02-four-layers)：应用、传输、网络和链路各解决哪个问题。
3. [数据怎样穿过校园网](./03-ip-and-packets)：IP 数据报、路由器、逐跳转发与排队。
4. [从课件请求看封装](./04-encapsulation)：把四层连起来，并用网络现象检查理解。
5. [协议字段为什么要约定字节序](./05-byte-order)：设备怎样一致地解释多个字节组成的数字。
6. [IPv4 地址与校园网网段](./06-ipv4-subnets)：读懂四组数字、子网掩码与 CIDR 前缀。
7. [路由器怎样选择下一跳](./07-longest-prefix)：用最长前缀匹配读转发表。
8. [已知网关 IP，怎样发出第一帧](./08-arp)：用 ARP 找到本地下一跳的链路地址。

## 怎样练习

先用自己的话回答本节的问题，再阅读图示与例题。遇到推算任务，写出条件、单位和中间步骤；遇到网络现象，分别写出“已经观察到什么”和“还不能确定什么”。完成题面后再展开参考解析，订正时说明是哪一步判断出了问题。

动手任务穿插在对应知识处。请求观察可以使用浏览器的网络面板；不便操作时，页面也提供教学记录供分析。字节序、子网和转发表任务用纸笔即可完成。教学记录用于练习推理，实际观察则需要记录你自己的结果。

## 学完后检查自己

| 要完成的任务              | 答案里应当说明什么                                                   |
| ------------------------- | -------------------------------------------------------------------- |
| 解释一份课件请求          | 客户端、服务端、资源路径和响应各是什么；一个页面为何可能有多次请求。 |
| 给网络现象找排查起点      | 四层各负责什么；现有证据支持哪些判断，还缺什么证据。                 |
| 计算长度和发送时延        | 从哪一层开始计数；首部、负载与帧如何区分；字节怎样换成位。           |
| 读出协议字段              | 字段位置、宽度、字节序以及解码过程。                                 |
| 划分 IPv4 子网            | 前缀、块范围、可分配地址与网关占用；子网之间是否重叠。               |
| 判断下一跳与 ARP 查询对象 | 所有匹配前缀、最长匹配、最终目标 IP、下一跳 IP 和当前链路地址。      |

最后把前八节连成一次通信：应用定义请求，传输层区分端点，IP 数据报逐跳转发，每段链路用自己的帧交付。用新的地址、包长或故障现象再解释一次，检查自己能否把方法迁移到另一个情境。
