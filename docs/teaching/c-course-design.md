# C 语言程序设计：完整课程设计（64 学时）

本课程围绕一个核心教学目标组织：**使学生建立清晰的物理内存心智模型与程序控制流思维，能够独立、严谨地完成上海开放大学两套大型上机综合实验，并在期末考试中准确解答 240 道客观题题库中的单选、多选与判断题目。**

教学主线结合 **freeCodeCamp C 语言入门手册** 的现代化通俗教学法与高校严谨教学规范：从底层计算机执行机制与编译流程切入，经历数据类型与运算符、格式化 I/O、分支与循环两大控制结构、数组与字符串哨兵，深入到函数调用栈帧、指针与物理内存寻址、结构体与字节对齐，最后落脚于文件持久化与综合工程实践。

## 四、核心教学难点与破局策略

### 1. 编译流水线与文件生命周期（解决“只会点运行，不懂底层”的问题）

- **传统盲区**：学生以为代码一写好就能直接跑，遇到链接错误（LNK2001/Undefined symbol）手足无措。
- **教学对策**：通过 `<CCompilationPipelineFigure />` 图解清楚展示 `.c`（源代码）→ `.i`（展开头文件与宏）→ `.s`（汇编代码）→ `.obj`（二进制目标文件）→ `.exe`（链接系统运行库后生成的可执行文件）。明确客观题中“源程序扩展名为 `.c`、编译后为 `.obj`、链接后为 `.exe`”的标准答案。

### 2. 标准输入流缓冲区与换行符遗留（解决字符输入的“幽灵跳步”Bug）

- **传统盲区**：用 `scanf("%d", &n);` 读入数字后，接着用 `getchar()` 或 `scanf("%c", &ch);` 读字符时，程序自动跳过输入。
- **教学对策**：使用 `<InputBufferFigure />` 展现键盘键入数据到进入进程内存的队列机制。讲透敲击回车产生的 `\n` 是一个实体字符，若不显式清理（如用 `getchar()` 吸收、循环清空或用 `scanf(" %c")` 跳过空白），后续字符读取必然失败。

### 3. 函数参数的值传递副本机制（解决“为什么写了 swap 却换不了”）

- **传统盲区**：很多初学者在写 `void swap(int x, int y) { int t = x; x = y; y = t; }` 时，认为已经成功交换了 `main` 函数中的变量。
- **教学对策**：使用 `<SwapStackFigure />` 对比函数调用栈。展示形参 `x, y` 只是在 `swap` 自身栈帧中分配的独立副本，函数结束栈帧弹出后毫无保留。唯有通过 `swap(int *p1, int *p2)` 传递变量的内存地址，在被调函数内通过 `*p1` 和 `*p2` 解引用直接操作调用方栈帧中的内存，交换才能真实生效。

### 4. 字符串的本质是字符数组 + `\0` 哨兵标记

- **传统盲区**：混淆字符常量 `'A'` 与字符串常量 `"A"`；忘记字符串必须多预留 1 字节存放 `\0`。
- **教学对策**：使用 `<StringArrayMemoryFigure />` 说明 `"China"` 在内存中占 6 字节而非 5 字节；演示若字符数组没有 `\0`，`printf("%s")` 将一直向后越界读取打印内存乱码，直至在偶遇 0 字节时发生奔溃（Segmentation fault）。

### 5. 结构体内存对齐与 sizeof 真实大小

- **传统盲区**：认为结构体大小等于各成员大小直接相加（`char(1) + int(4) + short(2) = 7`）。
- **教学对策**：结合 `<StructAlignmentFigure />` 图解讲解遵循目标 ABI 规范的成员与结构体对齐原则（成员偏移量为对齐要求的整数倍，结构体总大小为最大对齐成员的整数倍），推导内存空洞（Padding）的存在，解决题库中结构体空间大小计算的必考题。

## 五、两套实验的教学安排、标准解答与验收标准

### 实验一：流程控制（8 学时）

实验目的：熟练掌握 if 语句和 switch 语句分支结构；熟练掌握 while、do-while、for 循环结构；掌握常用分支与循环嵌套调试技巧。

1. **实验题 1（成绩评级）**：
   - 百分制转 A/B/C/D/E：`>=90` 为 A，`[80,90)` 为 B，`[70,80)` 为 C，`[60,70)` 为 D，`<60` 为 E。
   - 输入边界防御：小于 0 或大于 100 时输出“输入数据错误!”。
   - 分别采用 `if-else` 与 `switch-case` 两种方式完整实现。
2. **实验题 2（字符统计）**：
   - 接收一行字符输入，分别统计英文字母（大小写）、空格、数字字符和其他字符个数。
   - 掌握 `getchar()` 循环读取到 `\n` 终止的经典字符流模式。
3. **实验题 3（分数序列前 20 项和）**：
   - 序列规律：`2/1, 3/2, 5/3, 8/5, 13/8, 21/13...`，分子分母呈现斐波那契规律（下一项分子 = 原分子 + 原分母，下一项分母 = 原分子）。
   - 双精度浮点累加器与临时变量暂存机制推演。
4. **实验题 4（3 的倍数求和）**：
   - 输入整数 n，计算 1 至 n 中所有是 3 的倍数（`i % 3 == 0`）的数值之和。
5. **实验题 5（菱形图案打印）**：
   - 上三角 4 行，下三角 3 行。控制外层行循环、前导空格循环和星号循环的关系公式。

### 实验二：数组、函数和指针（8 学时）

实验目的：熟练掌握一维数组、字符数组、函数定义与调用、形参实参传递、一维指针及利用指针作为函数参数。

1. **实验题 1（10 个数最大值与下标定位）**：
   - 一维整型数组输入 10 个整数，遍历求最大值 max 及所在位置（下标加 1）。
2. **实验题 2（单词个数统计）**：
   - 输入一行字符串，以空白字符（空格/Tab/换行符）分隔单词，用状态标志位 `word` 区分当前处于“单词内”还是“间隔中”。
3. **实验题 3（自定义 Max 函数模块化求最值）**：
   - 编写 `int Max(int x, int y)` 函数，主函数中循环调用该函数求 10 个整数的最大值。
4. **实验题 4（求数组平均值函数）**：
   - 编写 `float Average(int a[], int n)` 函数，理解一维数组作为形参时退化为指针的特性。
5. **实验题 5（指针 swap 交换函数与大小排序输出）**：
   - 编写 `void swap(int *p1, int *p2)`，主函数输入 a, b 后利用指针变量调用 swap 实现大小排序输出。

- **期末综合机考 (50%)**：
  - 单选题：40%（从 145 题库抽取 20 题，每题 2 分）。
  - 多选题与判断题：20%（多选 5 题，判断 10 题）。
  - 程序填空与编程题：40%（实验一、二中的经典变式程序综合编写）。
