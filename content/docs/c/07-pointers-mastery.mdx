# 指针精讲与内存寻址

在计算机科学中，有一句广为人知的名言：**“如果你不懂指针，你就不能算真正学会了 C 语言。”**

许多人觉得指针神秘晦涩，根本原因在于脱离了计算机体系结构去空谈语法。一旦你在脑海中建立了清晰的**物理内存心智模型**，指针不仅不再难以理解，反而会成为你在底层世界中最强大、最直观的利刃。

本节建立清晰的计算机物理内存模型与门牌号哲学，深度掌握取地址（&）与解引用（\*）的本质机理，剖析函数调用中指针跨栈帧原地修改的 swap 核心模式，以及指针算术运算的内存步长规律。

## 一、计算机内存模型与门牌号哲学

想象物理内存（RAM）是一排望不到头的储物柜：

- 每一个储物柜的大小恰好是 **1 个字节（1 Byte = 8 bit）**。
- 为了能够快速找到某一个柜子，操作系统为每个字节分配了一个独一无二的编号——这个编号就是**物理内存地址（Address）**。
- 在 32 位操作系统中，地址范围是 $0 \sim 2^{32}-1$（用 8 位十六进制表示，如 `0x0019FF3C`）；在 64 位操作系统中，地址更宽长（用十六进制表示，如 `0x7ffd58`）。

当你定义一个整型变量 `int a = 42;` 时：

- 编译器在内存中为你申请了 **4 个连续的储物柜（4 字节）**。
- 这 4 个储物柜中第一个储物柜的编号，就是**变量 a 的首地址**，用取地址运算符 **`&a`** 获取。
- 储物柜内部存放的内容，就是数值 **`42`**。

## 二、什么是指针变量？& 与 \* 运算符

**指针的本质就是内存地址。**
而**指针变量（Pointer Variable）**，就是专门用来存储**另一个变量的内存首地址**的变量！

<PointerIndirectionFigure />

### 1. 指针的定义与初始化

语法格式：

```c
基类型 *指针变量名;
```

```c
int a = 42;
int *p = &a; // 定义一个指向 int 类型的指针变量 p，并将 a 的地址赋给它
```

- `*` 在定义语句中只是一个**类型标识符**，表示变量 `p` 是一个指针。
- `p` 的**基类型是 `int`**，意味着通过 `p` 去访问内存时，每次操作连续的 4 个字节。

### 2. 解引用运算符（间接访问运算符）`*`

当指针 `p` 已经保存了 `a` 的内存地址后，我们在表达式中使用 **`*p`**：

- `*p` 的含义是：**“顺着指针 p 里面存的地址，直接开门进入那个储物柜，读写里面的数据”**！
- 因此，**`*p` 完全等价于变量 `a` 本身**！
  - `printf("%d", *p);` $\implies$ 打印的就是 `a` 的值 `42`。
  - `*p = 100;` $\implies$ 储物柜里的内容被改成了 100，此时查看 `a`，`a` 也变成了 `100`！

## 三、指针作为函数参数：swap 两数交换的成败内幕

在前面的章节中我们学到，函数传参默认是**值传递**（只拷贝副本）。现在，我们终于可以通过**指针传递（传地址）**彻底打破函数栈帧的隔离限制！

<SwapStackFigure />

### 1. 为什么错误版本的 swap 根本换不了？

```c
void wrong_swap(int x, int y) {
    int t = x;
    x = y;
    y = t;
}
```

**死因分析**：`main` 函数调用 `wrong_swap(a, b)` 时，操作系统只是把 `a` 和 `b` 的数值拷贝给了形参 `x` 和 `y`。`wrong_swap` 忙活了半天只是交换了自己的局部变量。一旦函数执行完毕返回，`wrong_swap` 的栈帧被系统瞬间销毁，`main` 中的 `a` 和 `b` 完好如初！

### 2. 指针版本的正确 swap 实现

如果把变量的**内存首地址 `&a` 和 `&b`** 传递给函数：

```c
void swap(int *p1, int *p2) {
    int temp; // 注意：temp 必须是普通整型变量，用于暂存数值！
    temp = *p1; // 取出 p1 所指地址（main 里的 a）的值，存入 temp
    *p1 = *p2;  // 将 p2 所指地址（main 里的 b）的值，直接写入 p1 所指的内存
    *p2 = temp; // 将 temp 写入 p2 所指的内存
}
```

**生效原理**：`p1` 拿到了 `main` 中 `a` 的门牌号，`p2` 拿到了 `main` 中 `b` 的门牌号。函数内部通过 `*p1` 和 `*p2` 解引用，**直接跨栈帧修改了位于 main 函数内存空间中的实际数据**！

### 3. 指针 swap 的两大致命避坑！

> [!CAUTION] 极高频经典易错陷阱！
> **致命错误 1：只交换指针自身（换门牌号贴纸）**
>
> ```c
> void error_swap1(int *p1, int *p2) {
>     int *p;
>     p = p1; p1 = p2; p2 = p; // 仅仅交换了形参指针自己存的地址，被指内存里的数据分毫未动！
> }
> ```
>
> **致命错误 2：野指针解引用（灾难崩溃 Segmentation fault）**
>
> ```c
> void error_swap2(int *p1, int *p2) {
>     int *p; // 危险！未初始化的野指针，内部指向随机未知内存地址！
>     *p = *p1; // 试图向系统受保护的随机内存写入数据，程序瞬间奔溃退出！
>     *p1 = *p2;
>     *p2 = *p;
> }
> ```

## 四、实战案例：指针实现两数排序与降序输出

**任务描述**：编写 `swap` 交换函数，在主函数中输入两个整数 `a, b`，利用指针变量调用 `swap` 函数，实现两数按大小顺序（大的在前，小的在后）输出。

### 核心实现代码

```c
#include <stdio.h>

// 正确的指针版本交换函数
void swap(int *p1, int *p2)
{
    int temp;       // 临时整型变量
    temp = *p1;     // 取出 p1 指向的内容
    *p1 = *p2;      // 将 p2 的内容写入 p1
    *p2 = temp;     // 将 temp 写入 p2
}

int main()
{
    int a, b;
    int *pointer_1, *pointer_2;

    printf("please enter two integer numbers:");
    scanf("%d,%d", &a, &b);

    pointer_1 = &a; // pointer_1 指向 a
    pointer_2 = &b; // pointer_2 指向 b

    if (a < b)      // 如果 a 比 b 小，则需要交换使 a 保持为较大值
        swap(pointer_1, pointer_2); // 调用 swap 函数，指针变量作为实参

    // 按大小顺序输出 (max在前，min在后)
    printf("max=%d,min=%d\n", a, b);
    return 0;
}
```

## 五、指针与一维数组的等价性与步长机制

### 1. 数组名与指针的亲缘关系

在 C 语言中，数组名其实就是一个**常量指针**，指向数组的首元素：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a; // 等价于 int *p = &a[0];
```

一旦指针指向了数组首地址，下标运算符 `[]` 与指针解引用 `*` 之间存在完全等价的恒等式：
$$a[i] \iff *(a + i) \iff *(p + i) \iff p[i]$$

### 2. 指针的算术运算与“步长”

给一个指针加 1（`p + 1`），物理内存地址增加的绝对**不是 1 个字节**！

> [!IMPORTANT] 指针移动步长公式
> 指针加上整数 $n$ 时，实际物理地址增加的字节数等于：
> $$\Delta \text{Address} = n \times sizeof(\text{基类型})$$

- 若 `p` 是 `char*`（基类型占 1 字节），`p + 1` 地址后移 **1** 字节。
- 若 `p` 是 `int*`（基类型占 4 字节），`p + 1` 地址后移 **4** 字节（正好指向下一个 int！）。
- 若 `p` 是 `double*`（基类型占 8 字节），`p + 1` 地址后移 **8** 字节。

## 本节小结与核心要点

1. **指针就是地址**：指针变量专门存放目标变量的首地址。
2. **& 与 \* 互逆**：`&` 获取地址，`*` 顺藤摸瓜解引用读写数据。
3. **swap 核心要素**：必须使用普通局部变量 `int temp` 暂存数值，通过 `*p1 = *p2` 真正原地改写内存。
4. **野指针大忌**：未初始化的指针严禁解引用（会导致崩溃段错误）。
5. **指针步长取决于基类型**：`p + 1` 物理地址递增 $sizeof(\text{基类型})$。
