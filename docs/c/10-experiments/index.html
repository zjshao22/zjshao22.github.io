核心技术与调试避坑小结

  1. switch 穿透合并技巧：若多个 case 执行相同的逻辑，可省略 break 实现穿透（如 case 10 与 case 9 共同判定为 A，case 5 到 0 连续穿透判定为 E）。
  2. 状态机标志位法：使用 word 标志位可在遍历字符串时准确区分“空格间隔”与“单词首字母”，能够自然过滤首尾空格与多个连续空格。
  3. 数组传参的指针本质：一维数组作为形参时会退化为指针（int a[] 实际等价于 int *a），无法在函数内通过 sizeof(a)/sizeof(a[0]) 获取长度，必须显式传递数组大小参数 n。
  4. 值传递 vs 传地址本质：普通变量传参只复制副本，无法修改调用方内存；利用指针传递内存首地址并配合解引用 *，才能实现跨函数栈帧的变量原地修改。
