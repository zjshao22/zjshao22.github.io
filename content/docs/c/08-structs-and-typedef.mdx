# 结构体、枚举与自定义类型

在前面的学习中，我们处理的数据都是基本类型（整数、浮点数、字符）或者它们的同质集合（数组）。然而，在现实世界中，一个业务对象往往是由**不同类型的数据项**共同组成的：例如一名学生，既有整型的学号，又有字符数组的姓名，还有浮点型的成绩。

**结构体（struct）** 赋予了程序员根据实际需求将不同数据类型聚合为一个全新复合类型的能力。

本节全面解析结构体定义与内存布局、成员访问运算符（. 与 ->）、底层字节对齐与空间填充规则，以及 typedef 类型别名与 enum 枚举的应用。

---

## 一、结构体的定义与变量声明

### 1. 结构体类型的定义

语法格式：

```c
struct 结构体名 {
    数据类型 成员名1;
    数据类型 成员名2;
    ...
}; // 注意：结构体定义末尾的花括号后面必须有分号 ;
```

例如定义一个“学生”结构体：

```c
struct Student {
    int id;           // 学号
    char name[20];    // 姓名
    char sex;         // 性别 ('M' 或 'F')
    float score;      // 成绩
};
```

<Callout type="info" title="关键概念辨析">
仅仅写出 `struct Student { ... };` 只是声明了一种**自定义数据类型模板**，系统此时**并不会为其分配任何内存空间**！只有在用它定义了具体的**结构体变量**后，系统才会真正开辟物理内存。

</Callout>

### 2. 结构体变量的声明与初始化

```c
// 定义结构体变量并初始化
struct Student stu1 = {1001, "张三", 'M', 92.5f};

// 单独为成员赋值
struct Student stu2;
stu2.id = 1002;
stu2.score = 88.0f;
```

## 二、成员访问运算符：点 `.` 与 箭头 `->`

访问结构体内部的具体成员，根据左侧是“普通变量”还是“指针变量”，严格区分两种运算符：

|  运算符  | 运算符全称             | 左侧操作数类型     | 典型语法范式           | 底层等价转换           |
| :------: | :--------------------- | :----------------- | :--------------------- | :--------------------- |
| **`.`**  | **圆点成员访问符**     | **结构体普通变量** | `stu1.id`、`stu1.name` | 直接寻址对应成员偏移量 |
| **`->`** | **箭头指针成员访问符** | **结构体指针变量** | `p->id`、`p->name`     | **`(*p).id`**          |

```c
struct Student stu1 = {1001, "李四", 'M', 89.0f};
struct Student *p = &stu1; // p 是指向 stu1 的结构体指针

// 以下四种方式在逻辑上完全等价：
printf("%d\n", stu1.id);
printf("%d\n", p->id);
printf("%d\n", (*p).id);
```

<Callout type="idea" title="为什么 (*p).id 必须加圆括号？">
因为在 C 语言运算符优先级表中，点运算符 `.` 的优先级为最高级（1级），而解引用运算符 `*` 仅为 2 级！如果不加括号写成 `*p.id`，会被编译器理解为 `*(p.id)`，引发语法报错！使用 `p->id` 则兼顾了安全与优雅。

</Callout>

<Quiz
  question="设有定义 struct Book { int id; char title[20]; } b, *p = &b;，下列成员引用表达中错误的是（    ）。"
  options={["A b.id", "B p->id", "C (*p).id", "D *p.id"]}

## 三、结构体内存字节对齐与 sizeof 真实大小

许多初学者理所当然地认为：结构体占用的内存大小等于所有成员大小的简单累加。**这是完全错误的！**

为了提高 CPU 通过数据总线读取物理内存的吞吐效率，现代编译器会遵循**内存字节对齐（Byte Alignment）** 规则：

<StructAlignmentFigure />

### 结构体对齐核心规则（基于主流自然对齐 ABI）

在未指定 `#pragma pack` 打包指令的主流平台（x86-64 / ARM64）ABI 规范下，结构体布局遵循**类型的对齐要求（Alignment Requirement，C11 中可用 `_Alignof` 获取）**，而非简单看成员的 `sizeof`：

1. **成员对齐**：每个成员的起始偏移量（Offset），必须是其**类型对齐值**的整数倍。若前一个成员结束后空位不满足对齐要求，编译器会自动填充 Padding 字节。
   *(注：数组成员的对齐值等于其基元素类型的对齐值，例如 `char bytes[3]` 的对齐要求是 1 字节，而不是 3 字节)*。
2. **总大小对齐**：整个结构体的总字节大小，必须是结构体中**最大成员对齐值的整数倍**。末尾不足时同样会填充 Padding，以保证该结构体构成数组时，后续每个元素都能满足对齐要求。

#### 实战推算案例：

```c
struct Example {
    char a;   // 1 字节，起始于 offset 0
              // 自动填充 3 字节 padding (offset 1, 2, 3) 满足 int 4字节对齐
    int b;    // 4 字节，起始于 offset 4 (4 的倍数)
    short c;  // 2 字节，起始于 offset 8 (2 的倍数)，占用 8, 9
              // 末尾填充 2 字节 padding (offset 10, 11) 使总大小成为 4 的倍数
};
```

成员本身只占 $1 + 4 + 2 = 7$ 字节，但在默认 4 字节自然对齐前提下，通过 `sizeof(struct Example)` 计算出来的真实大小是 **`12` 字节**！

## 四、使用 typedef 简化类型命名

关键字 **`typedef`**用于为已有的数据类型定义一个**新的同义词（别名）**。

### 1. typedef 的标准语法与用途

```c
typedef 原数据类型名 新类型别名;
```

```c
typedef unsigned int uint; // 以后 uint 就等价于 unsigned int
typedef int* IntPtr;       // 以后 IntPtr 就等价于 int*
```

### 2. 结合结构体打造优雅代码

在没有 `typedef` 时，每次声明结构体变量都必须带上啰嗦的 `struct` 关键字：

```c
struct Student s1; // 必须写 struct
```

利用 `typedef`，我们可以将结构体定义与别名合并：

```c
typedef struct Student {
    int id;
    char name[20];
} Student;

// 从此以后，定义变量就像使用 int 一样清爽：
Student s1;
Student s2;
```

<Callout type="warn" title="核心机制：typedef 并不创造新类型！">
  `typedef`
  仅仅是给一个**已经存在的类型**赋予了一个好记、简洁的名称，**它没有开辟任何新的数据类型**，也没有占用新的存储空间。

</Callout>

## 五、枚举类型：enum

**枚举（enum）** 是一组具名的整型常量集合，常用于表达有限的状态、方向或选项：

```c
enum Weekday {
    MON = 1, // 默认从 0 开始，也可显式指定初值
    TUE,     // 自动递增为 2
    WED,     // 3
    THU,     // 4
    FRI,     // 5
    SAT,     // 6
    SUN      // 7
};

enum Weekday today = FRI;
```

<Callout type="info" title="关键概念：C 语言枚举的底层本质是整数">
  在 C 语言中，枚举在底层兼容某种整数类型（通常为 `int`）。语言机制本身**并不会在编译或运行时强制阻止**将列表之外的整数赋值给枚举变量（例如写 `today = 99;` 在 C 语言语法中是合法的）。枚举的核心价值在于为代码赋予清晰的符号常量和有限状态意图；若业务要求严格限定输入值，需要开发者显式编写校验逻辑。
</Callout>

## 本节小结与核心要点

1. **类型定义不占内存**：声明 `struct` 模板不分配空间，定义具体变量才分配。
2. **两类访问运算符**：普通变量用点 `.`，指针变量用箭头 `->`（`p->id ≡ (*p).id`）。
3. **内存对齐防空洞**：成员偏移与总大小均须对齐，`sizeof` 通常大于各成员简单累加之和。
4. **typedef 只是取别名**：不创建新类型，只为已有类型提供简明名称。
5. **enum 是整数符号集合**：默认从 0 开始递增，增强程序语义可读性。
