格式化输入与输出

与某些自带 print 语言内置关键字的高级语言不同，C 语言本身不提供任何输入输出语句。所有的输入和输出功能全部由 C 标准库函数（通过包含 #include <stdio.h>）提供。

其中，最基础也最核心的两个函数是格式化输出函数 printf() 和格式化输入函数 scanf()。

一、格式化输出函数：printf()

printf（Print Formatted）用于将数据按照指定的格式转换为文本字符，并输出到控制台终端。

1. printf 的基本语法

格式控制字符串包含两类内容：

  1. 普通文本字符：按原样原汁原味地输出（如提示词、标点符号、空格）。
  2. 格式转换说明符：以 % 开头，用于指定后续对应输出项的数据类型和显示格式。

2. 常用格式转换说明符

说明符对应数据类型输出形式与示例
%d / %iint、short有符号十进制整型（如 100, -25）
%cchar单个字符（如 'A', '9'）
%s字符串（字符数组/指针）连续字符，直到遇到 '\0' 终止符
%ffloat、double小数形式的浮点数，默认保留 6 位小数
%lfdouble双精度浮点数（现代 printf 中 %f 与 %lf 通用）
%o整型无符号八进制 形式输出（不带前导 0）
%x / %X整型无符号十六进制 形式输出（小写 a-f 或大写 A-F）
%p指针变量输出变量的十六进制内存物理地址（如 0x7ffd58）
%%—输出一个纯百分号 % 本身

3. 宽度与精度修饰符

我们可以通过修饰符对输出的排版布局进行精确控制：

  • %md：设定输出宽度为 m 列。若数据位数小于 m，则在左侧补空格（右对齐）；若超过 m，按实际位数完整输出。
  • %-md：设定输出宽度为 m 列，左对齐，不足部分在右侧补空格。
  • %.nf：控制浮点数输出保留 n 位小数（按照四舍五入规则）。
  • %m.nf：同时指定总宽度 m 列与保留小数位数 n。

二、格式化输入函数：scanf()

scanf（Scan Formatted）用于从键盘标准输入流读取数据，并按照指定的格式存入变量对应的内存地址单元中。

1. scanf 的核心语法与地址取地址符 &

[!CAUTION] 极高频严重错误：绝不能漏写取地址符 & scanf 的底层工作原理是：它必须知道数据要写到内存中的哪个具体地址单元去！ 因此，参数列表中必须传入变量的地址（&变量名），而不是变量的名字！

  • 正确：scanf("%f", &score); ✔
  • 错误：scanf("%f", score); ❌（会导致野指针内存非法访问，程序崩溃崩溃 Segmentation fault！）
  • 唯一例外：当读取字符串到字符数组时（如 char name[20]; scanf("%s", name);），数组名本身就代表该数组在内存中的首地址，此时无需加 &！

2. 格式控制字符串中的分隔符匹配

scanf 的格式字符串中写了什么，用户在键盘上就必须严格敲入对应的字符：

  • 若写 scanf("%d%d", &a, &b);：两个数字之间可以使用空格、Tab 键或回车键作为分隔符。
  • 若写 scanf("%d,%d", &a, &b);：两个数字之间必须严格输入英文逗号（如键盘输入 10,20），否则后续变量无法正确识别赋值！

1. 产生原因剖析

  1. 当程序提示输入年龄时，用户在键盘上敲入 20 并按下 回车键 Enter。
  2. 操作系统将击键输入整行压入标准输入缓冲区 stdin，此时缓冲区内有 3 个字符：'2'、'0'、'\n'（换行符）。
  3. scanf("%d", &age) 读走了数字部分 20，但换行符 '\n' 被孤零零地留在了缓冲区队列中！
  4. 当程序接着执行 scanf("%c", &grade) 时，因为 %c 是读取任何字符（包括空白字符和回车），它发现缓冲区里正好有一个现成的 '\n'，于是瞬间读走并赋予 grade，程序完全不会停下来等待用户键入！

本节小结与核心要点

  1. 库函数性质：C 语言本身没有 I/O 语句，输入输出依赖 <stdio.h>。
  2. printf 默认小数：%f 默认输出 6 位小数；%.2f 强制指定保留 2 位小数。
  3. scanf 必须带 &：普通变量前必须加 & 取地址；数组名本身即首地址不需加 &。
  4. 缓冲区残存回车：%d 读取后遗留的 \n 会被后续 %c 误读；利用 getchar() 吸收或 scanf(" %c") 前导空格规避。
  5. 字符 I/O 利器：getchar() 逐字符流读取，putchar() 快速单字符输出。
