# 计算机网络讲授提示

学生没有配套讲义。四个学生页面必须独立提供术语定义、例子、图示、练习与判断依据；课堂讲授和课后阅读都不应依赖打开参考仓库或 PDF。

## 课程取材

内容借鉴了 [Introduction to Computer Networking 第一单元讲义镜像](https://github.com/khanhnamle1994/computer-networking) 的概念顺序：应用需求、四层模型、IP 服务、分组交换和封装。学生页面已改用国内学生熟悉的校园网、班级群、铁路查询、国内视频平台等情境。所有具体路径和拓扑均标为教学模型，不声称是真实平台的内部实现。

## 讲授重点

- 先让学生说清“哪个程序向哪个程序要什么”，再引入层次。
- 区分资源路径、端口、IP 地址和当前链路；不要把它们合称“网址”。
- IP 的尽力而为是“没有交付保证”，不等于网络平时不能使用。
- 路由器逐跳处理网络层信息，当前链路帧可能在下一跳改变。
- 404 是应用层响应，不能直接解释为宿舍 Wi-Fi 断开。

## 检查理解

让学生先独立回答页面中的问题，再用页面给出的答案检查理由。最后一节的综合段落可以检验学生是否能把应用、传输、网络、链路及封装连成同一次通信。
