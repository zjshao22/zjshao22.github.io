# 34｜怎样适配一个任务

三个需求分别是“读到本周新通知”“统一回答格式”“学会一种新分类任务”。都去微调，看似统一，却可能把易变事实写进难以追溯的参数，同时花费额外成本。先判断缺的是材料、任务描述，还是参数所表达的能力。

## 先做能定位问题的基线

提示可以规定任务、示例与输出格式；检索把外部材料送入上下文；微调以数据和损失更新参数。这些路线可以组合。若正确材料没有被检到，应先修检索；若现有模型在清楚材料和示例下仍系统性失败，再判断是否值得训练。训练不能补回根本未提供的数据来源。

| 需求           | 优先建立的基线        | 还须检查                       |
| -------------- | --------------------- | ------------------------------ |
| 今日开放安排   | 带版本与来源的检索    | 例外、过期、冲突和拒答         |
| 固定 JSON 格式 | 清晰提示加结构校验    | 内容正确与格式正确分别统计     |
| 稳定专门任务   | 提示/检索后与微调对照 | 标签质量、留出任务、遗忘和成本 |

## LoRA 具体改变哪一块

一层原权重 $W_0\in\mathbb R^{m\times n}$。完整微调更新 $mn$ 个数；低秩适配冻结它，令

$$
W=W_0+BA,\quad B\in\mathbb R^{m\times r},\quad A\in\mathbb R^{r\times n}.
$$

可训练数为 $r(m+n)$，更新矩阵秩至多为 $r$。这里省略常见的缩放因子，教学实验等价于缩放为 1；真实配置需另记录。低秩限制是选择，不意味着所有任务的最佳改变都恰好低秩。[LoRA 原论文](https://arxiv.org/abs/2106.09685)讨论的语言模型结果也有具体任务与基模型条件。

取 $W_0=I_2$，$A=[1,2]$，$B=[0.1,0.2]^T$，则 $BA=\begin{bmatrix}0.1&0.2\\0.2&0.4\end{bmatrix}$。对输入 $x=(1,0)^T$，原输出为 $(1,0)^T$，适配后为 $(1.1,0.2)^T$。这组手填权重只演示表示方式，训练证据在实际实验中。

一般会让 A 随机而 B 初始为零，使起点仍是原模型。若两者都为零，在普通乘积参数化下，两边初始梯度也可能都为零，无法启动。反向传播通过 $B(Ax)$ 更新两个小矩阵，冻结基础权重不等于整个计算图无须前向或反向。

## 真实适配与蒸馏分别看什么

[L7](/docs/ai/lab-07-resources-and-adaptation) 先训练一个 $4\times8$ 线性网络，再冻结它，用 rank 1 更新适配构造的新目标。完整更新 32 参数，低秩更新 12 参数；输出含训练前后哈希、留出误差和全量微调对照。新目标特意由 rank 1 扰动构成，适合验证机制，不能据此宣布 rank 1 对任何任务足够。

蒸馏则让学生模型模仿教师的输出或分布。对固定输入，教师分布 $p_T$、学生分布 $p_S$，可最小化 $-\sum_i p_T(i)\log p_S(i)$；相对硬标签，它保留多个候选的相对概率。也可用教师示范序列训练，但教师错误会传递，筛选与独立评测不可省。缩小模型、量化、蒸馏与 LoRA 改变的对象不同，不应混称一个操作。

教师先给上述三个需求，让学生选择最小可检验路线；学生再跑真实低秩更新，检查基础权重未变。调参用训练/验证数据，最终测试用于报告；若反复看测试再调 rank，这份测试已经参与选择。

## 学生任务：低秩一定更省吗

一个 $8\times16$ 矩阵，rank 2、rank 8 的可训练参数分别多少？只按参数数目，哪种少于完整更新？

<summary>提示一：先确认两个小矩阵形状</summary>

B 为 $8\times r$，A 为 $r\times16$。完整更新是 $8\times16$。

</details>

<details>
<summary>提示二：比较 24r 与 128</summary>

rank 2 为 48，rank 8 为 192。低秩参数化也可能在维度过小时超过完整更新。

</details>

<details>
<summary>完整解析与验收</summary>

rank 2 比完整更新少 80；rank 8 反而多 64。参数少还不能直接等同训练峰值、速度或质量更好；验收同时报告留出误差、基础权重哈希与测量口径。

</details>

## 独立变式

适配后新任务提高，旧任务下降，能否只提交新任务结果？

<details>
<summary>独立完成后核对</summary>

应同时报告旧任务回归和新任务收益；分析数据混合、学习率与适配容量，并按实际用途决定取舍。保留原模型和适配器版本，能回退不等于旧能力从未受损。

</details>
