真实 · 127.0.0.1 回环套接字

真实（本页）

mode: "real"、host: "127.0.0.1"。Python 真实调用 bind / connect / accept / sendto / recvfrom / sendall / recv / shutdown，保存运行环境与真实输出后在此回放。

观察的是 socket API 的返回值，不是抓包；不产生 .pcap，不读取链路分组，不做内核 TCP 状态内省，也不是完整 TCP 实现（无拥塞控制、重传、窗口）。

模拟 · 离散事件模型

模拟（主实验台）

网络实验台的 18 个预设是 JavaScript 离散事件网络模型，不创建任何真实 socket，用虚拟时间推演路由、NAT、TCP 子集等。请始终把它当作模拟。

模型结果由配置计算，不是链路上抓到的报文。真实运行成功也不能反过来证明模型参数符合任何真实网络。

边界提醒：本机 127.0.0.1 回环收发成功，只说明本机协议栈对这组 API 调用的实际返回，不能证明公网或校园网的丢包、延迟、乱序、拥塞行为；本页不验证这些性质。端口、时间戳、recv() 块长每次运行都会变化。
