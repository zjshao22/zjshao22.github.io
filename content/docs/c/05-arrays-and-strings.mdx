# 数组、字符数组与字符串处理

在之前的学习中，每个变量只能存储一个孤立的数据。如果需要处理一个班级 50 名学生的成绩，定义 50 个变量 `score1, score2, ...` 将导致代码极其冗余繁杂。

**数组（Array）**是 C 语言中用来在内存中开辟一段**连续的物理存储空间**，以存放相同数据类型元素的数据结构。

本节深入解析一维数组与二维数组的内存布局、下标规则，重点掌握数组极值检索算法、字符数组与字符串终止符机制，以及经典单词统计状态机的工程实现。

---

## 一、一维数组的定义、内存特征与初始化

### 1. 一维数组的定义语法

```c
类型说明符 数组名[常量表达式];
```

例如：`int a[10];` 表示定义了一个包含 10 个整型元素的一维数组。

<Callout type="error" title="极高频关键陷阱：C 语言下标从 0 起算！">
  - 包含 10 个元素的数组 `int a[10];`，其合法下标范围是 **`0` 到 `9`**（即
  `a[0], a[1], ..., a[9]`）！ - **绝对不存在 `a[10]` 这个元素**！ - **C
  语言编译器不做任何数组下标越界检查**！越界读写会导致读取脏数据，甚至覆写关键内存引起程序崩溃。

</Callout>

### 2. 数组的内存特征与首元素地址

在内存中，数组的所有元素是**紧密相邻、线性连续存放**的：

- 在常见平台上（若假设 `int` 占 4 字节），若 `a[0]` 的地址为 `0x2000`，则 `a[1]` 的地址必然为 `0x2004`，以此类推。
- **数组名与首元素指针**：在大多数表达式上下文中，数组名 `a` 会隐式转换为指向其首元素的指针（即 `a` 退化为 `&a[0]`）。
- **关键辨析（数组不是指针常量）**：数组是一个完整的复合数据类型，而不是指针对象。在两个特殊上下文中数组名**绝不会**退化为指针：
  1. `sizeof(a)`：求的是**整个数组占据的总字节数**（如 $5 \times 4 = 20$ 字节），而不是指针本身的大小；
  2. `&a`：取的是**整个数组的地址**，其类型是指向整个数组的指针（如 `int (*)[5]`），指针步长是整个数组长度。
- 数组名不能被赋值（如 `a = b;` 非法），是因为 C 语言语法禁止对数组整体进行直接赋值。

### 3. 数组的初始化方式

```c
int a[5] = {1, 2, 3, 4, 5}; // 完全初始化
int b[5] = {1, 2};          // 不完全初始化：前两个为 1, 2，后面自动补 0！
int c[] = {1, 2, 3};        // 省略长度：编译器根据初始项数量自动推断长度为 3
```

## 二、实战案例：数组求 10 个数中的最大值及位置

**任务描述**：用数组的方法，求 10 个整数中的最大值，以及它所在的序号（位置从 1 开始，即下标加 1）。

### 算法思路与打擂台法

1. 输入 10 个数存入数组 `a[0] ~ a[9]`。
2. 设定打擂台初始擂主：假设第一个元素 `a[0]` 是最大值，`max = a[0]`，其所在序号 `max_i = 1`。
3. 从第二个元素（下标 `j = 1`）开始遍历到下标 9，一旦发现 `a[j] > max`，立即更新擂主：
   `max = a[j]; max_i = j + 1;`。

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    int a[10]; // 定义含 10 个元素的数组变量
    int i, j, max, max_i;

    printf("input 10 numbers:\n");
    for (i = 0; i < 10; i++)
        scanf("%d", &a[i]);

    printf("\n");
    max = a[0];
    max_i = 1;

    for (j = 1; j <= 9; j++)
    {
        if (a[j] > max)
        {
            max = a[j];
            max_i = j + 1;
        }
    }

    printf("the max number is %d, it locate at %d.\n", max, max_i);
    return 0;
}
```

## 三、二维数组的定义与存储规则

二维数组常用于表示数学矩阵、表格数据：

```c
int a[3][4]; // 3 行 4 列的二维数组，共 12 个元素
```

- **行优先连续存储**：在物理内存中，二维数组是按“第 0 行所有元素 $\to$ 第 1 行所有元素 $\to$ 第 2 行所有元素”顺序连续存放的。
- **维度定义规则**：二维数组初始化时，**第一维（行数）可以省略，但第二维（列数）绝对不能省略**！
  - 正确：`int a[][4] = {{1,2}, {3,4}};` ✔（编译器通过列数自动推算出行数）
  - 错误：`int a[3][] = ...;` ❌（列数未知无法计算单行跨度，编译报错！）

## 四、字符数组与字符串终止符 '\0' 的秘密

在 C 语言中，没有原生的 `string` 数据类型，**字符串本质上就是一个以空字符 `'\0'` 结尾的字符数组**。

<StringArrayMemoryFigure />

### 1. 字符数组 vs 字符串

```c
char a[] = {'C', 'h', 'i', 'n', 'a'};        // 纯字符数组，占用 5 字节，不是合法字符串！
char b[] = "China";                          // 字符串字面量，末尾自动追加 '\0'，占用 6 字节！
```

<Callout type="warn" title="缺少 '\0' 的致命灾难">
  当你使用 `printf("%s", a)` 输出字符串时，`printf`
  会顺着内存地址一个字节一个字节往下读，**直到读到数值为 0 的 `'\0'`
  才会停止**！如果字符数组末尾没有
  `\0`，它将一直越界读取内存中的乱码，直到触发内存保护段错误（Segmentation
  fault）！

</Callout>

## 五、实战案例：统计一行字符串中的单词个数（状态机）

**任务描述**：输入一行字符，统计其中有多少个单词，单词之间用空格分隔开。

### 状态机标志位法（Flag）

如何准确识别单词？不能单纯统计空格数量（连续多个空白或开头结尾的空白会导致误判）。
我们引入标志位 `word`，并将空格 `' '`、制表符 `'\t'` 以及 `fgets` 保留的换行符 `'\n'` 等均作为**空白分隔符**：

- `word == 0`：表示当前处于**空白间隔区**。
- `word == 1`：表示当前处于**单词内部**。
- **状态转移**：
  1. 如果当前字符是空白分隔符（空格、Tab、换行符） $\implies$ 让 `word = 0`。
  2. 如果当前字符是常规可见字符，且此前 `word == 0` $\implies$ 说明遇到了**新单词的第一个字符**！此时单词计数器 `num++`，并将 `word = 1`！

<WordStateMachineFigure />

### 核心实现代码

```c
#include <stdio.h>

int main()
{
    char string[81];
    int i, num = 0, word = 0;
    char c;

    // 从标准输入读取一行字符串（检查返回值，规避直接 EOF 或读取失败导致的未初始化访问）
    if (fgets(string, sizeof(string), stdin) == NULL)
    {
        printf("There are 0 words in this line.\n");
        return 0;
    }

    // 遍历直到字符串结尾 '\0'；正确处理空格、制表符及行尾 '\n'
    for (i = 0; (c = string[i]) != '\0'; i++)
    {
        if (c == ' ' || c == '\t' || c == '\n' || c == '\r')
        {
            word = 0;                         // 遇到空白分隔符，标记处于间隔区
        }
        else if (word == 0)                   // 首次进入新单词
        {
            word = 1;                         // 标记进入单词
            num++;                            // 单词计数累加 1
        }
    }

    printf("There are %d words in this line.\n", num);
    return 0;
}
```

## 六、字符串标准库函数：string.h

进行字符串操作时，只需引入 `#include <string.h>`：

### 1. `strlen(str)` —— 计算字符串有效长度

- 统计从首地址开始直到遇到第一个 `'\0'` 之前的有效字符个数（**不包括 `'\0'` 本身**）。
- 对比：`sizeof("hello")` 为 6（包含 `\0`），而 `strlen("hello")` 为 5。

### 2. `strcpy(dest, src)` —— 字符串拷贝

- 将 `src` 字符串（包含末尾的 `'\0'`）完整复制到 `dest` 数组中。
- **规范**：`dest` 必须有足够大的容量，否则会发生严重的缓冲区溢出！不能写 `str1 = str2;`（C 语言中数组对象不能整体赋值，需通过库函数逐字节拷贝）。

### 3. `strcmp(str1, str2)` —— 字符串比较

- 按照字符 ASCII 码字典序自左向右逐字节比较：
  - 若 `str1 == str2`，返回 `0`。
  - 若 `str1 > str2`，返回正整数（`> 0`）。
  - 若 `str1 < str2`，返回负整数（`< 0`）。
  - 严禁使用 `str1 == str2` 比较内容（那比较的是两个数组的内存首地址是否相同）！

### 4. `strcat(dest, src)` —— 字符串拼接

- 将 `src` 拼接在 `dest` 原有内容（覆盖掉原 `dest` 的 `'\0'`）之后，并在新末尾添加 `'\0'`。

## 本节小结与核心要点

1. **下标越界无校验**：`int a[10]` 的下标是 0~9，使用 `a[10]` 属严重越界。
2. **二维数组缺省规则**：行数可省，列数绝不能省（如 `int a[][3]` 合法）。
3. **字符串灵魂标志**：末尾必须带 `'\0'`（ASCII 为 0）。
4. **strlen vs sizeof**：strlen 算字符个数不含 `\0`；sizeof 算数组总内存大小包含 `\0`。
5. **单词统计状态机**：标志位 `word` 监控空格交替，首入字母时累加计数。
