# 数据类型、常量变量与表达式计算

在 C 语言中，任何数据在内存中都有其特定的存储形式和字节长度。作为程序员，必须明确知道你的数据在底层占用了多少字节，以及各种数学和逻辑操作是如何在 CPU 中被计算求值的。

---

## 一、标识符命名规则与 C 语言关键字

**标识符（Identifier）** 是程序员为变量、函数、数组、自定义类型等起的名称。

### 1. 标识符的三大刚性规则

1. **只能由英文字母（A-Z, a-z）、数字（0-9）和下划线（`_`）组成**。
2. **第一个字符必须是字母或下划线，绝不能以数字开头**！
3. **不能与 C 语言的系统保留关键字（Keyword）重名**。
4. C 语言**严格区分大小写**（例如 `count`、`Count`、`COUNT` 是三个完全互不相干的标识符）。

| 常见标识符示例                       | 合法性判定  | 原因说明                           |
| :----------------------------------- | :---------: | :--------------------------------- |
| `_sum`、`student_name`、`totalScore` | **合法** ✔  | 字母或下划线开头，仅含允许字符     |
| `3days`、`2026_exam`                 | **非法** ❌ | **以数字开头**                     |
| `a-b`、`my score`、`num#1`           | **非法** ❌ | 包含了减号 `-`、空格或特殊符号 `#` |
| `int`、`return`、`void`、`while`     | **非法** ❌ | 属于 C 语言系统保留关键字          |

## 二、基本数据类型与内存大小

C 语言提供了简洁而强有力的数据类型系统。C 标准仅规定了各类型的相对大小关系（如 $sizeof(short) \le sizeof(int) \le sizeof(long)$，且 $sizeof(char) \equiv 1$ 字节）；普通 `char` 是有符号还是无符号取决于编译器和平台实现。下表列出的是主流现代计算平台（x86-64 / ARM64）下的**典型数据模型**（LP64 / LLP64）：

| 数据类型关键字        | 中文名称     |       典型字节大小 (sizeof)       | 典型取值范围与特点                                |
| :-------------------- | :----------- | :-------------------------------: | :------------------------------------------------ |
| `char`                | 字符型       |          1 字节 (8 bit)           | `-128 ~ 127`（有符号时），存储对应的 **ASCII 码** 整数 |
| `short` / `short int` | 短整型       |          2 字节 (16 bit)          | `-32,768 ~ 32,767`                                |
| `int`                 | 基本整型     |          4 字节 (32 bit)          | `-2,147,483,648 ~ 2,147,483,647` (约 $\pm 21$ 亿) |
| `long` / `long int`   | 长整型       | 4 字节 (Win) / 8 字节 (Unix 64位) | 满足 $sizeof(long) \ge sizeof(int)$               |
| `float`               | 单精度浮点型 |          4 字节 (32 bit)          | 约 6~7 位有效十进制数字                           |
| `double`              | 双精度浮点型 |          8 字节 (64 bit)          | 约 15~16 位有效十进制数字                         |

### 核心机制：字符型 char 的本质就是小型整数！

在 C 语言中，字符常量用**单引号**括起来（如 `'A'`）。字符在内存中并不存储“图形形状”，而是直接存储其在 ASCII 编码表中的整型数值：

- `'0'` 的 ASCII 码是 **48**
- `'A'` 的 ASCII 码是 **65**
- `'a'` 的 ASCII 码是 **97**
- 大小写字母转换公式：`'a' - 'A' = 32`，小写转大写只需减去 32：`ch = ch - 32;`。
- 字符与数字可以自由混合做加减运算！例如：`'B' - 'A' == 1`，`'9' - '0' == 9`。

## 三、常量与字面量辨析

### 1. 整型常量的三种表示法

- **十进制**：如 `100`, `-50`。
- **八进制**：以数字 `0` 开头，如 `012`（换算为十进制是 $1 \times 8^1 + 2 \times 8^0 = 10$）。
- **十六进制**：以 `0x` 或 `0X` 开头，如 `0x1A`（换算为十进制是 $1 \times 16 + 10 = 26$）。

### 2. 字符常量、字符对象 vs 字符串字面量

这是日常开发与底层理解中最容易被混淆的概念，需要从语言标准层面厘清三者的区别：

1. **整数字符常量（如 `'a'`）**：
   - 在 C 语言标准（C11 §6.4.4.4）中，单引号括起来的普通字符常量其类型是 **`int`** 而不是 `char`！
   - 因此在主流环境中执行 `sizeof('a')`，结果通常等于 `sizeof(int)`（4 字节）。
2. **字符变量对象（如 `char c = 'a';`）**：
   - 变量 `c` 的类型是 `char`，C 语言保证 $sizeof(char) \equiv 1$ 字节。
3. **字符串字面量（如 `"a"`）**：
   - 双引号括起来的字符串由若干字符和系统自动在末尾附加的空终结符 **`'\0'`** 组成。
   - `"a"` 本质是一个包含 `'a'` 和 `'\0'` 的 `char[2]` 数组，因此 `sizeof("a")` 占 **2 个字节**！

```c
char c = 'A';       // sizeof(c) 为 1 字节
char str[] = "A";   // sizeof(str) 为 2 字节（包含 'A' 和 '\0'）
// 注：在 C 中 sizeof('A') == sizeof(int)（通常为 4）
```

## 四、核心运算符与表达式计算

### 1. 算术运算符与整数除法陷阱

算术运算符包括：`+`、`-`、`*`、`/`、`%`。

<Callout type="warn" title="高频易错陷阱：除法截断与取模规则">
  1. **整数相除向零截断**：如果两个操作数都是整数，`5 / 2` 的结果是**2** 而不是
  2.5！只有当至少有一个操作数是浮点数时（如 `5.0 / 2` 或 `5 /
  2.0`），结果才是浮点数 `2.5`。 2. **取模运算 `%` 的两边必须是整数**：`5 % 2`
  结果为余数 `1`；像 `5.5 % 2` 或 `5 % 2.0` 在语法上是**非法报错**的！

</Callout>

### 2. 自增自减运算符：`++` 与 `--`

- `++i`（前置自增）：**先加后用**。变量 i 先自增 1，然后将新值作为整个表达式的值。
- `i++`（后置自增）：**先用后加**。先将变量 i 当前的原值作为表达式的值参与运算，随后 i 自身再增加 1。

```c
int a = 5, b, c;
b = ++a; // a 变成 6，b 得到 6
c = a++; // c 得到 6，a 变成 7
```

/>

### 3. 关系运算符与逻辑运算符

- 关系运算符：`<`、`>`、`<=`、`>=`、`==`（等于）、`!=`（不等于）。
- 逻辑运算符：
  - `&&`（逻辑与）：两边均为真时结果为真（1）。
  - `||`（逻辑或）：只要有一边为真，结果就为真（1）。
  - `!`（逻辑非）：单目运算符，真变假，假变真。

<Callout type="idea" title="逻辑短路求值原则（Short-Circuit Evaluation）">
  - 在 `A && B` 中，如果表达式 `A`
  为假（0），整个表达式已经注定为假，编译器**绝不再去计算表达式 B**！ - 在 `A ||
  B` 中，如果表达式 `A`
  为真（非0），整个表达式已经注定为真，编译器**绝不再去计算表达式 B**！

</Callout>

### 4. 三目条件运算符：`? :`

语法格式：`条件表达式 ? 表达式1 : 表达式2`
含义：若条件为真，取“表达式1”的值；若条件为假，取“表达式2”的值。

```c
int max = (a > b) ? a : b; // 一行代码求两数最大值
```

### 5. `sizeof` 运算符

`sizeof` 是一个编译期或运行期运算符，用于获取某种数据类型或表达式在内存中所占的字节数：
- 对于普通基础类型、固定大小结构体和定长数组，`sizeof` 是**编译期常量表达式**，在编译时由编译器直接计算，不消耗运行时 CPU；
- **例外注意**：当操作数涉及 C99 引入的**变长数组（VLA）**时，`sizeof` 会在**运行时**动态计算数组实际长度占用的字节数。

```c
printf("%zu\n", sizeof(int));    // 典型平台输出 4
printf("%zu\n", sizeof(double)); // 输出 8
```

|     **2**      | 单目运算符 | `!` 逻辑非、`~` 按位取反、`++` 自增、`--` 自减、`-` 负号、`*` 解引用、`&` 取地址、`sizeof` | **自右向左** |

|     **4**      | 算术加减   | `+` 加、`-` 减                                                                             |   自左向右   |
|     **5**      | 移位运算   | `<<` 左移、`>>` 右移                                                                       |   自左向右   |

## 本节小结与核心要点

1. **命名合法性**：字母或下划线开头，仅包含字母、数字和下划线，避开关键字。
2. **ASCII 基准值**：`'0'` 为 48，`'A'` 为 65，`'a'` 为 97。大小写差 32。
3. **字符与字符串存储**：`char` 变量占 1 字节；字符串 `"A"` 带末尾 `\0` 占 2 字节（注：字符常量表达式 `'A'` 在 C 中类型为 `int`）。
4. **整数除法与取模**：`5 / 2` 为 2；`%` 必须作用于整型。
5. **优先级要诀**：初等运算符最高，单目/三目/赋值自右向左，算术高于关系，关系高于逻辑，赋值最低仅高于逗号。
