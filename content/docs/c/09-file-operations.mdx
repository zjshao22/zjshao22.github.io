# 文件操作与数据持久化

在之前编写的所有程序中，变量和数组均存放在计算机的随机存取内存（RAM）中。一旦程序执行完毕退出，或者电脑关机断电，内存中的数据就会**彻底灰飞烟灭**。

为了将计算结果、学生档案或用户日志长久保存下来，我们必须将数据写入外存磁盘中——这就是**文件（File）操作与数据持久化**。

本节深入解析文本文件与二进制文件的底层差异、FILE 文件指针结构、fopen 打开模式权限规范以及字符、字符串、格式化与数据块级读写操作。

---

## 一、文件的分类：文本文件 vs 二进制文件

在 C 语言中，操作系统将外存文件视为一个有序的**字节序列（流式文件，Stream）**。根据数据的组织与编码形式，文件分为两大类：

| 文件类别                  | 存储编码形式                                 | 优缺点对比                                                                              | 典型应用与后缀                 |
| :------------------------ | :------------------------------------------- | :-------------------------------------------------------------------------------------- | :----------------------------- |
| **文本文件 (ASCII 文件)** | 每个字节保存一个字符的 **ASCII 码**          | 可用任意文本编辑器（如记事本、VS Code）直接打开阅读；但数值数据占空间大，读写时需要转换 | `.txt`、`.c`、`.csv`、`.json`  |
| **二进制文件**            | 按照数据在内存中的**底层二进制原样**存入磁盘 | 极其紧凑省空间，读写速度极快；但人类无法直接阅读（记事本打开是乱码）                    | `.bin`、`.dat`、`.jpg`、`.exe` |

例如整数 `10000`：

- 在**文本文件**中保存为 5 个 ASCII 字符 `'1'`, `'0'`, `'0'`, `'0'`, `'0'`，占用 **5 个字节**。
- 在**二进制文件**中直接以 `int` 的 4 字节二进制原样存储，仅占 **4 个字节**。

## 二、文件指针 FILE\* 与 fopen() 打开模式

### 1. 文件指针：`FILE *fp`

C 标准库在 `<stdio.h>` 中预定义了一个名为 **`FILE`** 的结构体类型。它记录了被操作文件的缓冲区地址、读写当前位置、打开模式和状态标志等信息。
操作文件时，我们始终通过指向该结构体的指针变量（**`FILE *fp;`**）来与文件流进行交互。

### 2. 文件打开函数：fopen()

```c
FILE *fopen(const char *filename, const char *mode);
```

- `filename`：要打开的文件路径及文件名（如 `"data.txt"`）。
- `mode`：打开模式字符串。
- **返回值**：若打开成功，返回指向该文件的有效 `FILE*` 指针；**若打开失败，返回 `NULL`（空指针）**！

### 3. 核心打开模式深度辨析

|          模式字符串          | 含义                       | 文件已存在时的行为                           | 文件不存在时的行为   |
| :--------------------------: | :------------------------- | :------------------------------------------- | :------------------- |
|          **`"r"`**           | 只读 (Read) 打开文本文件   | 正常打开，光标位于文件开头                   | **出错返回 NULL** ❌ |
|          **`"w"`**           | 只写 (Write) 打开文本文件  | **强行清空并销毁原有全部内容！**             | **新建一个空文件** ✔ |
|          **`"a"`**           | 追加 (Append) 打开文本文件 | 保留原有内容，光标位于文件末尾               | 新建一个空文件 ✔     |
| **`"rb"` / `"wb"` / `"ab"`** | 二进制方式打开             | 规则与上述对应模式完全相同，仅以二进制流处理 | —                    |
| **`"r+"` / `"w+"` / `"a+"`** | 读写模式打开               | 允许同时进行读和写操作                       | 规则同基准模式       |

> [!CAUTION] 极高频关键陷阱
>
> 1. 用 `"r"` 读取文件前，**必须做非空校验**：若文件不存在，fopen 会返回 `NULL`，此时直接操作野指针会导致程序崩溃！
> 2. 用 `"w"` 打开已存在的文件，会**无情抹掉原文件所有内容**！如果想在原文件后面续写，必须使用追加模式 `"a"`！

```c
FILE *fp = fopen("students.txt", "r");
if (fp == NULL) {
    printf("错误：文件打开失败或文件不存在！\n");
    return 1;
}
```

## 三、文件关闭规范：fclose()

文件操作完毕后，必须显式调用 `fclose()` 关闭文件：

```c
int fclose(FILE *fp);
```

### 为什么必须及时关闭文件？

1. **缓冲区刷新（Flush）**：为了提高 I/O 效率，写文件时数据先暂存在操作系统内存缓冲区中。调用 `fclose()` 会强制将缓冲区内残留的所有数据立刻刷盘写入物理磁盘！
2. **释放操作系统资源**：操作系统对单个进程同时打开的文件数量有严格限制。不关闭文件会导致文件描述符泄漏。

## 四、常用文件读写函数族

C 语言标准库提供了不同粒度的丰富读写函数：

<FileFunctionsTreeFigure />

### 1. 字符与行读写：fgetc 与 fgets

```c
// 读取单个字符，读到文件末尾时返回 EOF (-1)
int ch = fgetc(fp);

// 从文件安全读取一行字符串（最多读 sizeof(buf)-1 个字符，保留换行符）
char buffer[128];
while (fgets(buffer, sizeof(buffer), fp) != NULL) {
    printf("%s", buffer);
}
```

### 2. 格式化文件读写：fprintf 与 fscanf

用法与 `printf`/`scanf` 几乎一模一样，唯独在参数首位多了一个 `FILE *fp`：

```c
// 向文件写入学生成绩
fprintf(fp, "%d %s %.1f\n", 1001, "Alice", 95.5f);

// 从文件读取解析数据
int id;
char name[20];
float score;
fscanf(fp, "%d %s %f", &id, name, &score);
```

### 3. 二进制数据块读写：fread 与 fwrite

用于将内存中的结构体、数组整个内存块一次性持久化到磁盘：

```c
size_t fwrite(const void *ptr, size_t size, size_t count, FILE *stream);
size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
```

- `ptr`：内存缓冲区的首地址。
- `size`：每个数据项的字节数（如 `sizeof(Student)`）。
- `count`：要读写的数据项个数。
- `stream`：文件指针。

```c
struct Student s = {1001, "Bob", 'M', 90.0f};
// 将结构体变量 s 整体写入二进制文件
fwrite(&s, sizeof(struct Student), 1, fp);
```

## 本节小结与核心要点

1. **流式文件特征**：C 语言以连续字节流的形式组织文件。
2. **两类文件本质**：文本文件存 ASCII 码；二进制文件存原始物理位。
3. **fopen 返回值**：成功返回 `FILE*`，失败返回 `NULL`。
4. **模式特性**：`"r"` 不存在报错；`"w"` 存在清空；`"a"` 末尾追加。
5. **fclose 必执行**：强制将内存缓冲区数据刷入磁盘，避免数据丢失。
