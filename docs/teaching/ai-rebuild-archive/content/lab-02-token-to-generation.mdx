# L2｜从词元到生成

对应 06—12 单元。需要 L1 的梯度与更新概念。问题是：当前最后一个词元相同，模型能否依据前文给出不同答案？只看相邻词元的计数基线在这里不足。

## 明确任务和真实训练对象

词表为 `^abcd?;`，构造序列形如 `^a?a;`。其中 `^a?` 是请求式前缀，后面的 a 是复制目标，`;` 为结束。前缀 `^a?` 与 `^b?` 的末词元同为 `?`，目标却不同。模型有嵌入、学习位置、因果注意力、归一化、前馈、残差与输出层；它不是只返回预设答案的脚本。

```sh
python3 -B ai_lab.py l2 --output ./runs/l2 --seed 42
```

程序执行小语料 BPE 演示、真实 Transformer 训练、遮挡对照、检查点保存重载与采样。BPE 演示和字符复制任务是不同数据环节，不要将合并出的子词表当作复制网络词表。

## 观察哪些状态

教师先让学生预测两种前缀应输出什么，再展示 `history`、`copy_probes` 与检查项。学生检查训练前后参数哈希、交叉熵、注意力各行和为 1、未来位置改变是否影响早期输出，以及重载后同输入是否一致。

从 JSON 检查点可以恢复参数；恢复的模型还要配相同结构与词表。程序的重载检查是实际赋值后前向比较，不能用“文件已经写出”替代。采样对照需保留种子、温度、概率和逐步选择，生成随机性与训练随机性分开说。

## 学生任务与验收

手画 `^a?` 三个输入位置的可见性矩阵，复算其中一行 softmax，并指出复制成功需要哪段上下文。提交实际训练曲线、重载检查、两种采样结果与能力限制：四字母复制不代表自然语言理解，探针也不是陌生语义泛化题。

<details>
<summary>提示一：因果可见性是下三角</summary>

第一个位置看自身，第二个看前两个，第三个看前三个。不能看未来答案位置。

</details>

<details>
<summary>提示二：生成时目标尚未进入输入</summary>

在 `^a?` 后预测 a 时，网络可读取早先的 a；如果拿掉前文，单凭 `?` 无法区分四种目标。

</details>

<details>
<summary>完整解析与最低验收</summary>

矩阵依次为 `100`、`110`、`111`，它是可见性表而非注意力概率。合格报告把矩阵、归一化权重、生成候选分开，并保留真实训练和重载证据。

</details>

## 独立变式

在复制出的源码中取消位置或改变遮挡，只改一项；先写预期，再观察损失、复制和因果测试。若指标变化很小，解释这个小任务能否区分假设，而非直接宣布位置或遮挡永远无用。下一实验比较监督与偏好等训练信号。
