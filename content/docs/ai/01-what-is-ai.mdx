## 一、人工智能是什么

> **人工智能(Artificial Intelligence,AI)**——研究如何让计算机去做那些“原本需要人的智能才能完成的事”的学科:看、听、说、读、写、推理、学习、决策。

“人工”强调它由人造出来,“智能”是它的目标。这个名词 1956 年才正式诞生,但 AI 早已悄悄住进你的生活:

<DataGrid
  caption="你身边的人工智能"
  items={[
    { value: "语音助手", note: "听懂你的话,帮你设闹钟、查天气" },
    { value: "人脸识别", note: "刷脸解锁手机、刷脸支付" },
    { value: "拍照识花", note: "拍一张照片,告诉你这是什么花" },

    { value: "AI 写作助手", note: "帮你润色作文、修改病句" },
  ]}
/>

这些功能看起来各不相同。如今许多识别、生成类 AI 使用**机器学习**：人提供数据和目标，模型在训练中调整参数，从数据中找到有用的规律。不过，AI 也包括由人整理知识和推理规则的专家系统；第 6 课会讲清它们的关系。

### 1. AI 与普通程序的区别

用“计算器”和“识猫 App”对比一下:

|              | 计算器(普通程序)     | 识猫 App(AI 程序)                |
| ------------ | -------------------- | -------------------------------- |
| 怎么工作     | 人写好运算规则       | 用带标签的照片训练模型参数       |
| 新本领从哪来 | 要由人修改规则和程序 | 可以用新数据重新训练模型         |
| 遇到新输入   | 按既定规则算出结果   | 根据学到的规律作预测，也可能认错 |

> 这里对比的是普通计算器和**机器学习式**的识图程序。不能据此说“凡是按规则工作的系统都不是 AI”：专家系统同样属于人工智能。

## 二、怎么判断机器“会思考”?——图灵测试

“机器能不能思考?”这个问题很难直接回答——连“思考是什么”都说不清。1950 年,英国数学家**图灵**换了个聪明的问法:**怎么判断?**

<DataShowcase
  value="隔着一堵墙聊天,你能分辨对方是人还是机器吗?"
  caption="图灵测试的原始设定:打字交流,不看脸、不听声"
/>

图灵设想了一个“模仿游戏”:一个人坐在房间里,和幕布另一头的对象纯文字聊天。聊得足够久之后,如果他**分辨不出**对面到底是人还是机器,就说明这台机器通过了测试,具备了“会思考”的能力。

这个思想实验后来被称为**图灵测试**,成为衡量机器智能的经典标尺。

<Quiz
  question="图灵测试主要考察机器的什么能力?"
  options={[
    "A 计算速度有多快",
    "B 对话表现能不能骗过真人",
    "C 有没有真实的感情",
    "D 会不会下棋",
  ]}
  answer="对话表现能不能骗过真人"
  explanation="图灵测试比的是“聊天能不能以假乱真”——它考察的是行为表现,而不是机器内心有没有意识。"
/>

> 注意:图灵测试考察的是**表现**,不是**内心**。“会聊天”和“真理解”是不是一回事?这是 AI 领域吵了几十年的问题,第 4 课我们会专门讨论。

## 三、弱人工智能与强人工智能

把所有 AI 按“本事大小”分两类,能帮我们看懂各种新闻:

<DataGrid
  caption="弱 AI 与强 AI"
  items={[
    { value: "弱人工智能", note: "只擅长一件事:下棋的不会聊天,认脸的不会写诗" },
    {
      value: "强人工智能",
      note: "像人一样啥都能学啥都能干——目前只存在于科幻片里",
    },
  ]}
/>

- **弱人工智能(专用 AI)**:只会干好一件(或几件)专门的事。AlphaGo 围棋天下无敌,但让它写作文就抓瞎了。
- **强人工智能(通用 AI,AGI)**:能像人一样理解、学习、迁移,做什么都行——这是 AI 研究的终极梦想,现实中还没有出现。

<Quiz
  question="人脸识别门禁属于哪一类人工智能?"
  options={["A 强人工智能", "B 弱人工智能", "C 通用人工智能", "D 超人工智能"]}
  answer="弱人工智能"
  explanation="它会认脸,但不会聊天、不会写诗——只擅长一件事,是典型的弱人工智能。"
/>

> **今天你遇到的每一个 AI,都是弱人工智能。** 那些“AI 觉醒了”“机器人造反了”的新闻,大多是把科幻当成现实了。
