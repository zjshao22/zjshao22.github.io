机器怎样从数据中学习

认识了人工智能能做什么、经历了怎样的发展。接下来的问题是：给计算机一张租房记录表，它究竟怎样从表中得到预测新房租金的能力？“学习”如果只是一个比喻，就无法回答这个问题。本课把数据、模型、误差、参数更新和检验连成一条可以逐步计算的链。

讲授时始终使用同一组虚构数据；所有数值都服务于说明原理，不代表真实城市的房租。

1. 先把“学习”说准确

人工智能是任务领域：让机器完成识别、语言处理、规划等通常需要智能的工作。机器学习是其中一种获得能力的办法：人设计任务与模型形式，程序依据数据调整参数。深度学习又是机器学习中的一类方法，主要使用多层神经网络。因此，三者是逐层包含的关系，而不是三个互相竞争的软件名字。

对照一个传统程序：程序员可以直接写“面积乘以 40 再加 400，得到租金”。给同样输入，它永远按这条规则执行。机器学习程序的区别在于，程序员先提供一个带空位的规则，再让数据决定空位中的数。程序写出怎样学习，数据影响学到的参数。 这一点同样适用于下一课拥有大量参数的神经网络。

有答案的训练样本用于监督学习；分析无标签数据的结构也可以学习；依据行动反馈调整策略则属于另一类学习。本课用监督学习，因为它最容易展示一次完整训练。最后我们还会看到：有标签不等于答案无误，训练成功也不等于已经理解了现实原因。

2. 一张表怎样变成学习任务

假设预测同一片区域的小公寓月租金。面积 xxx 的单位是 10 平方米，租金 yyy 的单位是千元。下面是人为编造的六条记录。

房屋面积 xxx实际租金 yyy
A2.01.2
B2.51.4
C3.01.6
D3.51.8
E4.02.0
F4.52.2

一行称为一个样本；用于预测的 xxx 是特征；希望预测的 yyy 是标签。房屋 C 的面积是 30 平方米，月租金是 1600 元。将来遇到新房屋时，输入中只有面积，真实租金尚不知道；模型要给出预测值 y^\hat yy^​。符号上的小帽子就是提醒我们：y^\hat yy^​ 是估计，不是已经观察到的事实。

请注意任务设计里隐藏的限制。现实租金还取决于地段、楼层、装修、交通和日期。模型只收到面积，便无法直接根据这些信息修正预测。反过来，如果把成交之后才知道的“实际月租金”混入输入，离线测试可能漂亮，却根本无法在预测时使用。这叫数据泄漏。开始训练前就要确定预测时究竟能获得什么信息。

数据也要有一致的含义。若有些“租金”包含物业费，有些不包含；有些“面积”是建筑面积，有些是套内面积，同一列便不再表示同一件事。标签可能有测量误差。机器学习不是把任意表格塞进程序就能得到可靠答案，数据定义本身就是建模的一部分。

3. 模型：一个可调整的计算式

表中面积每增加 0.50.50.5，租金增加 0.20.20.2。先用最简单的直线描述这种关系：

y^=wx+b.\hat y=wx+b.y^​=wx+b.

www 是权重，决定面积增加一个单位时预测租金增加多少；bbb 是偏置，决定直线的位置。两者合称模型的参数。表中数据可以由 w=0.4w=0.4w=0.4、b=0.4b=0.4b=0.4 描述。例如 x=3x=3x=3 时，y^=0.4×3+0.4=1.6\hat y=0.4\times3+0.4=1.6y^​=0.4×3+0.4=1.6。给一套 32 平方米的新房屋，x=3.2x=3.2x=3.2，便得到 y^=1.68\hat y=1.68y^​=1.68，也就是预测 1680 元。

这里展示了使用模型作预测的过程，叫推断。推断只把输入带入已确定的参数；它不会因为预测了一次就自动学习。真正的训练要从尚不合适的参数开始，让样本逐步改变它们。

直线是一种模型假设。表中的六个点恰好排在同一条线上，是为了使手算清楚。现实数据会有波动；复杂模型也可能更适合复杂关系。但模型再复杂，都要回答同一个问题：怎样判断参数好不好？

4. 损失：把“预测错了”变成数

假设训练刚开始时 w=0.3w=0.3w=0.3、b=0.4b=0.4b=0.4。对房屋 C，模型的预测是

y^=0.3×3+0.4=1.3,\hat y=0.3\times3+0.4=1.3,y^​=0.3×3+0.4=1.3,

比实际的 1.61.61.6 少了 0.30.30.3，即少预测 300 元。一个常用的误差度量是平方损失：

L(w,b;x,y)=(y^−y)2=(wx+b−y)2.L(w,b;x,y)=(\hat y-y)^2=(wx+b-y)^2.L(w,b;x,y)=(y^​−y)2=(wx+b−y)2.

这一条样本的损失为 (1.3−1.6)2=0.09(1.3-1.6)^2=0.09(1.3−1.6)2=0.09。平方让高估与低估都产生非负损失，并使较大误差受到更重的惩罚：误差从 0.30.30.3 增至 0.60.60.6，损失从 0.090.090.09 增至 0.360.360.36，变为四倍。单位也变成“千元的平方”，因此损失主要用于比较模型，不应直接读成“平均差多少元”。若想用原来的金额单位描述错误，可以另外计算绝对误差。

训练不能只让 C 好看。对 nnn 个样本，平均平方损失是

J(w,b)=1n∑i=1n(wxi+b−yi)2.J(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2.J(w,b)=n1​i=1∑n​(wxi​+b−yi​)2.

训练的目标是寻找使 JJJ 尽量小的参数。平均损失把多条样本放到同一个尺度上，也揭示“学会一条”和“学会一类”之间的差别：只调整到恰好符合房屋 C，可能损害其他房屋的预测。

可以把当前参数 w=0.3,b=0.4w=0.3,b=0.4w=0.3,b=0.4 对六条记录的结果一次算完。预测依次为 1.00,1.15,1.30,1.45,1.60,1.751.00,1.15,1.30,1.45,1.60,1.751.00,1.15,1.30,1.45,1.60,1.75；与标签相比，误差依次为 −0.20,−0.25,−0.30,−0.35,−0.40,−0.45-0.20,-0.25,-0.30,-0.35,-0.40,-0.45−0.20,−0.25,−0.30,−0.35,−0.40,−0.45。平方后求平均，得到

J(0.3,0.4)=0.04+0.0625+0.09+0.1225+0.16+0.20256≈0.1129.J(0.3,0.4) =\frac{0.04+0.0625+0.09+0.1225+0.16+0.2025}{6} \approx0.1129.J(0.3,0.4)=60.04+0.0625+0.09+0.1225+0.16+0.2025​≈0.1129.

这个数描述了当前参数在整批样本上的误差。若选 w=0.4,b=0.4w=0.4,b=0.4w=0.4,b=0.4，这组六条人为排整齐的数据恰好都有零损失。然而在真实数据中，不大可能找到一条穿过所有观测点的直线；训练常是在许多误差之间寻找折中。个别离群记录会因为平方而产生很大影响，这时应调查记录是否有错、是否来自不同市场，也可以考虑另一种损失，而不是盲目要求模型把每个异常点都追上。

表格、模型和损失各有分工：表格提供例子；模型规定如何从输入得到预测；损失规定如何衡量预测的好坏。 选错损失，优化方向也会改变。分类问题通常需要对正确类别的概率打分，不能把所有任务都硬塞进租金的平方误差里。

5. 一次完整的参数更新

损失告诉我们错了多少，却还没有告诉我们 www、bbb 应当怎样改。由于 y^=wx+b\hat y=wx+by^​=wx+b，两个参数都能改变预测。

💡 直观物理理解（旋钮敏感度）： 如果您未学过多元微积分，可以把参数 www 和 bbb 想象成收音机上的两个调谐旋钮。偏导数 ∂L∂w\frac{\partial L}{\partial w}∂w∂L​ 就衡量“当把 www 旋钮顺时针微拧一点时，系统的噪音（损失）是变大还是变小”。

  • 导数为负数：说明调大参数会让损失下降（即“多拧一点会更准”）；
  • 导数为正数：说明调大参数会让损失上升，此时应当调小参数。 梯度下降的精髓，就是沿着让误差变小的反方向（减去梯度），按学习率步长对参数进行微调。公式推导展示了内部严格计算，初学者重点把握“顺着减小误差的方向调参数”即可。

数学上，对单条样本运用复合函数求导，可得偏导数：

∂L∂w=2(wx+b−y)x,∂L∂b=2(wx+b−y).\begin{aligned} \frac{\partial L}{\partial w} &=2(wx+b-y)x,\\ \frac{\partial L}{\partial b} &=2(wx+b-y). \end{aligned}∂w∂L​∂b∂L​​=2(wx+b−y)x,=2(wx+b−y).​

把房屋 C 的 x=3x=3x=3、y=1.6y=1.6y=1.6 和当前参数代入，预测误差为 −0.3-0.3−0.3，所以

∂L∂w=2(−0.3)(3)=−1.8,∂L∂b=2(−0.3)=−0.6.\begin{aligned} \frac{\partial L}{\partial w}&=2(-0.3)(3)=-1.8,\\ \frac{\partial L}{\partial b}&=2(-0.3)=-0.6. \end{aligned}∂w∂L​∂b∂L​​=2(−0.3)(3)=−1.8,=2(−0.3)=−0.6.​

两个导数都是负数，表示此刻让参数增加一点，会降低这一条样本的损失。梯度下降按“减去导数”的方向更新。设学习率 η=0.02\eta=0.02η=0.02：

w新=w−η∂L∂w=0.3−0.02(−1.8)=0.336,b新=b−η∂L∂b=0.4−0.02(−0.6)=0.412.\begin{aligned} w_{\text{新}}&=w-\eta\frac{\partial L}{\partial w} =0.3-0.02(-1.8)=0.336,\\ b_{\text{新}}&=b-\eta\frac{\partial L}{\partial b} =0.4-0.02(-0.6)=0.412. \end{aligned}w新​b新​​=w−η∂w∂L​=0.3−0.02(−1.8)=0.336,=b−η∂b∂L​=0.4−0.02(−0.6)=0.412.​

更新后，房屋 C 的预测成为 0.336×3+0.412=1.420.336\times3+0.412=1.420.336×3+0.412=1.42，损失成为 (1.42−1.6)2=0.0324(1.42-1.6)^2=0.0324(1.42−1.6)2=0.0324。这一小步确实改善了 C 这一个样本。它没有证明全部六条样本的平均损失也下降；若要评价整体，应重新计算 JJJ。实际训练经常在一小批样本上计算平均梯度并更新，而不是只根据一条记录决定整个模型。

这里可以看到“学习”的实物：输入列没有变，程序结构没有变，参数从 (0.3,0.4)(0.3,0.4)(0.3,0.4) 变成了 (0.336,0.412)(0.336,0.412)(0.336,0.412)。反复经过“预测、算损失、求梯度、更新参数”，参数逐渐趋向能解释数据的位置。学习率太大可能来回越过低损失区域；太小则训练很慢。将全部训练样本处理一遍叫一个轮次，处理多个轮次并不自动意味着对新房屋更准。

6. 分类仍沿用同一条训练链

租金是连续数值，属于回归。若目标变成“邮件是正常通知还是广告”，就是分类。输入可以是词语、发件人、链接数等特征；输出要说明各类别有多可能。模型会先给类别打分，再把分数转换成概率。例如两类原始分数为 222 和 111，用 softmax 转换后，第一类概率约为 0.7310.7310.731，第二类约为 0.2690.2690.269。正确类别获得的概率越低，分类损失通常越大。

P(y=k∣x)=ezk∑jezj,L=−log⁡P(y=正确类别∣x).P(y=k\mid x)=\frac{e^{z_k}}{\sum_j e^{z_j}}, \qquad L=-\log P(y=\text{正确类别}\mid x).P(y=k∣x)=∑j​ezj​ezk​​,L=−logP(y=正确类别∣x).

这里 zkz_kzk​ 是第 kkk 类的原始分数。这个公式稍后也会用于语言模型选择下一个词元。回归和分类的标签与损失不同，但都遵循样本 → 预测 → 损失 → 参数更新。概率较高仍不保证绝对正确；还要用真实数据检查模型是否在某些类别上经常自信地犯错。

7. 检验：学到的是规律，还是记住了表格

如果把六套房屋的答案背下来，再考原来的六套，满分说明不了对新房屋的能力。机器学习关心的核心是泛化：面对训练中没见过、但属于同一任务的新样本时，是否仍然表现良好。

数据集合用途能否反复拿来改模型
训练集计算损失并更新参数可以
验证集比较模型方案、选择停止时机可以用于选择，但不能当作未碰过的最终检验
测试集方案确定后估计新数据表现不应根据其结果反复调方案

真实项目需要足够的数据来划分；眼前六条只是教学样本，不适合硬拆成可信的三份统计结果。这里要理解的是用途边界：若每次看见测试成绩不好就修改方案，测试集已经参与决策，最后的高分会显得过于乐观。

训练损失很低、验证损失却高，可能发生了过拟合：模型记住训练细节却没有抓住稳定关系。训练损失本身很高，则可能是欠拟合：模型表达能力不够、特征不合适，或尚未充分训练。这两种现象要结合训练曲线、样本和错误类型判断，不能只凭“模型大还是小”下结论。更复杂的模型可能更容易拟合细节，但也可能在数据充足、约束得当时更好地泛化。

即使测试集表现不错，也要问它代表谁。如果训练与测试都来自同一年、同一区域的小公寓，却拿模型估算几年后外地的大房屋，就发生了分布变化。旧测试成绩不能直接保证新环境效果。按时间或使用场景划分数据，往往比随机拆分更接近真正的问题。

最后，预测关系不是因果解释。面积与租金同向变化，可能还伴随地段、品质等因素变化。模型可以利用相关性预测，却不能单凭这张表证明“人为把面积数字写大，租金就会上涨”。模型输出的依据、能够适用的范围和现实因果，需要分别讨论。

8. 为下一课留下的问题

我们已经看清一条训练链：定义输入和标签，选择模型，计算损失，沿梯度调整参数，再用独立样本检验。直线只用两个参数，便于板书算清；它处理复杂图像、声音和语言时很有限。下一课要解决的关键是：模型怎样自己形成更有用的中间特征，同时仍能用损失来训练大量参数？
