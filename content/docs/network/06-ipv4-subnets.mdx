# 第六节：IPv4 地址与校园网网段

前面说“路由器根据目标 IP 地址转发”，但地址究竟长什么样？这节先看 **IPv4**。IPv4 是互联网协议的一个版本；现实网络也广泛使用 IPv6，两者地址写法不同。这里集中学习 IPv4 的表示和网段判断。

## 一、四组数字组成一个地址

IPv4 地址长度是 **32 位**，通常分成四个 8 位组，用点隔开。每组是 0～255 的十进制数。例如**192.168.10.34**。因为每组占 8 位，所以四组一共是 32 位。IP 地址描述网络层的位置，具体绑定到设备的网络接口；一台设备可能有不止一个接口和地址。

在宿舍或校园网，你可能见到 10.x.x.x、172.16～31.x.x、192.168.x.x 之类的私有地址。私有地址能在内部网络重复使用，不能仅凭它推断设备在公网的唯一位置。外网访问还可能经过地址转换、代理等设备。这里用 **192.168.10.34** 作为虚构的校园练习地址，不表示任何真实学校的配置。

## 二、地址后面的 /24 是什么意思

写成 **192.168.10.34/24**时，“/24”表示前 24 位是网络前缀。由于每组 8 位，前三组**192.168.10**恰好占 24 位。与它对应的子网掩码是**255.255.255.0**：255 的 8 个二进制位都是 1，用来保留前缀；最后一组 0 的 8 个位不属于前缀。

这一地址所在的 /24 地址块写作 **192.168.10.0/24**，包含从 192.168.10.0 到 192.168.10.255 的 256 个地址。这里说的是**地址块包含的地址数**，不等于这些地址都能直接分配给普通主机；网络地址、广播地址等用途会影响常见子网中的可分配数量。

CIDR 是按任意长度前缀描述地址块的方法。前缀越长，固定的位越多，地址块越小：/24 留下 8 位，块内有 2⁸ = 256 个地址；/26 留下 6 位，块内有 2⁶ = 64 个地址。

## 三、判断两个地址是否在同一个前缀块

假设你的笔记本是 **192.168.10.34/24**：

| 要比较的地址  | 前 24 位对应的前三组 | 与笔记本同属 192.168.10.0/24 吗？ |
| ------------- | -------------------- | --------------------------------- |
| 192.168.10.80 | 192.168.10           | 是                                |
| 192.168.11.8  | 192.168.11           | 否                                |

“同属一个前缀块”是**按给定前缀计算**的结论。它还不能单独证明两台设备之间物理直连，或一定允许互访；校园网可能有隔离与访问控制。通常设备会据本地配置决定：目标在本地链路上时尝试直接交付，不在本地时交给默认网关。

## 四、前缀不总停在小数点处

/26 比 /24 多固定了两位。一个 /24 地址块可以分为四个 /26 块，每块 64 个地址：

| /26 地址块        | 最后一组的范围 |
| ----------------- | -------------- |
| 192.168.10.0/26   | 0～63          |
| 192.168.10.64/26  | 64～127        |
| 192.168.10.128/26 | 128～191       |
| 192.168.10.192/26 | 192～255       |

因此 192.168.10.34 和 192.168.10.80 虽同属 **192.168.10.0/24**，却不属于同一个 **/26** 块。这说明“是否同网段”必须连同 **前缀长度** 一起说，不能只看前几组数字是否相同。

## 五、用按位与求网络地址

对 IPv4 地址和子网掩码逐位做**按位与**：对应位都为 1 时结果才为 1。掩码中的 1 保留前缀位，0 清掉主机位。例如 192.168.10.130/26 的掩码为**255.255.255.192**。最后一组 130 的二进制是 10000010，192 是 11000000；逐位与得到 10000000，即十进制 128。所以网络地址是**192.168.10.128**，块写作**192.168.10.128/26**。

这个办法适用于前缀不在字节边界的情况，不能只看点分十进制的前几组。比如 /27 的最后一组掩码是 224，每块 32 个地址；/29 的最后一组掩码是 248，每块 8 个地址。能否把一个地址块写对，可再用“块起点必须是块大小的整数倍”检验：192.168.10.130/26 所在块起点为 128，130 本身不能作为这个 /26 块的起点。

## 六、网络地址、广播地址与可用地址

对传统 IPv4 单播子网，主机位全 0 的地址是网络地址，主机位全 1 的地址是该子网的定向广播地址。以 **192.168.10.128/26**为例，整个块是 .128～.191；网络地址 .128，广播地址 .191；通常可分配给接口的地址是**.129～.190，共 62 个**。这里的 62 来自 2⁶ − 2，而不是一条可以无条件套在任何前缀上的公式；/31 点到点链路和 /32 主机路由有特殊用途。

“可分配”也不等于“校园网里一定能使用”。例如学校可能把 .129 配为网关、把其他地址保留给设备，或用 DHCP 分配范围限制实际可领到的地址。地址计算和网络管理策略要分开。

## 七、按需求划分一个教学地址块

假设实验室拿到 **192.168.10.0/24**，需要两个独立子网：A 有 50 台终端，B 有 25 台终端，**每个子网还各有一个网关接口，占用一个可分配地址**，暂不预留其他接口。A 需要 51 个可分配地址，因此选择 /26：64 个地址，传统计算下 62 个可分配。B 需要 26 个，选择 /27：32 个地址，30 个可分配。可以把 A 放在 **192.168.10.0/26**（.0～.63），B 放在 **192.168.10.64/27**（.64～.95）。两块不重叠，剩余地址可留给后续规划。

| 子网     | 前缀             | 整块范围 | 通常可分配范围 |
| -------- | ---------------- | -------- | -------------- |
| 实验室 A | 192.168.10.0/26  | .0～.63  | .1～.62        |
| 实验室 B | 192.168.10.64/27 | .64～.95 | .65～.94       |

## 八、动手推演：把接口需求放进地址块

现在重新规划 **192.168.10.0/24**。A 有 **58 台学生终端**，B 有 **26 台学生终端**；每个子网另外需要 **1 个网关接口、3 个固定设备接口**。所有这些接口都各占一个地址，网关和固定设备**没有计入学生终端数量**。采用传统 IPv4 单播子网规则，网络地址和广播地址不能分配；选择刚好能容纳需求的最小地址块，不另留增长余量。

先分别算出 A、B 的接口总数，再比较 /27 和 /26 的容量。将较大的 A 从 .0 开始分配，B 放在 A 之后第一个符合自身块大小的边界；每块的首个可分配地址给网关，接着三个给固定设备，之后给终端。**交出地址规划表**：前缀、网络地址、广播地址、网关、固定设备范围、终端范围。核对块起点是否对齐、两块是否重叠，以及每段范围用“末地址 − 首地址 + 1”计算后是否满足需求。

<details>
<summary>规划提示：先数接口，不急着写地址</summary>

对每个子网列三项：学生终端、网关接口、固定设备接口。把三项相加后，按主机位数计算地址块总数，再扣除网络和广播两个地址，与接口需求比较。

</details>

<details>
<summary>边界提示：容量够用还要检查什么</summary>

先写 A 整块的起点和终点，B 的起点必须在 A 之后且为 B 块大小的整数倍。网络地址和广播地址不能计入终端范围；固定设备与网关也不能重复占用同一个地址。

</details>

<details>
<summary>完成后核对地址规划</summary>

A 需要 58 + 1 + 3 = 62 个可分配地址，/26 的 2⁶ − 2 = 62 恰好够用。B 需要 26 + 1 + 3 = 30 个，/27 的 2⁵ − 2 = 30 恰好够用。

下表中的简写均以前三组 `192.168.10` 为前缀。

| 子网 | 地址块           | 网络地址 | 广播地址 | 网关 | 固定设备 | 学生终端 |
| ---- | ---------------- | -------- | -------- | ---- | -------- | -------- |
| A    | 192.168.10.0/26  | .0       | .63      | .1   | .2～.4   | .5～.62  |
| B    | 192.168.10.64/27 | .64      | .95      | .65  | .66～.68 | .69～.94 |

.0 是 64 的整数倍，.64 是 32 的整数倍，边界正确；.0～.63 与 .64～.95 不重叠。A 的终端范围有 62 − 5 + 1 = 58 个地址，B 有 94 − 69 + 1 = 26 个。两块均已用满可分配地址，不能再把网关当成“不占名额”。

</details>

### 换一个条件：A 多一台终端

A 增至 **59 台学生终端**，其他接口数量不变，B 的需求不变。仍从 .0 开始放 A，并让 B 紧接在下一个合法边界。原来的 /26 还够吗？写出 A、B 的新前缀、网络地址、广播地址和可分配地址数，并解释 B 为什么需要移动。

<details>
<summary>查看迁移题解析</summary>

A 需要 59 + 1 + 3 = 63 个地址，超过 /26 的 62 个；最小可用块改为 /25，提供 2⁷ − 2 = 126 个可分配地址。

A 用 **192.168.10.0/25**：网络地址 .0，广播地址 .127，可分配 .1～.126，共 126 个。B 用 **192.168.10.128/27**：网络地址 .128，广播地址 .159，可分配 .129～.158，共 30 个。

原来 B 的 .64～.95 落进了新的 A 块 .0～.127，继续使用会重叠，因此移到 .128；128 也是 32 的整数倍。A 增加一台终端就越过了容量边界，地址块必须整块扩展，不能只把广播地址拿来分配。

</details>
