# 现代人工智能：原理、系统与前沿（2026）课程设计与实施

大纲编制：2026-10-20；制作接续与一手资料复核：2026-10-21。本文供教师与后续课程制作者使用。

状态：40 个单元、环境页与 8 组实验教学页已制作，标准库 CPU 程序、构造数据、下载包与核验输出由仓库保存。依据 2026-10-21 用户“检查哪些没完成、继续做完”的明确要求，接续原中断制作。课程结构最初由 AI 提议；本次实现取舍与用户已确认条件分别说明。尚未实际授课，也没有学生掌握证据。

## 一、已确认的对象、目标与条件

依据用户在 2026-10-20 本次对话中的明确说明：

- 学生为大四学生，具备计算机基础，有 Python 基础，尚未接触人工智能。
- 重点是现代人工智能的原理、系统与截至 2026 年的最新进展，传统机器学习不是课程主体。
- 不设置学时上限；不按其他课程的 64 学时或既有十节目录压缩范围。
- 学生没有 GPU 和模型 API 条件。核心实验按本地 CPU 设计，不要求购买账号、调用云端模型或训练大规模模型。
- 允许整体重建，同时参考旧材料中有价值的算例和解释；本轮先整理大纲。

年度案例在 2026-10-21 重新访问一手原文，不包含此后进展。已有计算机与 Python 基础不等于已掌握 AI 所需的向量、概率、求导或深度学习框架；这些内容要在对应问题中给足桥梁。

## 二、课程主线与结束时的能力

建议课程名称为“现代人工智能：原理、系统与前沿”。以一个可以回答、查资料、看图和使用工具的系统为贯穿对象：先拆开系统，再理解模型的表示、学习与生成，随后理解后训练、推理、多模态、知识接入和行动，最后用实验判断效果、成本与边界。

学习主线：**输入如何表示 → 参数如何学到 → 输出如何生成 → 能力如何改善 → 知识如何接入 → 行动如何执行 → 结果如何验证。**

完成课程后，学生应能够：

1. 区分模型与产品、训练与推断、参数与上下文、检索与工具、工作流与智能体，追踪一条回答或一次行动的信息来源。
2. 对微型网络、注意力和生成过程复算关键中间状态，用 Python 验证预测，并解释改变数据、参数或约束后的结果。
3. 解释 Transformer 的完整数据流，以及预训练、指令微调、偏好优化、可验证奖励、蒸馏和推理时计算各改变了什么。
4. 解释图文对齐、视觉语言模型、扩散与流匹配、语音和视频模型的基本机制，分清生成效果与可靠理解、物理正确性之间的差别。
5. 在课程提供的 CPU 环境中实现规模受控的检索问答与受限工具系统，保存输入、状态、输出、错误和评测证据。
6. 阅读一份新的模型卡或技术报告，识别公开机制、实验条件、厂商主张、未披露细节及尚无证据支持的推广。

历史、传统方法与哲学讨论在需要时提供背景。规则与搜索用于建立基线、解释规划和验证；回归用于看清更新；CNN 用于理解局部结构。不安排一套独立的传统算法巡礼作为全课主轴。

## 三、知识结构：七个模块、四十个单元

知识单元不等于固定课时，也不要求一个单元只对应一张网页。按问题与依赖拆分，后续可以将复杂单元展开为多页。每单元同时规定核心机制与可检查的学习产出，避免仅以“介绍过主题”作为完成标准。

运行环境按实验需要提前交付：第 03 单元前完成标准库数值与自动求导诊断，第 08 单元前交付可读微型 Transformer，第 15 单元前准备回答位置监督实验。通用预训练模型的 CPU 推断另有选配分支，制作机已实测，未要求全体学生具备该实例；这一实施取舍及具体前置门槛见第五部分。第 32 单元系统解释运行时、量化与资源。

入口问题：普通程序已经会计算和查表，现代 AI 究竟增加了什么？

| 02 现实怎样成为模型输入 | 表格、像素、声音采样、文本编号；样本、特征、标签；观察信息的损失；预测时点与数据泄漏                       | 为一个任务定义可用输入与目标；构造一个泄漏反例；说明记录遗漏了什么                   |
| 03 运算需要的数学桥梁   | 向量、矩阵、维度、点积、加权和；概率分布、条件概率与期望；用具体数组和小表推演                             | 用 Python 与手算核对点积、矩阵形状、归一化概率；解释编号大小为何不是语义距离         |
| 04 学习究竟改变了什么   | 参数、预测、损失、导数、梯度与学习率；从试改参数到梯度更新；训练、验证、测试与泛化                         | 用旧租金算例完成更新，重新算整批损失；改变学习率；保存训练与未见样本的误差           |
| 05 从直线到表示学习     | XOR 反例、非线性、隐藏层、计算图、链式法则、自动求导；表达能力与学得结果的区别                             | 追踪一个小网络的前向、反向与更新；检验梯度；区分手工构造权重与真实训练所得权重       |

### 模块 C：从预训练到助手与推理模型（13—18）

## 六、每个单元必须交付的教学组成

1. 一个具体问题和可判断的学习目标，先让学生尝试或预测。
2. 一个朴素方案及其失败反例，说明新机制解决的具体缺陷。
3. 自足的必要定义、数学桥梁和逐步状态，给清单位、维度、输入输出与符号。
4. 至少一个完整讲解例题，随后给学生补中间状态、改条件或运行验证的任务。
5. 三层提示：线索/字段、中间状态、完整解析。完整答案与独立任务分开呈现。
6. 陌生变式与明确验收标准，记录独立完成、提示后完成、仍不能解释的差别。
7. 教师动作、学生动作、材料、预期产物、常见错误和检查方法。
8. 涉及真实模型或动态事实时，给来源、版本、条件和适用边界；学生页给足学习材料，教师取材与课程规划留在教师文档。

检查点建议：05 后检验训练链；12 后重建 Transformer 生成链；18 后区分各类训练与推理；24 后比较多模态路线；31 后审计完整行动轨迹；36 后完成系统评测；40 做延迟保持与陌生迁移。具体分值和成绩权重未确定，不冒充学校已定考核制度。
